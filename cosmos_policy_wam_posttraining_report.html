背景与动机（Background & Motivation）

Cosmos Policy 是 NVIDIA 基于 Cosmos 世界基础模型发展出的机器人策略路线。它的关键思想不是把一个 VLM 后面简单接 action head，而是把机器人动作、本体感知、未来视觉状态和值函数都转成与视频 latent 兼容的“帧”，让同一个 Video2World 扩散/rectified-flow 模型承担三类预测任务。

这正好落在 WAM 的核心定义上：模型不仅需要输出动作 \(a_{t:t+H}\)，还需要理解动作导致的未来状态 \(s_{t+H}\)，并对未来好坏给出价值估计 \(V_t\)。抽象地说：

\[ \text{WAM:}\quad p_\theta(a_{t:t+H},\, s_{t+1:t+H},\, V_t \mid o_{\le t},\, l) \]

其中 \(o_{\le t}\) 表示历史观测（observation history），\(l\) 表示语言指令（language instruction），\(a_{t:t+H}\) 是未来 \(H\) 步动作块（action chunk），\(s_{t+1:t+H}\) 是未来世界状态或未来图像/本体感知，\(V_t\) 是从当前状态出发的价值或折扣回报。

VLA 直接预测动作：\(p(a\mid o,l)\)。优点是部署简单；缺点是不显式想象动作后果。
WM 预测世界演化：\(p(s'\mid s,a,l)\)。优点是能 rollout；缺点是不一定直接给可执行策略。
WAM 联合动作、未来和值：\(p(a,s',V\mid o,l)\)。适合长程任务、失败恢复和 model-based selection。

本地证据显示，13_dreamdojo_world_model 已经从 4 月 DreamDojo 快照转向 5 月 Cosmos Predict2.5 / Cosmos Policy RoboCasa finetune。该判断见本地 [README](C:/Users/mousongzhe/pryer/project/13_dreamdojo_world_model/README.md) 第 1-22 行，以及远端进度报告第 30-75 行。

数学表达：从 WAM 目标到训练损失

1. 轨迹与回报

令一条机器人轨迹为：

\[ \tau = (o_0, p_0, a_0, r_0, o_1, p_1, a_1, r_1, \dots, o_T, p_T) \]

其中 \(o_t\) 是视觉观测，\(p_t\) 是 proprioception，\(a_t\) 是动作，\(r_t\) 是奖励或成功标注转换出的 reward。Cosmos Policy 的 value 监督通常来自 Monte Carlo return：

\[ G_t = \sum_{k=0}^{T-t} \gamma^k r_{t+k},\qquad \gamma=0.99 \]

这里 \(G_t\) 是一个标量（scalar）。本地代码会把它 expand 成和 latent frame 同形状的张量，以便复用视频去噪损失；语义上仍是一个 value/return 数。

2. WAM 的联合条件分布

理想 WAM 可以写成：

\[ p_\theta(a_{t:t+H}, o_{t+H}, p_{t+H}, G_t \mid o_t, p_t, l) \]

Cosmos Policy 的工程实现不是四个完全独立 head，而是把这些对象放进 latent-video 序列 \(x\) 的不同 slot：

\[ x = [x^{obs}_1,\dots,x^{obs}_m,\ x^{action}_{i_a},\ x^{future}_{i_f},\ x^{value}_{i_v}] \]

其中 \(x^{action}_{i_a}\) 由 action chunk 注入，\(x^{future}_{i_f}\) 对应未来图像/未来 proprio，\(x^{value}_{i_v}\) 对应 value return。

3. 扩散/EDM 去噪目标

令干净 latent 为 \(x_0\)，噪声为 \(\epsilon\)，噪声尺度为 \(\sigma\)，加噪后的 latent 为：

\[ x_\sigma = \mu(\sigma)x_0 + s(\sigma)\epsilon \]

模型 \(D_\theta\) 根据 noisy latent、噪声尺度和条件 \(c\) 预测干净 latent：

\[ \hat{x}_0 = D_\theta(x_\sigma, \sigma, c) \]

基础 EDM loss 可以写成：

\[ \mathcal{L}_{edm} = w(\sigma)\left\|\hat{x}_0 - x_0\right\|_2^2 \]

其中 \(w(\sigma)\) 是噪声尺度相关权重。代码中的 weights_per_sigma_B_T 就对应每个样本、每个 latent frame 的权重。

4. 三任务 mask 损失

Cosmos Policy 的关键在于为每个样本构造任务 mask。令 \(m^\pi, m^W, m^V\in\{0,1\}\) 分别表示 policy demo、world-model rollout、value-function rollout。总损失可写成：

\[ \mathcal{L} = \mathbb{E}_{\tau,t,\sigma} \left[ \lambda_a m^\pi \ell_{i_a} + m^W \sum_{j\in \mathcal{F}}\ell_j + \lambda_v m^V \ell_{i_v} \right] \]

其中：

  • \(\ell_j = w(\sigma)\|\hat{x}_{0,j}-x_{0,j}\|_2^2\)，表示第 \(j\) 个 latent slot 的 denoising loss。
  • \(i_a\) 是 action slot，对应 action_latent_idx。
  • \(\mathcal{F}\) 是未来状态 slot 集合，包括未来 wrist image、third-person image、future proprio。
  • \(i_v\) 是 value slot，对应 value_latent_idx。
  • \(\lambda_a=16\) 来自本地配置 action_loss_multiplier: 16。
为什么 rollout 样本还要按 p_world_model=0.5 分给 world/value？

因为 world model 和 value function 对输入 mask 与预测 slot 的要求不同。world 样本把 action 作为条件，预测未来；value 样本把除 value slot 外的信息作为条件，预测 return。分流能避免同一个 rollout 样本同时承担过多目标，降低 mask 复杂度、loss 竞争和显存开销。它不是所有 WAM 的通用必选设计，而是 Cosmos Policy 这类统一 latent-frame 训练里很自然的工程取舍。

伪代码 1：RoboCasa WAM 样本构造

def build_cosmos_policy_sample(idx):
    """
    输入：
        idx: DataLoader 给出的全局样本索引。

    输出：
        sample_dict: 一个 Cosmos Policy WAM 训练样本。

    目标：
        把机器人轨迹中的图像、动作、本体感知、未来状态、value return
        组织成 Video2World 可以吃的 video-like slot 序列。
    """

    # 1. 根据 idx 判断样本来源。
    #    demo: 成功示教，用来训练 policy/action。
    #    success_rollout / failure_rollout: 执行 rollout，用来训练 world/value。
    sample_type = determine_sample_type(
        idx,
        adjusted_demo_count,
        adjusted_success_rollout_count,
    )

    rollout_data_mask = 0 if sample_type == "demo" else 1
    rollout_data_success_mask = 1 if sample_type == "success_rollout" else 0

    # 2. 读取当前时间步和未来时间步。
    #    future_frame_idx 通常是 relative_step_idx + chunk_size，
    #    表示模型要预测一个动作块之后的未来世界。
    episode_data, relative_step_idx = load_episode_slice(sample_type, idx)
    future_frame_idx = min(
        relative_step_idx + chunk_size,
        episode_data["num_steps"] - 1,
    )

    # 3. 对 rollout 样本进一步分流。
    #    world_model_sample: action 是条件，目标是预测 future image/proprio。
    #    value_function_sample: 未来状态/action 是条件，目标是预测 value return。
    #    demo 样本默认是 policy/action 样本。
    is_world_model_sample = False
    is_value_function_sample = False
    if sample_type != "demo":
        if return_value_function_returns:
            if random_uniform_0_1() < p_world_model:
                is_world_model_sample = True
            else:
                is_value_function_sample = True
        else:
            is_world_model_sample = True

    # 4. 构造 video-like slot 序列。
    #    每个 slot 最终都会变成 latent video 的一个时间位置。
    image_list = []
    current_sequence_idx = 0

    # 4.1 当前图像 slot：作为条件输入。
    current_left = load_current_left_image(episode_data, relative_step_idx)
    image_list.append(duplicate_for_tokenizer(current_left))
    current_image_latent_idx = current_sequence_idx
    current_sequence_idx += 1

    # 4.2 当前 proprio slot：图像位置先放 blank，数值稍后注入 latent。
    current_proprio = episode_data["proprio"][relative_step_idx]
    image_list.append(blank_image_like(current_left))
    current_proprio_latent_idx = current_sequence_idx
    current_sequence_idx += 1

    # 4.3 action slot：先放 blank，后面用 replace_latent_with_action_chunk 写入动作。
    image_list.append(blank_image_like(current_left))
    action_latent_idx = current_sequence_idx
    current_sequence_idx += 1

    # 4.4 未来 proprio slot：world model 的目标之一。
    future_proprio = episode_data["proprio"][future_frame_idx]
    image_list.append(blank_image_like(current_left))
    future_proprio_latent_idx = current_sequence_idx
    current_sequence_idx += 1

    # 4.5 未来图像 slot：world model 的主要视觉预测目标。
    future_left = load_future_left_image(episode_data, future_frame_idx)
    image_list.append(duplicate_for_tokenizer(future_left))
    future_image_latent_idx = current_sequence_idx
    current_sequence_idx += 1

    # 4.6 value slot：先放 blank，后面把 scalar return 扩展成 latent frame。
    image_list.append(blank_image_like(current_left))
    value_latent_idx = current_sequence_idx
    current_sequence_idx += 1

    # 5. 取动作块。
    #    如果剩余动作不足 chunk_size，就重复最后一个动作补齐。
    action_chunk = slice_actions_with_padding(
        episode_data["actions"],
        start=relative_step_idx,
        length=chunk_size,  # 本地配置为 32
    )

    # 6. 取 value return。
    #    语义上是 scalar G_t；后续模型会把它扩展成 latent frame。
    value_function_return = episode_data["returns"][future_frame_idx]

    # 7. 组装训练样本。
    return {
        "video": preprocess_and_stack(image_list),          # 输入给视频 tokenizer / VAE
        "command": episode_data["command"],                 # 语言指令文本
        "t5_text_embeddings": lookup_t5_embedding(command), # 文本条件
        "actions": action_chunk,                            # [32, 7]
        "proprio": current_proprio,                         # 当前 proprio
        "future_proprio": future_proprio,                   # 未来 proprio
        "rollout_data_mask": rollout_data_mask,
        "rollout_data_success_mask": rollout_data_success_mask,
        "world_model_sample_mask": int(is_world_model_sample),
        "value_function_sample_mask": int(is_value_function_sample),
        "action_latent_idx": action_latent_idx,
        "value_latent_idx": value_latent_idx,
        "current_proprio_latent_idx": current_proprio_latent_idx,
        "future_proprio_latent_idx": future_proprio_latent_idx,
        "future_image_latent_idx": future_image_latent_idx,
        "value_function_return": value_function_return,
    }

def get_data_and_condition(data_batch):
    """
    输入：
        data_batch: DataLoader collate 后的一批 sample_dict。

    输出：
        x0: 干净 latent video，包含图像 slot、action slot、future slot、value slot。
        condition: Video2World 条件对象，内部含 gt_frames 和 condition mask。

    核心思想：
        Cosmos 原本会把视频帧编码成 latent。Cosmos Policy 额外把机器人动作、
        proprio、value return 写进指定 latent frame，让这些非图像变量也能
        用同一个 denoiser 预测。
    """

    # 1. 调用 Video2World 基类：把 video 编码成 latent_state。
    raw_state, latent_state, condition = super_video2world_get_data(data_batch)

    # 2. 设置普通视频条件帧。
    #    例如当前图像作为条件，未来 slot 留给模型预测。
    condition.set_video_condition(
        gt_frames=latent_state,
        conditional_frames_probs={5: 1.0},  # 本地配置中固定条件帧策略
    )

    # 3. 对 world-model rollout 样本：
    #    action slot 应该被看成已知条件，因为世界模型要学 p(future | current, action)。
    if "rollout_data_mask" in data_batch:
        world_mask = expand_to_latent_mask(data_batch["world_model_sample_mask"])
        batch_indices = arange(batch_size)
        condition.condition_video_input_mask[
            batch_indices,
            :,
            data_batch["action_latent_idx"],
            :,
            :,
        ] = world_mask

    # 4. 对 value-function rollout 样本：
    #    除 value slot 之外，其余 slot 都可以作为条件；
    #    value slot 留给模型预测 G_t。
    value_mask = expand_to_latent_mask(data_batch["value_function_sample_mask"])
    condition.condition_video_input_mask = where(
        value_mask_applies_to_all_frames(value_mask),
        ones_like(condition.condition_video_input_mask),
        condition.condition_video_input_mask,
    )
    condition.condition_video_input_mask[
        batch_indices,
        :,
        data_batch["value_latent_idx"],
        :,
        :,
    ] = 0

    # 5. 把 action chunk 写入 action latent frame。
    #    这一步是 Cosmos Policy 的关键 glue：
    #    actions 原本是 [B, 32, 7]，会被投影/铺展到 latent frame 的 C,H,W 结构。
    condition.gt_frames = replace_latent_with_action_chunk(
        condition.gt_frames,
        data_batch["actions"],
        action_indices=data_batch["action_latent_idx"],
    )

    # 6. 把当前和未来 proprio 写入对应 latent frame。
    condition.gt_frames = replace_latent_with_proprio(
        condition.gt_frames,
        data_batch["proprio"],
        proprio_indices=data_batch["current_proprio_latent_idx"],
    )
    condition.gt_frames = replace_latent_with_proprio(
        condition.gt_frames,
        data_batch["future_proprio"],
        proprio_indices=data_batch["future_proprio_latent_idx"],
    )

    # 7. 把 scalar value return 扩展成 latent frame。
    #    注意：语义上仍是一个数 G_t；扩展只是为了复用视频 denoising loss。
    value_frame = expand_scalar_to_latent_frame(
        data_batch["value_function_return"],
        channels=C_latent,
        height=H_latent,
        width=W_latent,
    )
    condition.gt_frames[
        batch_indices,
        :,
        data_batch["value_latent_idx"],
        :,
        :,
    ] = value_frame

    return condition.gt_frames, condition

伪代码 3：训练步与三任务 Loss Mask

def cosmos_policy_train_step(data_batch):
    """
    输入：
        data_batch: 包含 video/actions/proprio/future/value/mask/index 的 batch。

    输出：
        loss: 一个标量，用于反向传播。
        metrics: action/world/value 三类分解指标。

    这段伪代码对应 policy_text2world_model.py 中的 compute_loss_with_epsilon_and_sigma。
    """

    # 1. 得到干净 latent x0 和条件 c。
    #    x0 的时间维 T 中，不同位置代表 current/action/future/value。
    x0, condition = get_data_and_condition(data_batch)

    # 2. 采样扩散噪声尺度 sigma 和高斯噪声 epsilon。
    #    训练目标是从 noisy latent 还原 clean latent。
    sigma = sample_sigma(batch_size=x0.shape[0], time_steps=x0.shape[2])
    epsilon = randn_like(x0)
    mean, std = sde_marginal_prob(x0, sigma)
    x_sigma = mean + epsilon * std

    # 3. 调用 Cosmos Video2World denoiser。
    #    模型看到 noisy latent、sigma、文本/视频/机器人条件，输出 predicted x0。
    model_pred = denoise_model(
        x_sigma,
        sigma,
        condition,
    )
    x0_hat = model_pred.x0

    # 4. 每个 latent slot 的基础 MSE / EDM loss。
    per_slot_mse = (x0_hat - x0) ** 2
    per_slot_weight = get_per_sigma_loss_weights(sigma)
    per_slot_loss = per_slot_mse * per_slot_weight

    # 5. 构造 final_mask_B_T。
    #    这是 WAM 后训练最重要的工程对象。
    #    它告诉模型：当前样本应该在哪些 slot 上计算损失。
    final_mask = zeros([B, T])

    for b in range(B):
        if data_batch["rollout_data_mask"][b] == 0:
            # demo 样本：只监督 action slot，训练 policy。
            ia = data_batch["action_latent_idx"][b]
            final_mask[b, ia] = action_loss_multiplier  # 本地配置为 16

        elif data_batch["world_model_sample_mask"][b] == 1:
            # rollout world 样本：action 已作为条件，目标是预测未来世界。
            for jf in future_slots_of_sample(data_batch, b):
                final_mask[b, jf] = 1

        elif data_batch["value_function_sample_mask"][b] == 1:
            # rollout value 样本：其他 slot 作为条件，目标只监督 value slot。
            iv = data_batch["value_latent_idx"][b]
            final_mask[b, iv] = 1

    # 6. 应用 mask 并 reduce。
    #    如果没有 mask，模型会对所有 latent frame 都算 loss，
    #    这会把 action/world/value 的训练目标混在一起。
    masked_loss = per_slot_loss * final_mask[:, None, :, None, None]
    loss = masked_loss.mean()

    # 7. 记录分解指标，避免只看总 loss。
    metrics = {
        "demo_sample_action_mse_loss": mse_on_slot(x0_hat, x0, action_slots, demo_samples),
        "world_model_sample_future_image_mse_loss": mse_on_slot(x0_hat, x0, future_image_slots, world_samples),
        "world_model_sample_future_proprio_mse_loss": mse_on_slot(x0_hat, x0, future_proprio_slots, world_samples),
        "value_function_sample_value_mse_loss": mse_on_slot(x0_hat, x0, value_slots, value_samples),
    }

    # 8. 反向传播更新。
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()

    return loss, metrics

def reproduce_cosmos_policy_wam():

    这个流程不是一次性上来跑百万步，而是按风险分层推进。

    assert world_samples_only_have_future_loss(final_mask, batch)
    assert value_samples_only_have_value_loss(final_mask, batch)

    # Stage C: 小 batch overfit

    model = load_cosmos_predict25_policy_base_or_small_mock()

    # Stage D: 真实短跑

    # 目的：不只看 diffusion loss，还看机器人任务成功率。

        ],

复现路线与资源栈

推荐切入顺序

  1. 只做数据契约：复现 robocasa_dataset.py 的 sample 字段、slot index、mask 逻辑。
  2. 只做 loss mask：mock latent，不加载 2B 权重，验证 policy/world/value mask。
  3. 小模型或局部 overfit：用极小数据检查三类 loss 是否可下降。
  4. 加载 Cosmos Predict2.5 2B checkpoint 短跑：对齐 batch、chunk、action multiplier、save_iter。
  5. closed-loop eval：RoboCasa/LIBERO 成功率才是策略能力证据。

方法对比与选择建议

路线做法优点缺点建议
VLA action-only 只学 \(p(a\mid o,l)\) 最快得到可执行 policy baseline 没有未来想象和 value 作为对照组必须做。
Cascaded WAM VLA 提候选动作，WM rollout，value/heuristic 选动作 模块化，容易调试 延迟高，误差会级联 适合早期验证 WAM 是否有收益。
Cosmos Policy Joint WAM action/future/value 都放进 latent-frame denoising 统一模型，能力边界最接近 WAM 工程复杂，数据契约严格，算力重 这是本报告主推复现路线。
从零预训练 DreamDojo/Cosmos 大规模视频世界模型预训练再机器人后训练 研究完整度最高 数据/算力成本极高 不建议作为第一阶段复现。

复现检查清单

  • 数据确认 success_only 与 all_episodes 的 episode 数、task 分布、success/failure 比例。
  • 动作确认 action dim 为 7，chunk size 为 32，归一化统计与训练配置一致。
  • 文本确认 reason1_embeddings.pkl 中每条 command 都可查到 T5 embedding。
  • Value确认 returns 字段存在，\(\gamma=0.99\)，value 是 scalar 而不是向量。
  • Slot确认 action/value/future/current 的 latent index 不越界、不重复误用。
  • Mask确认 demo/world/value 三种样本的 loss mask 与 condition mask 分别正确。
  • 日志记录总 loss 之外的 action/world/value loss breakdown。
  • 评估closed-loop success rate 必须和 loss 一起看，不能只用生成 loss 宣称 policy 成功。
