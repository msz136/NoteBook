可微分 RL 损失函数：LLM Agent 训练的梯度计算深度调研

聚焦反向传播兼容的损失函数设计、梯度流动机制与实验验证（2024-2026）
关键区分：本报告仅讨论可通过反向传播计算梯度并更新模型权重的损失函数，而非规则评分函数

问题（Question）

在训练 LLM Agent 时，如何将强化学习的奖励信号转化为可微分的损失函数，使梯度能够通过反向传播流向模型参数？具体而言：策略梯度如何在多轮交互中流动？优势信号如何从轨迹级/回合级传递到 token 级？KL 散度惩罚如何实现？长序列中的梯度问题如何解决？

背景与动机（Background & Motivation）

LLM Agent 的 RL 训练面临一个核心挑战：奖励信号通常是不可微的（如环境返回的成功/失败标量），无法直接对模型参数求导。策略梯度方法（Policy Gradient）通过 REINFORCE 定理将这一问题转化为可微分的代理损失（surrogate loss），使得标准反向传播可以更新模型权重。

本报告深入分析 2024-2026 年间的关键方法，聚焦于：

  • 损失函数的精确数学形式
  • 梯度如何从损失流向每个 token 的 logit
  • 不同优势估计方法对梯度方向和幅度的影响
  • 长序列场景下的梯度稳定性问题与解决方案

1. GRPO/PPO 精确梯度计算（多轮 Agent）

1.1 GRPO 核心损失函数

Group Relative Policy Optimization（GRPO）[1] 是 DeepSeek-R1 的核心训练算法。其关键创新在于无需 critic 网络，通过组内相对比较计算优势。

GRPO 优化目标

\[ \mathcal{J}_{\text{GRPO}}(\theta) = \mathbb{E}_{q} \mathbb{E}_{o \sim \pi_{\theta_{\text{old}}}} \left[ f_\varepsilon\!\left(\frac{\pi_\theta(o|q)}{\pi_{\theta_{\text{old}}}(o|q)},\; \hat{A}(q,o)\right) \right] - \beta \cdot D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}}) \]

其中裁剪函数为：

\[ f_\varepsilon(x, y) = \min\!\big(x \cdot y,\; \text{clip}(x, 1-\varepsilon, 1+\varepsilon) \cdot y\big) \]

梯度如何流向每个 token

关键理解：\(\pi_\theta(o|q)\) 是序列级概率，分解为 token 级乘积：

\[ \pi_\theta(o|q) = \prod_{t=1}^{T} \pi_\theta(o_t | q, o_{因此对数概率比（log importance ratio）为：

\[ \log \frac{\pi_\theta(o|q)}{\pi_{\theta_{\text{old}}}(o|q)} = \sum_{t=1}^{T} \log \frac{\pi_\theta(o_t | q, o_{

Per-Token 梯度计算

对每个 token \(o_t\)，梯度为：

\[ \nabla_\theta \mathcal{J} \approx \hat{A}(q,o) \cdot \nabla_\theta \log \pi_\theta(o_t | q, o_{其中 \(\nabla_\theta \log \pi_\theta(o_t | q, o_{相同的优势信号 \(\hat{A}(q,o)\) 作为缩放因子。

1.2 GRPO 优势计算（Advantage）

对于二值可验证奖励 \(r(q,o) \in \{0, 1\}\)，使用均值-方差归一化 [2]：

\[ \hat{A}(q,o) = \frac{r(q,o) - \mu_{\pi_{\theta_{\text{old}}}}(q)}{\sigma_{\pi_{\theta_{\text{old}}}}(q)} \]

当奖励服从伯努利分布（\(\mu = p,\; \sigma^2 = p(1-p)\)）时，简化为：

\[ \hat{A}(q,o) = \begin{cases} \sqrt{\frac{1-p(q)}{p(q)}} & \text{if } r(q,o) = 1 \\[6pt] -\sqrt{\frac{p(q)}{1-p(q)}} & \text{if } r(q,o) = 0 \end{cases} \]
关键洞察 [2]：GRPO 等价于一个自适应加权的对比损失（contrastive loss）。成功率 \(p(q)\) 越低的问题，正确回答获得的梯度权重越大（\(\propto \sqrt{(1-p)/p}\)），形成自动课程学习效应。

1.3 GRPO 的等效损失形式

Razin et al. [2] 证明 GRPO 实际上优化的是一个 arcsin 目标：

GRPO 隐式目标（Proposition 3.1）

\[ \nabla_\theta \mathcal{J}_{\text{GRPO}} \propto \nabla_\theta \left[ 2 \arcsin\!\sqrt{p_\theta(q)} \right] \]

其中 \(p_\theta(q)\) 是策略在问题 \(q\) 上的通过率。这意味着 GRPO 在概率空间中执行均匀的"角度推进"。

1.4 veRL / OpenRLHF 框架实现

veRL（HybridFlow）[3] 和 OpenRLHF [4] 是两个主流的 GRPO/PPO 训练框架。

反向传播实现要点

  • 前向传播：对每个 rollout 序列计算 \(\log \pi_\theta(o_t|q, o_{
  • 优势计算：在组内（G 个 rollout）计算归一化优势，此步骤 stop_gradient
  • 损失构造：loss = -mean(min(ratio * adv, clip(ratio) * adv))
  • 反向传播：PyTorch/JAX 自动微分对 loss 求导，梯度流经 LLM 的所有层
  • 关键：优势 \(\hat{A}\) 和旧策略概率 \(\pi_{\theta_{\text{old}}}\) 均被 detach，不参与梯度计算

veRL 使用 3D-HybridEngine 实现训练/推理并行度切换，通信量为 \(\frac{t_p - t_g \cdot p_g}{t_g \cdot p_g \cdot t_p} \cdot M\)，其中 \(M\) 为模型大小 [3]。

2. Turn-Level PPO 梯度计算

2.1 Turn-PPO：回合级 MDP 建模 [5]

Turn-PPO 将多轮交互重新建模为回合级 MDP，而非 token 级 MDP：

  • 状态：\(s_n := (\oplus_{n'
  • 动作：\(a_n := R_n\)（整个 LLM 回复作为一个原子动作）

回合级优势估计（GAE）

\[ \delta_n = r_n + \gamma V(s_{n+1}) - V(s_n) \] \[ \hat{A}_n = \sum_{l=0}^{N-n-1} (\gamma\lambda)^l \delta_{n+l} \]

Critic 损失：

\[ \mathcal{L}_{\text{critic}}(\phi) = \mathbb{E}\left[\frac{1}{G}\sum_i \frac{1}{N_i}\sum_n \frac{1}{2}\big(V_\phi(s_n^i) - \hat{R}_n^i\big)^2\right] \]

关键问题：回合级优势如何传递到 token 级梯度？

Turn-PPO 的梯度传播机制

回合级重要性采样比：

\[ r_n^i(\theta) = \frac{\pi_\theta(a_n^i|s_n^i)}{\pi_{\theta_t}(a_n^i|s_n^i)} = \prod_{h=1}^{|a_n^i|} \frac{\pi_\theta(a_{n,h}^i|s_{n,h}^i)}{\pi_{\theta_t}(a_{n,h}^i|s_{n,h}^i)} \]

Actor 损失：

\[ \mathcal{L}_{\text{actor}}(\theta) = -\mathbb{E}\left[\frac{1}{G}\sum_i \frac{1}{|a^i|}\sum_n \text{MC}_\varepsilon\!\big(r_n^i(\theta),\; \hat{A}_n^i\big)\right] \]

其中 \(\text{MC}_\varepsilon\) 是 PPO 的 min-clip 算子。

梯度流动：虽然优势 \(\hat{A}_n^i\) 在回合级计算，但损失中的 \(\log \pi_\theta(a_{n,h}^i|s_{n,h}^i)\) 对每个 token \(h\) 都产生梯度。同一回合内所有 token 共享相同的优势信号 \(\hat{A}_n^i\)，但各自的梯度方向由其 logit 决定。

2.3 ST-PPO：回合级重要性采样的稳定化 [6]

Stabilized Off-Policy PPO（SO-PPO/ST-PPO）进一步解决了离策略训练中的梯度偏差问题。

回合级重要性权重

\[ w_k^{\text{turn}}(\theta) = \exp\!\left(\frac{1}{|y^k|}\sum_{t} \log \frac{\pi_\theta(y_t|x, y_{使用几何平均而非算术乘积，避免长序列中的数值下溢。

裁剪触发归一化（Clipping-Triggered Normalization）

PPO 梯度分解为两部分 [6]：

\[ \frac{\partial \mathcal{J}_{\text{PPO}}}{\partial \log \pi_\theta} = \mathbb{E}[\text{Policy Gradient}] - \mathbb{E}[C(\theta)] \]

其中裁剪偏差项为：

\[ C_{\text{turn}}(\theta) := \mathbb{E}_\tau\!\left[\frac{1}{|y|}\sum_t \mathbb{1}_{t \in B_{\text{turn}}^c} \cdot w_t^{\text{turn}}(\theta) \cdot \hat{A}_t\right] \]

稳定化梯度：

\[ \nabla_\theta \mathcal{J}_{\text{SO-PPO}}(\theta) := \frac{1}{\max(\|C_{\text{turn}}(\theta)\|_2,\; \delta)} \cdot \nabla_\theta \mathcal{J}_{\text{Turn-PPO}}(\theta) \]

实验结果：SO-PPO 在医学 QA 上达到 53.88% 平均准确率，SO-GRPO 达到 55.34%，显著优于 Search-R1 的 45.37% [6]。

3. GiGPO 双层优势 → 梯度

3.1 核心思想：宏观 + 微观优势 [7]

Group-in-Group Policy Optimization（GiGPO）引入双层优势估计架构，解决长序列 Agent 中的信用分配问题。

Episode 级（宏观）优势

\[ A^E(\tau_i) = \frac{R(\tau_i) - \text{mean}(\{R(\tau_j)\}_{j=1}^N)}{F_{\text{norm}}(\{R(\tau_j)\})} \]

其中 \(F_{\text{norm}}\) 为标准差或固定为 1（无偏估计）。这与标准 GRPO 的优势计算相同。

Step 级（微观）优势

\[ A^S(a_t^{(i)}) = \frac{R_t^{(i)} - \text{mean}\!\big(\{R_t^{(j)} \mid (a_t^{(j)}, R_t^{(j)}) \in \mathcal{G}^S(\tilde{s})\}\big)}{F_{\text{norm}}(\cdots)} \]

折扣回报：\(R_t^{(i)} = \sum_{k=t}^{T} \gamma^{k-t} r_k^{(i)}\)

锚定状态分组（Anchor State Grouping）

微观优势的关键创新——在相同环境状态下跨轨迹聚合动作：

\[ \mathcal{G}^S(\tilde{s}) = \{(a_t^{(i)}, R_t^{(i)}) \mid s_t^{(i)} = \tilde{s},\; 1 \le i \le N,\; 1 \le t \le T\} \]

3.2 组合损失函数

GiGPO 最终可微分损失

\[ A(a_t^{(i)}) = A^E(\tau_i) + \omega \cdot A^S(a_t^{(i)}) \] \[ \mathcal{J}_{\text{GiGPO}}(\theta) = \mathbb{E}\!\left[\min\!\big(\rho_\theta(a_t^{(i)}) \cdot A(a_t^{(i)}),\; \text{clip}(\rho_\theta, 1\pm\varepsilon) \cdot A(a_t^{(i)})\big)\right] - \beta \cdot D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}}) \]

梯度流动：每个 token 的梯度 = \(\nabla_\theta \log \pi_\theta(a_t|s_t)\) 乘以组合优势 \(A(a_t^{(i)})\)。宏观优势提供全局方向，微观优势提供局部修正。

3.4 GAGPO：进一步引入 TD/GAE 时序优势 [8]

Generalized Advantage Grouped Policy Optimization（GAGPO）在 GiGPO 基础上引入非参数化的分组值代理：

\[ \bar{V}(s) = \frac{1}{|\mathcal{G}(s)|}\sum_{(j,u) \in \mathcal{G}(s)} \hat{R}_u^{(j)} \] \[ \delta_t^{(i)} = r_t^{(i)} + \gamma \bar{V}(s_{t+1}^{(i)}) - \bar{V}(s_t^{(i)}) \] \[ \hat{A}_t^{(i)} = \sum_{l=0}^{T_i - t} (\gamma\lambda)^l \delta_{t+l}^{(i)} \]

这实现了无 critic 网络的 GAE——通过分组统计量替代值函数网络。

实验结果：GAGPO 在 ALFWorld 上达到 93.5%（vs GiGPO 88.1%），WebShop 上达到 88.6 分（vs GiGPO 79.8）[8]。

4. 过程奖励作为可微分信号

4.1 AgentPRM：Actor-Critic 框架 [9]

过程奖励模型（Process Reward Model, PRM）为每个中间步骤提供奖励信号。关键问题是如何将其整合到策略梯度中保持可微性。

PRM 定义为 Q 函数

\[ Q^\pi(s_t, a_t) = \mathbb{E}_\pi\!\left[\sum_{k=t}^{T} \gamma^{k-t} r(s_k, a_k) \;\middle|\; s_t, a_t\right] \]

PRM 训练损失（软二值交叉熵）

\[ \mathcal{L}(Q_\phi) = -\mathbb{E}_{(s,a,\hat{Q}) \sim \mathcal{D}}\!\left[\hat{Q} \log Q_\phi(s,a) + (1-\hat{Q})\log(1-Q_\phi(s,a))\right] \]

策略优化目标

\[ \pi_i = \arg\max_\pi \mathbb{E}_{s \sim \mathcal{D},\; a \sim \pi_\theta(\cdot|s)}\!\left[Q_\phi(s,a)\right] - \beta \cdot D_{\text{KL}}\!\left[\pi_\theta(\cdot|s) \| \pi^{i-1}(\cdot|s)\right] \]

实验结果 [9]：3B 模型在 ALFWorld 上达到 88.1% 成功率，超越 GPT-4o（76.1%）。Best-of-N（N=16）推理达到 91.0%。

4.2 Q-RM：Token 级奖励的判别式策略优化 [10]

Q-RM 方法将判别式策略的 log-概率直接映射为优势函数：

最优判别策略与优势的关系

\[ \beta \log \phi^*(s_t, a_t) = Q^*(s_t, a_t) - V^*(s_t) = A^*(s_t, a_t) \]

Token 级奖励推导

\[ r(s_t, a_t) = \beta \log \phi^*(s_t, a_t) + V^*(s_t) - V^*(s_{t+1}) \]

与 PPO 集成

\[ A_t = Z_{\text{std}}^*(s_t, a_t) - \beta \cdot \text{KL}(s_t) - V_\psi(s_t) \]

其中 \(Z_{\text{std}}^*\) 是标准化后的 logit。

实验结果 [10]：GSM8K 上 PPO+Q-RM 达到 72.23% Pass@1（比 DPO-RM 基线 +5.85 点），收敛速度比 ORM 快 12 倍，比 step-level PRM 快 11 倍。

4.3 FRPO：Future-KL 修正的过程奖励 [11]

Future-KL Regularized Policy Optimization 将 token 级 f-散度正则化整合到策略梯度中：

通用正则化目标

\[ Q_f(\theta) = \mathbb{E}_x\!\left[\ell\!\left(\mathbb{E}_{a \sim \pi_\theta} r(x,a)\right)\right] - \beta \mathbb{E}_x \mathbb{E}_{a \sim \pi_\theta}\!\left[\sum_{i=1}^{T} f(u_i)\right] \]

其中 \(u_i = \pi_{\text{ref}}(a_i|s_i) / \pi_\theta(a_i|s_i)\)，\(f\) 为凸生成函数。

策略梯度定理（Theorem 4.1）

\[ \nabla_\theta Q_f(\theta) = \mathbb{E}_x \mathbb{E}_{a \sim \pi_\theta}\!\left[\sum_{i=1}^{T} w_i \cdot \nabla_\theta \log \pi_\theta(a_i|s_i)\right] \] \[ w_i = \text{sg}\!\left(A_i - \beta \cdot \text{reg}_i\right) \] \[ \text{reg}_i = \sum_{j \ge i}\!\left[f(u_j) - f'(u_i) u_i\right] \]

关键：\(\text{reg}_i\) 包含未来所有 token 的 KL 贡献，实现了前瞻性正则化。

FRPO 优势（Reverse KL 特化）

\[ \hat{A}_t^{\text{FRPO}} = \text{sg}\!\left(\hat{A}_t^{\text{GRPO}} - \beta \sum_{j=t}^{T_i} \log\frac{\pi_\theta(a_j|s_j)}{\pi_{\text{ref}}(a_j|s_j)}\right) \]

每个 token 的梯度权重不仅考虑当前优势，还减去从当前位置到序列末尾的累积 KL 散度。这防止了策略在序列后半段过度偏离参考策略。

实验结果 [11]：Qwen3-30B-A3B 上，FRPO 在 AIME25 达到 45.23%（vs GRPO KL-loss 的 22.04%），绝对提升超过 20 个百分点。

4.4 MT-GRPO：多轮信用分配 [12]

Multi-Turn GRPO 为中间回合分配独立的优势信号：

K 轮 MT-GRPO 优势

\[ A_{i,k}^{\text{MT-GRPO}} = \sum_{l=k}^{K-1} \alpha^{l-k} \cdot A_{i,l}^I + \alpha^{K-k} \cdot A_i^O \]

其中 \(A^I\) 为中间奖励优势，\(A^O\) 为结果奖励优势，\(\alpha\) 控制衰减。

5. KL 散度惩罚实现

5.1 三种 KL 估计器及其梯度等价性 [13]

在 RLHF/Agent RL 中，KL 散度惩罚有三种常见实现方式，它们的梯度性质截然不同：

KL 估计器定义

设 \(\delta(x) = \pi_\theta(x) / \pi_{\text{ref}}(x)\)：

\[ k_1(x) = -\log \delta(x) = \log \frac{\pi_{\text{ref}}(x)}{\pi_\theta(x)} \quad \text{（无偏，高方差）} \] \[ k_2(x) = \frac{1}{2}(\log \delta(x))^2 \quad \text{（有偏，低方差）} \] \[ k_3(x) = \delta(x) - 1 - \log \delta(x) \quad \text{（一阶近似，有问题）} \]

两种实现风格

  • "kn in reward"（系数 detach）：\(\mathcal{J} = \mathbb{E}[k_n \cdot \nabla_\theta \log \pi_\theta]\) — KL 项作为奖励的一部分，不对其求导
  • "kn as loss"（梯度穿透）：\(\mathcal{J} = \mathbb{E}[k_n(\pi_\theta, \pi_{\text{ref}})]\) — 直接对 KL 项求导

核心定理 [13]

在 on-policy 采样下：

  • "k₁ in reward" 与 "k₂ as loss" 梯度等价——两者都恢复真实的 reverse KL 梯度：\(-\log(\pi_\theta/\pi_{\text{ref}}) \cdot \nabla_\theta \log \pi_\theta\)
  • "k₁ as loss" 的梯度期望为零——完全无效！因为 \(\mathbb{E}_{\pi_\theta}[\nabla_\theta \log \pi_\theta] = 0\)
  • k₃ 是一阶 Taylor 展开：\(-\log\delta \approx 1 - \delta + O((\delta-1)^2)\)，在尾部有病态不对称性

5.2 Token 级 vs 序列级 KL

Token 级 KL（REINFORCE++ 风格）[14]

\[ r(s_t, a_t) = \mathbb{I}(s_t = [\text{EOS}]) \cdot r(x,y) - \beta \cdot \text{KL}(t) \] \[ \text{KL}(t) = \log \frac{\pi_{\theta_{\text{old}}}^{\text{RL}}(a_t|s_t)}{\pi^{\text{SFT}}(a_t|s_t)} \] \[ A_t(s_t, a_t) = r(x,y) - \beta \sum_{i=t}^{T} \text{KL}(i) \]

每个 token 的优势包含从当前位置到序列末尾的累积 KL 惩罚。

序列级 KL 分解

序列级 KL 通过链式法则分解为 token 级之和 [15]：

\[ D_{\text{KL}}^{\text{seq}} = \sum_{t=1}^{T} \mathbb{E}_{c_t \sim d_t^{\pi_{\text{roll}}}}\!\left[D_{\text{KL}}(c_t)\right] \]

关键警告 [15]

不存在函数 \(f\) 使得 \(D_{\text{KL}}^{\text{tok,max}} \le f(D_{\text{KL}}^{\text{seq}})\) 对所有策略对成立。即：控制平均散度不能保证控制最大 token 级散度。这是 PPO 裁剪在长序列中失效的根本原因。

5.3 自适应 KL 调度

SAFE：PID 控制驱动的自适应阈值 [16]

\[ \tau_t = \left(\tau_{\text{base}} + K_p \cdot e_t + K_i \cdot \sum e_k + K_d \cdot (e_t - e_{t-1})\right) \cdot \varphi_t \]

控制误差追踪奖励改善速率：\(e_t = \Delta\text{EMA}(r_t) - v_{\text{target}}\)（\(v_{\text{target}} = 0.001\)）

阈值裁剪到 \([0.1, 0.6]\)，并由阶段乘子 \(\varphi_t\) 调制（warmup: 1.5, climbing: 1.2, plateau: 0.8, convergence: 1.0）

实验结果 [16]：SAFE 比 PPO 平均奖励提升 +5.15%（0.7249 vs 0.6894），奖励标准差降低 2.8 倍，KL 波动降低 42%，零次奖励崩溃（PPO 有 2 次）。

Token vs SeqToken 级提供更细粒度的正则化信号
自适应调度PID 控制比固定 \(\beta\) 稳定性提升 42% [16]

6. 长序列 Agent RL 中的梯度问题

6.1 梯度方差爆炸 [17]

长序列 LLM-RL 的核心挑战是梯度方差随序列长度爆炸，导致训练崩溃。

因果梯度估计器的方差

\[ \mathbb{V}[\tilde{g}_c(\tau)] = \mathbb{E}_\tau\!\left[\|\tilde{g}_c(\tau)\|^2\right] - \|\nabla_\theta \mathcal{J}(\theta)\|^2 \]

因果估计器分解为：

\[ \tilde{g}_c(\tau) = \sum_t s_t (G_t - B_t) \]

其中 \(s_t = \nabla_\theta \log \pi_\theta(a_t|s_t)\) 是 score function，\(G_t\) 是从 \(t\) 开始的回报，\(B_t\) 是基线。

最优 Token 基线（OTB）[17]

通过最小化每步方差推导时间依赖的最优基线：

\[ \min_{B_t} \mathcal{J}(B_t) = \mathbb{E}\!\left[W_t (G_t - B_t)^2\right] \]

其中 \(W_t \equiv \sum_{j=1}^{t} \|s_j\|^2\) 是"已实现能量"——累积梯度范数。

最优解：

\[ B_t^*(x) = \frac{\mathbb{E}[G_t \cdot W_t]}{\mathbb{E}[W_t]} \]

与全局最优基线 \(B_{\text{global}}^* = \frac{\mathbb{E}[R(\tau) \cdot \|S(\tau)\|^2]}{\mathbb{E}[\|S(\tau)\|^2]}\) 相比，OTB 通过动态适应实现严格更低的方差。

Logit-Gradient 代理（避免额外反向传播）

\[ \hat{w}_t = \|\delta_t\|^2 = 1 - 2\pi_\theta(y_t|x, y_{其中 \(\delta_t = e_{y_t} - \pi_t\) 是 logit 空间梯度。这允许仅通过前向传播估计梯度范数。

实验结果 [17]：OTB 在 AIME25 达到 30.31%（vs 全局基线 30.10%）；关键优势是用 N=4 样本匹配 N=32 的性能（66% token 节省）。

6.2 Retrieved Token Masking（Search-R1）[18]

Search-R1 引入检索 token 掩码机制，解决环境返回内容对梯度的干扰：

掩码机制

  • 将 <begin_of_documents>...<end_of_documents> 标记的检索内容在训练时掩码
  • 梯度仅流经模型自身生成的 token，不流经环境提供的内容
  • 防止反向传播试图优化固定的环境输出表示——这会造成计算浪费和潜在不稳定

6.3 GRPO 崩溃与 LLDS 正则化 [19]

GRPO 在 Agent 搜索任务中存在系统性崩溃——Lazy Likelihood Displacement（LLD）死亡螺旋：

三阶段崩溃轨迹

  1. 早期停滞（Phase I）：似然几乎不变，尽管奖励在增加
  2. 稳定衰减（Phase II, steps 60-120）：似然缓慢下降，奖励继续上升
  3. 加速崩溃（Phase III, >step 120）：似然急剧下降，梯度幅度急增，触发崩溃

LLD 定义

\[ \sum_t \Delta_t(x, y_t) \le \varepsilon \]

当正确回答的总对数似然变化为非正时，发生 LLD。

LLDS 正则化

\[ \mathcal{L}_{\text{LLDS}} = \sum_{i,t} \mathbb{1}\!\left[\sum_k \Delta_{i,t,k} > 0\right] \cdot \sum_k \max(0, \Delta_{i,t,k}) \] \[ \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{GRPO}} + \lambda \cdot \mathcal{L}_{\text{LLDS}} \]

正则化仅在总动作似然下降时激活，仅惩罚似然降低的 token。

实验结果 [19]：

  • Qwen2.5-3B：+45.2% 相对提升（0.312 → 0.440 平均 EM）
  • Qwen2.5-7B：+37.1% 相对提升（0.350 → 0.480）
  • Vanilla GRPO 在 300 步内崩溃，LLDS 保持稳定奖励增长
  • LLDS 比 Tree-GRPO 高 4-10%，且仅使用结果奖励

6.4 Trust Region Masking [15]

针对长序列中 PPO 裁剪失效的问题，Trust Region Masking 提出序列级掩码：

\[ \mathcal{L}_{\text{masked}}(\pi_\theta) = \mathbb{E}_{\pi_{\text{roll}}}\!\left[M(x,y) \cdot A(x,y) \cdot \sum_t \rho_t\right] \] \[ M(x,y) = \mathbb{I}\!\left[\max_t D_{\text{KL}}(c_t) \le \delta\right] \]

阈值 \(\delta\) 不依赖序列长度 \(T\)。被拒绝的序列贡献零梯度。

关键理论结果 [15]：在 \(T=4096, \delta=10^{-4}\) 时，统一误差界为 4.1（经典界为 1677），409 倍改进。

7. 多智能体可微分损失

7.1 MAGRPO：多智能体组相对策略优化 [20]

MAGRPO 将 LLM 协作建模为合作式多智能体强化学习（MARL）问题。

Agent \(i\) 的损失函数

\[ J(\theta_i) = \mathbb{E}\!\left[\frac{1}{|B|} \cdot \frac{1}{|\mathcal{G}|} \sum A_t^{(g)} \cdot \log \pi_{\theta_i}(a_{i,t}^{(g)} | h_{i,t}^{\mathcal{G}})\right] \]

组相对优势

\[ A_t^{(g)} = R_t^{(g)} - \frac{1}{G}\sum_\tau R_\tau^{(g)} \]

独立参数更新

\[ \theta_i \leftarrow \theta_i + \alpha \nabla_{\theta_i} J(\theta_i) \]
关键设计选择 [20]：
  • MAGRPO 不使用重要性采样和 epsilon 裁剪——因为它是 on-policy 的
  • KL 散度权重设为 0
  • 无显式通信损失项——协调通过对齐的联合奖励自然涌现
  • 每个 agent 维护独立参数 \(\theta_i\)，但接收相同的组相对优势信号

梯度性质

由于使用联合奖励但独立参数，每个 agent 的梯度方向由其自身的 \(\nabla_{\theta_i} \log \pi_{\theta_i}\) 决定，但幅度由联合优势 \(A_t^{(g)}\) 缩放。这实现了中心化训练、去中心化执行（CTDE）范式。

实验结果 [20]：在编码协作任务上，MAGRPO 使 agent 通过有效合作生成高质量回复，相比单 agent 基线显著提升。

7.2 MAGPO：自回归联合策略 [21]

Multi-Agent Guided Policy Optimization 使用自回归联合策略实现可扩展的协调探索：

  • 联合策略 \(\pi_{\text{joint}}(a_1, a_2, \ldots | s)\) 以自回归方式建模
  • 显式对齐联合策略与去中心化策略，确保部分可观测下的可部署性
  • 梯度通过联合策略的 log-prob 流向各 agent 参数
