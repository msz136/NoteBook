2.1 3D 占据预测：BEVOccPvb

congq_sensebot_perception/mmdet3d/models/fusion_models/bevoccpvb.py

基础概念：LSS（Lift-Splat-Shoot）视角变换

相机图像是二维的，但规划需要三维的 BEV（鸟瞰图）表示。LSS 的核心思想是：

  1. Lift（提升）：对每个像素预测一个深度分布，将 2D 特征"提升"到 3D 视锥体（Frustum）
  2. Splat（泼溅）：将 3D 视锥体中的特征投影到 BEV 平面，通过 Pillar Pooling 聚合
  3. Shoot（射击）：在 BEV 特征上运行下游任务头

数学上，像素 \((u, v)\) 在深度 \(d\) 处的三维坐标为：

\[ \mathbf{p}_{3D} = d \cdot K^{-1} [u, v, 1]^T \]

其中 \(K\) 是相机内参矩阵。

    # 3. 将视锥体特征 Splat 到 BEV 平面

    # ── LiDAR 分支 ────────────────────────────────────────────

    voxels = voxelize(points, voxel_size=[0.05, 0.05, 0.2])
    bev_lidar = sparse_encoder(voxels) # (B, 128, H_bev, W_bev)

    # ── 融合 ──────────────────────────────────────────────────
    bev_fused = conv_fuser(cat([bev_lidar, bev_img], dim=1))  # (B, 512, H, W)

    # ── 占据预测头 ────────────────────────────────────────────
    occ_logits = occ_head(bev_fused)   # (B, X, Y, Z, num_classes)
    loss = cross_entropy(occ_logits, gt_occ)
    return occ_logits, loss

2.2 动态目标检测：SPIDER (SPetr3D)

congq_sensebot_spider/projects/mmdet3d_plugin/

基础概念：PETR（Position Embedding Transformer）

PETR 是一种无需 NMS 的端到端 3D 检测器。核心思想是将三维位置信息编码进图像特征的位置嵌入（Position Embedding），让 Transformer 解码器直接在 3D 空间中查询目标。

与 DETR 的区别：DETR 的位置嵌入是 2D 的，PETR 将相机射线的 3D 坐标编码进去，使得 Transformer 能直接感知三维空间。

SPetr3D 架构（流式版本）

输入：单目相机图像 (B, 1, 3, 576, 1024) [120° FOV 中心相机] ResNet-34 骨干 输出: (B, 512, H/32, W/32) ↓ PVB 位置编码 (PVBPositionEmbeddingSine) 深度 bins: 64 | LID (对数逆深度): True 位置范围: [-110, -60, -10, 210, 60, 10] 将每个像素的 3D 射线坐标编码为 256 维嵌入 ↓ 图像特征 + 3D 位置嵌入: (B, 256, H', W') ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ StreamPETRHeadLight (流式检测头) 查询数量: 256 | 记忆长度: 512 (跨帧) 传播检测数: 128 | Top-K 提案: 128 ↓ SPETRTransformer 解码器 (4层) 每层: 自注意力 → 交叉注意力(查询↔图像特征) → FFN 注意力头: 8 | 嵌入维度: 256 | FFN: 2048 ↓ 检测头输出: 分类: (B, 256, 7) [7类: 车/卡车/公交/特种/三轮/自行车/行人] 回归: (B, 256, 10) [x,y,z,w,l,h,rot,vx,vy,vz] ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 损失函数: 分类: FocalLoss (γ=2.0, α=0.25, weight=2.0) 回归: L1Loss (weight=0.25) IoU: RotatedIoU3DLoss (weight=0.1) 匹配: HungarianAssigner3D (二分图匹配)

    memory_queue: Tensor  # (B, memory_len=512, 256)

def forward(img, img_metas, prev_memory=None):
    # ── 特征提取 ──────────────────────────────────────────────
    img_feat = resnet34(img)           # (B, 512, H', W')

    # ── 3D 位置编码 ───────────────────────────────────────────
    # 将每个像素对应的 3D 射线坐标编码为位置嵌入
    pos_embed = pvb_position_encoding(img_feat, intrinsics, extrinsics)
    # pos_embed: (B, 256, H', W')  包含深度 bins 的 3D 信息

    img_feat = img_feat + pos_embed    # 特征 + 3D 位置

    # ── 流式记忆更新 ──────────────────────────────────────────
    if prev_memory is not None:
        # 将上一帧的检测结果传播到当前帧
        propagated = propagate_detections(prev_memory, ego_motion)
        queries = cat([learned_queries, propagated], dim=1)  # (B, 256+128, 256)
    else:
        queries = learned_queries      # (B, 256, 256)

    # ── Transformer 解码 ──────────────────────────────────────
    for layer in transformer_decoder:  # 4 层
        # 自注意力：查询之间互相交互
        queries = self_attention(queries, queries)
        # 交叉注意力：查询从图像特征中提取信息
        queries = cross_attention(queries, img_feat.flatten(2).T)
        queries = ffn(queries)

    # ── 预测头 ────────────────────────────────────────────────
    cls_logits = cls_head(queries)     # (B, 256, 7)
    bbox_pred  = reg_head(queries)     # (B, 256, 10)

    # ── 匈牙利匹配 + 损失 ─────────────────────────────────────
    indices = hungarian_assign(cls_logits, bbox_pred, gt_bboxes, gt_labels)
    loss_cls  = focal_loss(cls_logits[indices], gt_labels[indices])
    loss_bbox = l1_loss(bbox_pred[indices], gt_bboxes[indices])
    loss_iou  = rotated_iou_loss(bbox_pred[indices], gt_bboxes[indices])

    # 更新记忆队列（供下一帧使用）
    new_memory = update_memory(queries, memory_queue)
    return cls_logits, bbox_pred, new_memory
流式（Streaming）的关键：memory_queue 保存了过去帧的检测查询（512 个 token）���当前帧的 128 个传播检测从中选取 Top-K 高置信度目标，使模型能跨帧追踪目标而无需显式跟踪器。

3.1 基础概念：DPT（Dense Prediction Transformer）

DPT 是将 ViT（Vision Transformer）用于密集预测任务（如深���估计、语义分割）的标准架构。ViT 将图像切成 patch 序列处理，DPT 通过多尺度特征重组将这些 patch 特征重新组装成空间分辨率逐渐升高的特征图，最终输出与输入同分辨率的预测。

class DepthAnything3Net(nn.Module):
    def forward(x, extrinsics=None, intrinsics=None):
        B, N, C, H, W = x.shape

        # ── 相机位姿编码（可选）────────────────────────────────
        cam_token = None
        if cam_enc is not None and extrinsics is not None:
            # 将外参+内参编码为 token，注入骨干网络
            cam_token = cam_enc(extrinsics, intrinsics, (H, W))
            # cam_token: (B, N, 1024)

        # ── DinoV2 骨干 ────────────────────────────────────────
        # 将 N 个视角合并到 batch 维度
        x_flat = x.reshape(B*N, C, H, W)
        # 提取 4 个中间层特征 + 最后一层的 camera_token
        feats = dinov2.get_intermediate_layers(
            x_flat, layers=[6, 12, 18, 24],
            cam_token=cam_token
        )
        # feats[-1] = (image_patches, camera_token)
        # image_patches: (B*N, 1369, 1024)
        # camera_token:  (B*N, 1024)

        # ── DualDPT 深度预测 ───────────────────────────────────
        output = dual_dpt(feats, H, W)
        # output["depth"]:      (B*N, 1, H, W)
        # output["depth_conf"]: (B*N, 1, H, W)
        # output["ray"]:        (B*N, 6, H, W)

        # ── 相机位姿解码 ───────────────────────────────────────
        camera_token = feats[-1][1]    # (B*N, 1024)
        pose_enc = cam_dec(camera_token)  # (B*N, 9)
        # 将 9 维位姿编码转换为 4×4 外参矩阵和 3×3 内参矩阵
        c2w, ixt = pose_encoding_to_extri_intri(pose_enc, (H, W))

        # ── 天空处理 ───────────────────────────────────────────
        sky_mask = output.get("sky", None)
        if sky_mask is not None:
            # 天空区域深度设为最大值
            output["depth"][sky_mask > 0.5] = max_depth

        output["extrinsics"] = c2w
        output["intrinsics"] = ixt
        return output

3.3 DA3 在机器人控制中的应用

方案 A：动作回归头

class DA3ActionRegression(nn.Module):
    """冻结 DA3 骨干，接动作回归头直接预测机器人动作"""
    def __init__(self):
        self.backbone = DA3Net(freeze=True)   # 冻结 DinoV2
        # 复用 CameraDec 的 MLP 权重作为特征提取器
        self.feat_mlp = Sequential(
            Linear(feat_dim, feat_dim), ReLU(),
            Linear(feat_dim, feat_dim), ReLU()
        )
        self.state_enc = Sequential(
            Linear(state_dim=72, feat_dim), ReLU(),
            Linear(feat_dim, feat_dim)
        )
        self.action_head = Sequential(
            Linear(feat_dim*2, feat_dim), ReLU(),
            Linear(feat_dim, feat_dim), ReLU(),
            Linear(feat_dim, horizon*action_dim)  # horizon=50, action_dim=72
        )

    def forward(image, state):
        # image: (B, V, 3, 518, 518)  V=视角数
        feats = backbone(image)
        cam_token = feats[-1][1]           # (B*V, feat_dim)
        cam_token = cam_token.mean(dim=0)  # 多视角平均池化: (B, feat_dim)

        feat = feat_mlp(cam_token)         # (B, feat_dim)
        state_feat = state_enc(state)      # (B, feat_dim)

        combined = cat([feat, state_feat]) # (B, feat_dim*2)
        actions = action_head(combined)    # (B, horizon*action_dim)
        return actions.reshape(B, horizon, action_dim)

方案 B：扩散动作头（Diffusion Action Head）

class DiffusionActionHead(nn.Module):
    """DA3 特征 + Transformer 解码器 + DDPM 扩散过程"""
    # hidden_dim=512, n_heads=8, n_layers=6
    # horizon=16, action_dim=7 (xyz + rot6d + gripper)
    # timesteps=100 (训练), 10 (推理 DDIM)

    def forward(noisy_action, timestep, image_feat, state):
        # noisy_action: (B, 16, 7)  加噪后的动作序列
        # image_feat:   (B, N_patches, feat_dim)  DA3 patch 特征

        # 图像特征投影为 memory
        memory = Linear(feat_dim → 512)(image_feat)  # (B, N_patches, 512)

        # 状态编码为额外 token
        state_token = state_mlp(state).unsqueeze(1)  # (B, 1, 512)
        memory = cat([memory, state_token], dim=1)   # (B, N_patches+1, 512)

        # 时间步嵌入 (正弦编码 + MLP)
        t_emb = sinusoidal_emb(timestep)             # (B, 512)

        # 动作 token 投影 + 位置嵌入 + 时间嵌入
        action_tokens = Linear(7 → 512)(noisy_action)  # (B, 16, 512)
        action_tokens = action_tokens + pos_emb + t_emb[:, None, :]

        # Transformer 解码器：动作 token 交叉注意力到图像 memory
        for layer in transformer_decoder:  # 6 层
            action_tokens = self_attn(action_tokens)
            action_tokens = cross_attn(action_tokens, memory)
            action_tokens = ffn(action_tokens)

        # 预测噪声

4.1 基础概念：Flow Matching（流匹配）

Flow Matching 是一种生成模型训练方法，比扩散模型更简单高效。核心思想：学习一个速度场 \(v_\theta(x_t, t)\)，使得沿着这个速度场积分可以将噪声分布变换为目标分布。

训练时，在噪声 \(x_0 \sim \mathcal{N}(0, I)\) 和目标 \(x_1\)（真实轨迹）之间做线性插值：

\[ x_t = (1-t) x_0 + t x_1, \quad t \in [0, 1] \]

目标速度场为：

\[ v^* = x_1 - x_0 \]

训练损失：

\[ \mathcal{L}_{FM} = \mathbb{E}_{t, x_0, x_1} \| v_\theta(x_t, t) - (x_1 - x_0) \|^2 \]

推理时，从噪声出发，用欧拉积分沿速度场走到目标：

\[ x_{t+\Delta t} = x_t + v_\theta(x_t, t) \cdot \Delta t \]

class TrajectoryFlowDecoder(nn.Module):
    # 学习速度场 v_θ(context, x_t, t)

    def velocity_field(context, traj_t, t):
        """预测当前时刻的速度"""
        # context: (B, 128)  融合上下文
        # traj_t:  (B, M, T, 2)  当前插值位置的轨迹
        # t:       (B,)  插值时间 ∈ [0, 1]

        # 时间嵌入
        t_emb = time_mlp(t.unsqueeze(-1))  # (B, 64)

        # 展平轨迹
        traj_flat = traj_t.reshape(B, -1)  # (B, M*T*2)

        # 拼接所有输入
        x = cat([context, traj_flat, t_emb], dim=-1)

        # MLP 预测速度
        velocity = velocity_head(x)        # (B, M*T*2)
        return velocity.reshape(B, M, T, 2)

    def sample(context, num_steps=10, noise_scale=1.0):
        """从噪声出发，欧拉积分到目标轨迹"""
        # 初始化为高斯噪声
        traj = randn(B, num_modes, future_steps, 2) * noise_scale

        dt = 1.0 / num_steps
        for step in range(num_steps):
            t = step * dt * ones(B)
            v = velocity_field(context, traj, t)
            traj = traj + v * dt  # 欧拉积分

        return traj  # (B, num_modes, T, 2)

5.1 基础概念：Rectified Flow（整流流）

Rectified Flow 是扩散模型的一种改进。传统扩散模型学习预测噪声 \(\epsilon\)，而 Rectified Flow 学习预测速度（velocity）\(v = \epsilon - x_0\)，即从数据到噪声的方向向量。

插值路径是直线（而非扩散模型的曲线），因此推理时步数更少：

\[ x_t = (1-t) x_0 + t \epsilon, \quad v^* = \epsilon - x_0 \]

训练目标：

\[ \mathcal{L} = \mathbb{E}_{t, x_0, \epsilon} \| v_\theta(x_t, t) - (\epsilon - x_0) \|^2 \]

        for block in dit_blocks:

class LatentActionModel(nn.Module):
    """从视频帧对中提取 32 维潜在动作"""
    # patch_size=16, model_dim=1024, latent_dim=32
    # enc_blocks=24, dec_blocks=24, num_heads=16

    def forward(frame_pair):
        # frame_pair: (B, 2, H, W, 3)  相邻两帧

        # ── Patchify ──────────────────────────────────────────
        patches = patchify(frame_pair, patch_size=16)
        # patches: (B, 2, N_patches, 768)  [768 = 3×16²]

        # ── 动作提示 token ────────────────────────────────────
        action_prompt = learnable_param(1, 1, 1, 768)  # 可学习参数
        action_prompt = action_prompt.expand(B, 1, 1, 768)

        # ── 编码器 (SpatioTemporalTransformer) ────────────────
        tokens = cat([action_prompt, patches], dim=2)
        # tokens: (B, 2, N_patches+1, 768)
        encoded = encoder(tokens)  # 24层 Transformer, 1024维, 16头

        # ── VAE 瓶颈 ──────────────────────────────────────────
        action_token = encoded[:, :, 0, :]  # 取动作提示 token
        z_params = Linear(1024 → 64)(action_token)  # 64 = 32*2
        z_mu, z_logvar = split(z_params, 32, dim=-1)

        # 重参数化采样
        z = z_mu + exp(0.5 * z_logvar) * randn_like(z_mu)
        # z: (B, T-1, 1, 32)  32维潜在动作

        # ── 解码器 (SpatioTransformer) ────────────────────────
        z_expanded = Linear(32 → 1024)(z)
        decoded = decoder(cat([z_expanded, encoded[:, :, 1:]], dim=2))
        recon = unpatchify(decoded)  # 重建帧

        # 损失: 重建 + KL 散度
        loss_recon = mse(recon, frame_pair[:, 1:])
        loss_kl = -0.5 * mean(1 + z_logvar - z_mu² - exp(z_logvar))
        return z, loss_recon + beta * loss_kl

        v_fake = student_model(x, sigma[step], timestep_scale=1.0)
        x = x + v_fake * dt  # 欧拉积分

    # 教师提供 score function (1步)
    v_real = teacher_model(batch["video_latent"], sigma[0])

    # 对抗损失 + Score Matching 损失
    loss_gan = discriminator_loss(x, batch["video_latent"])
    loss_score = mse(v_fake, v_real.detach())
    loss = loss_gan + loss_score
    loss.backward()

class Qwen2_5_VLForConditionalGenerationForJanusVLN:
    """
    双隐式记忆 = 语义记忆 (LLM KV 缓存) + 空间记忆 (VGGT KV 缓存)
    """
    # λ = 0.2: VGGT 特征融合权重
    # start_size=8, recent_size=48: 滑动窗口 KV 缓存

    def forward(input_ids, pixel_values, past_key_values=None,
                past_key_values_vggt=None):

        # ── 视觉编码 ──────────────────────────────────────────
        # 通过 Qwen2.5-VL 视觉编码器提取视觉 token
        vis_tokens = vision_encoder(pixel_values)  # (B, N_vis, 3584)

        # ── VGGT 空间记忆 (几何一致特征) ─────────────────────
        # VGGT 聚合器处理当前帧，利用历史 KV 缓存
        vggt_out, new_vggt_kv = vggt_aggregator(
            vis_tokens,
            past_key_values=past_key_values_vggt,  # 历史空间记忆
            kv_cache=StartRecentKVCache(start=8, recent=48)
        )
        # vggt_out: (B, N_vis, 2048)  几何感知特征

        # ── 特征融合 ──────────────────────────────────────────
        # 将 VGGT 特征投影到 LLM 维度
        vggt_proj = vggt_merger(vggt_out)  # (B, N_vis, 8192)

        # 加权融合: 视觉特征 + λ × VGGT 特征
        # λ=0.2: 保留主要视觉信息，用 VGGT 补充几何一致性
        fused_vis = vis_tokens_projected + 0.2 * vggt_proj

        # ── 嵌入层 ────────────────────────────────────────────
        text_emb = embed_tokens(input_ids)  # (B, L, 8192)
        # 将融合后的视觉 token 插入文本序列
        inputs_embeds = merge_visual_tokens(text_emb, fused_vis)

        # ── LLM 前向 (语义记忆) ───────────────────────────────
        # past_key_values 是 LLM 的 KV 缓存 = 语义记忆
        outputs, new_kv = llm(
            inputs_embeds=inputs_embeds,
            past_key_values=past_key_values,  # 历史语义记忆
            position_ids=compute_3d_rope_pos(inputs_embeds)
        )

        # ── 动作预测 ──────────────────────────────────────────
        logits = lm_head(outputs.last_hidden_state)  # (B, L, 152064)
        # 取最后一个 token 的 logits 预测下一个动作
        action_logits = logits[:, -1, :]
        action = argmax(action_logits)  # STOP/FORWARD/LEFT/RIGHT

        return action, new_kv, new_vggt_kv
双隐式记忆的本质：
  • 语义记忆 = LLM 的 KV 缓存，存储历史观测的语义理解（"我看到了什么"）
  • 空间记忆 = VGGT 的 KV 缓存，存储历史帧的几何一致特征（"空间结构是什么"）
  • 滑动窗口策略（保留最初 8 帧 + 最近 48 帧）平衡了长期记忆和短期记忆

class StreamVLNModel:
    """
    SlowFast 上下文:
      Fast 路径: 当前帧特征 (高频更新)
      Slow 路径: 历史记忆特征 (低频更新, 压缩存储)
    """
    # num_history=8: 保留最近 8 帧历史
    # 2D pooling stride=2: 空间压缩 (729→196 tokens/帧)

    def encode_rgbd(images, depths, poses, intrinsics, time_ids):
        # images: (B, num_view, C, H, W)
        # num_view 包含当前帧 + 历史帧

        # ── 视觉特征提取 ──────────────────────────────────────
        all_feats = vision_tower(images)  # (B*num_view, 729, feat_dim)
        # 729 = 27×27 patches (CLIP 标准)

        # ── 空间压缩 (Slow 路径的关键) ────────────────────────
        # 2D 池化将每帧 token 数从 729 压缩到 ~196
        all_feats = pool2d(all_feats.reshape(..., 27, 27, feat_dim),
                           stride=2)  # → (B*num_view, 14, 14, feat_dim)
        all_feats = all_feats.reshape(B, num_view, -1, feat_dim)
        # all_feats: (B, num_view, 196, feat_dim)

        # ── 分离历史帧和当前帧 ────────────────────────────────
        history_idx = time_ids[:-1]  # 历史帧索引
        current_idx = time_ids[-1:]  # 当前帧索引

        # Fast 路径: 当前帧 (完整特征)
        current_feats = all_feats[:, current_idx]  # (B, 1, 196, feat_dim)

        # Slow 路径: 历史帧聚合 (压缩记忆)
        history_feats = all_feats[:, history_idx]  # (B, H, 196, feat_dim)
        memory_feats  = history_feats.mean(dim=1)  # (B, 196, feat_dim) 时间平均

        # ── 投影到 LLM 维度 ──────────────────────���────────────
        current_tokens = mm_projector(current_feats.flatten(1, 2))
        memory_tokens  = mm_projector(memory_feats)

        return current_tokens, memory_tokens

    def forward(input_ids, images, ...):
        current_tokens, memory_tokens = encode_rgbd(images, ...)

        # 构建输入序列: [文本 | 记忆 token | 当前帧 token]
        # 记忆 token 代表 Slow 路径 (历史压缩)
        # 当前帧 token 代表 Fast 路径 (实时观测)
        inputs_embeds = interleave_tokens(
            text_emb, memory_tokens, current_tokens
        )

        # LLM 生成动作
        outputs = llm(inputs_embeds=inputs_embeds)
        action = decode_action(outputs)  # STOP/FORWARD/LEFT/RIGHT
        return action

class OpenTrackVLA(nn.Module):
    """
    Qwen3-0.6B + 双视觉编码器 (DINO + SiGLIP) + 航点预测头
    输出: 8个未来航点 (x, y, θ)
    """
    # LLM: Qwen3-0.6B, hidden_size=1024
    # 视觉: DINO + SiGLIP, feat_dim=1408
    # 航点数: n_waypoints=8, action_dims=3 (vx, vy, wz)

    def forward(images, text_instruction, angle, bbox=None):
        # images: (B, V, 3, H, W)  多视角图像
        # angle:  (B, 2)  当前朝向 (sin, cos)
        # bbox:   (B, 4)  目标物体边界框 (可选)

        # ── 视觉特征提取 ──────────────────────────────────────
        # 粗粒度特征 (DINO): 全局语义
        coarse_feats = dino_encoder(images)   # (B, N_coarse, 1408)
        # 细粒度特征 (SiGLIP): 局部细节
        fine_feats   = siglip_encoder(images) # (B, N_fine, 1408)

        # ── 视觉投影 ──────────────────────────────────────────
        # CrossModalityProjector: LayerNorm → Linear → GELU → Linear
        coarse_proj = vis_projector(coarse_feats)  # (B, N_coarse, 1024)
        fine_proj   = vis_projector(fine_feats)    # (B, N_fine, 1024)

        # ── TVI 嵌入 (时间-视觉-指令) ─────────────────────────
        # 为每个 token 添加时间、视角、类型嵌入
        coarse_proj = coarse_proj + time_embed + view_embed + kind_embed
        fine_proj   = fine_proj   + time_embed + view_embed + kind_embed

        # 角度编码 (sin/cos → 1024维)
        angle_token = angle_projector(angle)  # (B, 1, 1024)

        # 边界框编码 (4维 → 1024维, 可选)
        bbox_token = bbox_projector(bbox) if bbox else None

        # ── 文本编码 ──────────────────────────────────────────
        text_emb = llm.embed_tokens(tokenize(text_instruction))

        # ── 构建输入序列 ──────────────────────────────────────
        # [文本 | 粗粒度视觉 | 细粒度视觉 | 角度 | 边界框 | 动作token]
        inputs = cat([text_emb, coarse_proj, fine_proj,
                      angle_token, bbox_token, action_token], dim=1)

        # ── LLM 前向 ──────────────────────────────────────────
        hidden = llm(inputs_embeds=inputs).last_hidden_state
        # 取动作 token 位置的隐藏状态
        action_hidden = hidden[:, -1, :]  # (B, 1024)

        # ── 航点预测头 (PlannerHead3L) ────────────────────────
        # LayerNorm → Linear(1024→2048) → GELU → Linear(2048→2048) → GELU → Linear(2048→24)
        # 24 = 8 waypoints × 3 dims (vx, vy, wz)
        actions = planner_head(action_hidden)  # (B, 24)
        actions = tanh(actions) * alpha_task   # 有界输出
        actions = actions.reshape(B, 8, 3)     # (B, 8, 3)

        # ── 积分动作到航点坐标 ────────────────────────────────
        # dt=0.2s, 将速度指令积分为 (x, y, θ) 航点
        waypoints = integrate_actions_to_waypoints(actions, dt=0.2)
        # waypoints: (B, 8, 3)  8个未来位置

        return waypoints

6.4 Uni-NaVid：在线 Token 压缩记忆

class UniNaVIDMetaForCausalLM:
    """
    Vicuna-7B + EVA-CLIP + 在线 Token 合并记忆压缩
    统一处理: VLN / ObjectNav / EQA / 跟踪
    """
    # 余弦相似度阈值: 0.985 (相似帧合并)
    # length_threshold: 8 (超过8帧开始压缩)
    # 推理速度: 5 Hz (A100)

    def process_tensor(feat_cache, new_feats, nav_size):
        """
        在线 Token 合并: 将相似的历史帧压缩为单个 token
        feat_cache: (B, K*nav_size, feat_dim)  历史特征
        new_feats:  (B, nav_size, feat_dim)    新帧特征
        """
        k = feat_cache.shape[1] // nav_size  # 历史帧数

        if k <= 8:  # length_threshold
            # 帧数少时保留所有帧
            return cat([feat_cache, new_feats], dim=1)

        # 帧数多时压缩旧帧
        # 将历史帧分组
        frames = feat_cache.reshape(B, k, nav_size, feat_dim)

        # 计算相邻帧的余弦相似度
        compressed = [frames[:, 0]]  # 保留第一帧
        for i in range(1, k):
            sim = cosine_similarity(
                frames[:, i].mean(dim=1),    # 当前帧均值
                compressed[-1].mean(dim=1)   # 上一个压缩帧均值
            )
            if sim > 0.985:
                # 相似度高: 合并 (加权平均)
                compressed[-1] = (compressed[-1] + frames[:, i]) / 2
            else:
                # 相似度低: 保留为新 token
                compressed.append(frames[:, i])

        compressed = stack(compressed, dim=1)  # (B, K', nav_size, feat_dim)
        return cat([compressed.reshape(B, -1, feat_dim), new_feats], dim=1)

    def online_process_tensor(long_feat_cache, new_feats, weight):
        """长期记忆的在线更新"""
        if long_feat_cache is None:
            return new_feats, 1

        # 比较新帧与长期记忆最后一个 token
        sim = cosine_similarity(
            new_feats.mean(dim=1),
            long_feat_cache[:, -nav_size:].mean(dim=1)
        )

        if sim > 0.985:
            # 相似: 加权平均更新长期记忆
            long_feat_cache[:, -nav_size:] = (
                weight * long_feat_cache[:, -nav_size:] + new_feats
            ) / (weight + 1)
            return long_feat_cache, weight + 1
        else:
            # 不相似: 追加新 token
            return cat([long_feat_cache, new_feats], dim=1), 1

    def forward(images, instruction, feat_cache, long_feat_cache):
        # ── 视觉编码 ──────────────────────────────────────────
        img_feats = vision_tower(images)  # (B, N_patches, 1408)
        img_feats = mm_projector(img_feats)  # (B, N_patches, 4096)

        # ── 在线记忆压缩 ──────────────────────────────────────
        # 短期记忆: 最近帧 (精确)
        feat_cache = process_tensor(feat_cache, img_feats, nav_size)

        # 长期记忆: 压缩历史 (高效)
        long_feat_cache, weight = online_process_tensor(
            long_feat_cache, img_feats, weight
        )

        # ── 构建输入 ──────────────────────────────────────────
        # 拼接: 长期记忆 + 短期记忆 + 当前帧 + 指令
        all_feats = cat([long_feat_cache, feat_cache, img_feats], dim=1)
        inputs_embeds = merge_with_text(all_feats, instruction)

        # ── LLM 生成动作 ──────────────────���───────────────────
        output = llm(inputs_embeds=inputs_embeds)
        action = decode_action(output)  # STOP/FORWARD/LEFT/RIGHT
        return action, feat_cache, long_feat_cache, weight
