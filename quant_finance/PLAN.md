# 计量金融与量化资料库生成计划

更新日期：2026-07-22  
状态：`integrated` → G00–G05 已完成；已完成页面保留视觉 QA 警告
目标：建立一套从数学、经济金融、计量识别到数据、回测、组合、风险与研究生产的完整知识栈，并以可复现实验验证，而不是只汇总书单。

## 1. 学习终点与验收标准

完成资料库后，学习者应能：

1. 从经济或金融问题出发，区分预测（prediction）、因果识别（causal identification）和资产定价检验（asset-pricing test）。
2. 推导并实现 OLS、MLE、GMM、时间序列、面板/IV、波动率与因子模型，解释估计假设和失效方式。
3. 构造无未来信息泄漏、考虑点时数据、公司行动、交易成本和多重检验的研究数据集。
4. 完成“假设—数据—估计—稳健性—回测—风险—部署”闭环，并能复现实证论文或公开基线。
5. 对结果给出可证伪边界：样本外表现、置信区间、换手/容量、成本敏感性、制度变化与数据许可。

建议基准节奏为 36–48 周、每周 10–15 小时；实际推进按能力门槛，不按日历自动升级。首模块会通过诊断题调整数学与编程补课量。

## 3. 实践项目阶梯

项目不会等理论全部学完才开始，而是在对应模块后进入：

1. **P0 统计模拟实验**：有限样本偏差、置信区间覆盖率、异方差与 Bootstrap。
2. **P1 宏观时间序列实验**：使用 FRED/ALFRED，比较实时数据与修订后数据，避免 vintage leakage。
3. **P2 波动率预测**：历史波动率、EWMA、GARCH 的滚动样本外比较，报告 QLIKE 等适当损失。
4. **P3 因子定价复现**：从公开因子数据开始，复现时序回归和横截面检验；再讨论 CRSP/Compustat 点时数据要求。
5. **P4 组合与风险**：估计误差、协方差收缩、换手约束、成本与压力情景。
6. **P5 无泄漏 Alpha 研究**：严格训练/验证/测试时序切分，多重检验与失败策略登记。
7. **P6 事件驱动回测**：在 LEAN 中重建一个已审查策略，纳入订单、成交、滑点和手续费。
8. **P7 研究生产系统**：用 Qlib 或自建管线完成数据版本、特征、训练、回测、报告和监控闭环。
9. **Capstone**：复现一篇实证资产定价、金融计量或量化研究论文；明确“复现成功、部分复现、无法核验”。

## 4. 实践资源准备

### 4.1 软件基线

- Python：使用项目内锁定版本和依赖，不在计划阶段强行指定最新版本；先检查 Qlib、LEAN CLI 与科学计算包兼容矩阵。
- 基础工具：Git、JupyterLab、VS Code、`uv` 或 Conda、`pytest`、pre-commit；Docker 作为可选复现层。
- 数值与数据：NumPy、pandas、SciPy、PyArrow、Polars、DuckDB。
- 统计与计量：statsmodels、linearmodels、arch、scikit-learn。
- 优化与呈现：cvxpy、Matplotlib/Seaborn/Plotly。
- 研究/回测：先用小型自建向量化基线理解机制，再进入 Qlib；事件驱动与模拟成交使用 LEAN。

环境应至少保存：锁文件、操作系统、Python/包版本、随机种子、数据快照哈希、时区和交易日历。硬件起点以普通 16–32 GB 内存 CPU 机器为主；GPU 只在 M10 之后且基线证明需要时引入。

### 4.2 数据分层

| 层级 | 建议来源 | 用途 | 关键限制 |
|---|---|---|---|
| 免费/教学 | FRED、ALFRED、Kenneth French Data Library、SEC EDGAR、交易所/央行官方数据 | 宏观、因子、财报与教学复现 | 频率、修订、许可和点时属性各不相同 |
| 原型行情 | 公开 API 或供应商试用层 | API、清洗和研究原型 | 不默认适合发布、生产或高频回测；逐项核验授权 |
| 学术专业 | WRDS、CRSP、Compustat、TAQ（通常需机构订阅） | 严格资产定价、退市收益、公司事件、微观结构 | 付费、许可严格，不能把原始数据提交 Git |
| 生产/交易 | 交易所授权源、合规供应商、券商 API | 实时/历史行情、订单与实盘 | SLA、重放一致性、公司行动、时钟和成本显著 |

`data/` 只存数据字典、小型可再分发样本、下载脚本说明和校验和。任何来源在使用前必须登记许可与再分发边界。

### 4.3 书籍和课程的使用原则

- 主线教材只选 1 本，其他作为补充，避免“书单收藏替代练习”。
- 计量主线优先用研究生级教材配 MIT OCW 14.382；数值练习可用 QuantEcon。
- 金融经济学、资产定价、衍生品、微观结构和投资组合分别选择标准教材；仅登记合法购买、图书馆或作者公开入口。
- 每章形成“概念卡—推导—最小实现—实证复现—反例/坏案例—测验”六件套。

内容必须包含：问题、先修知识、基础与进阶概念、数学推导、带注释伪代码/代码映射、数据契约、实践任务、坏案例、测验、选择建议和编号来源。HTML 与审查记录同步 Markdown SHA-256。

## 6. 质量闸门

1. **来源闸门**：强主张优先论文、官方课程/教材/文档；二手资料不能单独支撑方法结论。
2. **数学闸门**：公式变量、假设、直觉和实现映射完整；边界条件与识别失败必须说明。
3. **数据闸门**：时间戳、交易日历、复权、退市、幸存者偏差、点时性和授权可追溯。
4. **实验闸门**：随机种子、配置、数据哈希、样本切分、指标和失败实验可恢复。
5. **回测闸门**：禁止未来函数；报告成本、滑点、换手、容量、样本外、多重检验与基准。
6. **渲染闸门**：一个 H1、有效层级/锚点、MathJax 安全、公式中无意外 `<em>`、窄屏和桌面视觉 QA。
7. **教学闸门**：每个模块含检索练习、推导题、代码题和口头解释题，并给出达标标准。
