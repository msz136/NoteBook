# 经典交易策略模型：主观判断、计量信号与跨资产组合

## 问题（Question）

本报告回答四个相互约束的问题：

1. 主观判断（discretionary）与计量信号（systematic/quantitative）如何把股票、黄金和跨资产叙事转成可审计的决策？
2. 价值、趋势、动量、均值回复、因子、carry、波动率目标、风险平价、宏观事件等经典模型的数学表达、统计特征和失效条件是什么？
3. 如何在同一收益、成本和交易时点协议下报告平均收益、CAGR、Sharpe、最大回撤、换手和不确定性？
4. 单一模型如何组合成风险可解释、可执行且不会把重复暴露误认为分散化的投资组合？

收益数字用于研究和教育，不构成个性化投资建议。任何数字都必须同时标注资产代理、样本期、频率、杠杆、交易成本、现金/融资收益和证据层级。

## 背景与动机（Background & Motivation）

股票和黄金常被放在同一组合中：股票代表企业现金流与风险溢价，黄金没有固定票息，却可能在部分实际利率、美元和流动性状态下发挥对冲或避险作用。跨资产策略的难点不在于列出更多指标，而在于区分收益来源：价格方向、股息/票息、展期、抵押品收益、估值修复和风险缩放并不等价。

主观策略拥有宏观信息、行业知识和事件判断的灵活性，但容易产生事后叙事、仓位漂移和不可复核的交易记录；计量策略具有明确的形成期、持有期和成本规则，却会遭遇数据窥探、参数不稳定、相关性跃迁和容量约束。本报告采用“模型章节并列”的组织方式：每个章节在同一章内同时讨论直觉、数学、统计指标、收益/回撤证据、组合方式和风险边界，而不是把所有公式集中在一章、所有结果集中在另一章。

## 基础概念与数据契约

### 收益与财富

对价格或总回报代理 (P_t)，简单收益和对数收益分别为：

\[
r_t=\frac{P_t}{P_{t-1}}-1,
\qquad
g_t=\ln(1+r_t).
\]

对 \(N\) 个同频观测、年化因子 \(K\)，本报告使用：

\[
\mathrm{CAGR}=\left(\frac{V_T}{V_0}\right)^{K/N}-1,
\quad
\sigma_{\mathrm{ann}}=\sqrt K\,s(r),
\quad
\mathrm{Sharpe}=\frac{K\bar r-r_{f,\mathrm{ann}}}{\sqrt K\,s(r)}.
\]

财富峰值 \(M_t=\max_{u\le t}V_u\)，回撤 \(D_t=V_t/M_t-1\)，最大回撤 \(\mathrm{MDD}=\min_tD_t\)。算术平均收益是线性尺度，CAGR 是乘法复合尺度；二者不能互换。

## 模型章节 01：买入并持有与战略资产配置

### 1.1 模型定位：所有主动策略的基准线

买入并持有（buy-and-hold）把资产的目标权重长期保持在初始水平附近，主要收益来源是资产本身的风险溢价、现金分配和价格变化；战略资产配置（strategic asset allocation, SAA）进一步把股票、黄金、债券和现金按长期风险目标配置，并在固定日历或偏离阈值触发再平衡。它不是“没有模型”，而是把主动判断压缩到资产选择、权重、再平衡、杠杆和风险约束上。

本章的作用是建立报告的零号基准：任何趋势、动量、均值回复或主观宏观策略，都必须回答“相对于固定权重基准增加了什么信息、承担了什么成本、是否真的改善了风险收益比”。若一套主动策略只是在样本内提高了收益，却没有说明它相对买入并持有的增量风险和换手，则不能称为完整比较。

### 1.2 数学表达

设有 \(n\) 个资产，时点 \(t\) 的简单收益向量为 \(\mathbf r_t=(r_{1,t},\ldots,r_{n,t})^\top\)，目标权重为 \(\mathbf w=(w_1,\ldots,w_n)^\top\)，满足 \(\sum_iw_i=1\)。在不考虑交易成本、融资和现金流的第一版模型中，组合收益为：

\[
r_{p,t}=\mathbf w^\top\mathbf r_t=\sum_{i=1}^{n}w_i r_{i,t}.
\]

**变量、直觉与实现映射：** \(r_{p,t}\) 是组合在第 \(t\) 个周期的收益，\(w_i\) 是资产 \(i\) 的目标权重。代码对应对齐后的收益矩阵与权重向量点积；它只描述“持仓不变一个周期”的收益，不等于再平衡后的长期财富。

若每月末把权重恢复为 \(\mathbf w\)，财富过程为：

\[
V_t=V_{t-1}(1+r_{p,t}),\qquad
V_T=V_0\prod_{t=1}^{T}(1+r_{p,t}).
\]

**变量、直觉与实现映射：** \(V_t\) 是累计财富；乘法复合意味着一个大亏损会改变后续恢复所需的收益。回测实现应先按交易时点计算资产收益，再按目标权重合成组合收益；不能把各资产的年化平均收益简单加权后当作组合 CAGR。

对于均值向量 \(\boldsymbol\mu=E[\mathbf r_t]\) 与协方差矩阵 \(\boldsymbol\Sigma=\operatorname{Cov}(\mathbf r_t)\)，组合的一阶二阶矩为：

\[
E[r_p]=\mathbf w^\top\boldsymbol\mu,\qquad
\operatorname{Var}(r_p)=\mathbf w^\top\boldsymbol\Sigma\mathbf w.
\]

**变量、直觉与实现映射：** 协方差项 \(w_iw_j\Sigma_{ij}\) 是分散化的数学来源；两个资产收益率都很高并不保证组合波动低，关键是相关性和极端状态下的联合损失。样本实现用滚动均值和协方差估计，但估计误差会直接传导到权重，因此本章只把固定权重作为稳健基准，不宣称样本均值是可靠的未来预期。

实际组合还存在权重漂移。令 \(w_{i,t}^{\text{pre}}\) 为收益发生后的漂移权重，月末再平衡交易量可用：

\[
\Delta_t=\frac12\sum_i\left|w_{i,t}^{\text{pre}}-w_i\right|,
\qquad
r_{p,t}^{\text{net}}\approx r_{p,t}^{\text{gross}}-c_t\Delta_t,
\]

其中 \(c_t\) 是每单位换手的综合成本。这里的 \(\Delta_t\) 是单边换手近似；实际执行还需拆分手续费、买卖价差、冲击、融资、税费和 ETF 管理费。

### 1.3 统计特征与应报告指标

对 \(N\) 个观测、年化因子 \(K\)（日频通常取 252，月频取 12），本报告统一报告以下指标：

| 指标 | 数学定义 | 解释 | 本模型的注意事项 |
|---|---|---|---|
| 年化算术平均收益 | \(K\bar r_p\) | 单周期平均收益的线性年化 | 不是长期财富增长率，忽略复合和波动拖累 |
| CAGR | \((V_T/V_0)^{K/N}-1\) | 真实复合增长速度 | 最适合和最大回撤并列，但对起止点敏感 |
| 年化波动 | \(\sqrt K\,s(r_p)\) | 收益标准差的年化尺度 | 只描述二阶矩，不覆盖跳跃和尾部 |
| Sharpe（零 RF 示例） | \(\sqrt K\,\bar r_p/s(r_p)\) | 每单位波动的超额收益 | 正式版本应扣除同频无风险利率 |
| 最大回撤 MDD | \(\min_t(V_t/\max_{u\le t}V_u-1)\) | 从历史峰值到谷值的最大损失 | 不是平均损失；单一路径统计量，置信区间需 bootstrap |
| Calmar | \(\mathrm{CAGR}/|\mathrm{MDD}|\) | 用最坏路径损失衡量增长效率 | 对样本长度、起止点和单次危机很敏感 |
| 回撤持续期 | 峰值到恢复峰值的时间 | 衡量资金被套住多久 | 对长期配置者常比单一 MDD 更有决策意义 |
| 换手与成本 | \(\Delta_t,\;c_t\Delta_t\) | 再平衡的可实现代价 | 低频不等于零成本，黄金期货还要考虑展期和保证金 |

固定权重组合的收益分布通常具有以下统计性质：一是资产收益的尖峰厚尾使样本均值和标准差不稳定；二是危机期间相关性可能上升，黄金并不保证每次股灾都上涨；三是再平衡把部分“卖出近期赢家、买入近期输家”的反向交易嵌入组合，但再平衡收益不是无条件的免费 alpha；四是长期 CAGR 与算术平均收益之间存在波动拖累，不能使用 \(K\bar r_p\) 替代 CAGR。

### 1.4 股票与黄金的资产映射

**股票代理。** 本轮本地快照使用 SPDR S&P 500 ETF Trust（SPY）的调整收盘价。它更接近含分红再投资的 ETF 持有者回报，但仍包含基金费率、跟踪误差和 ETF 交易机制；它不是无摩擦的 S&P 500 总回报指数，也不覆盖退市股票。

**黄金代理。** 本轮使用 SPDR Gold Shares（GLD）的调整收盘价，作为可交易黄金 ETF 代理。它不等于伦敦现货金或 COMEX 期货：ETF 费率、跟踪误差、交易时段、美元汇率、税务和流动性都可能改变投资者结果。黄金是否具有 hedge（对冲）或 safe haven（避险）属性，依赖“相对什么资产、什么时间窗口、什么冲击”定义，不能简化成始终与股票负相关。

**组合代理。** 60% SPY + 40% GLD、50%/50% 和 80%/20% 是月末再平衡的固定权重示例，用于展示“降低单一资产回撤”的机制，不代表最优权重。后续风险平价、波动率目标和宏观状态切换将作为平行章节分别研究，不能从本章的固定权重结果直接推断它们更优。

### 1.5 文献与研究证据

1. Markowitz (1952) 将投资组合选择写成均值—方差权衡，支持“相关性与权重共同决定组合风险”的理论起点；该文不支持任何具体股票+黄金权重在未来必然有效。[1]
2. Sharpe (1964) 的资本资产定价框架把风险与预期收益联系起来，为 Sharpe 比率和基准调整提供理论背景；它不等于一个可直接交易的择时策略，也不消除参数估计与模型错设。[2]
3. Baur 与 Lucey (2010) 区分 gold hedge 与 safe haven：黄金对股票的关系需要按正常时期与极端下跌时期分别检验；论文的概念边界支持条件相关性分析，不支持“黄金永远避险”的口号。[3]
4. Erb 与 Harvey (2013) 讨论黄金长期回报、通胀、美元和仓位问题，提醒研究者区分名义价格上涨、实际回报、持有成本和投资组合用途；其历史样本结论不能直接外推到当前 ETF 或人民币投资者。[4]

### 1.7 固定权重组合的实现伪代码

~~~python
def monthly_fixed_weight_backtest(price_panel, target_weights, cost_bps=0):
    # 1) 使用调整后价格构造同频收益，并删除尚未完成的当前周期。
    returns = price_panel.pct_change().dropna()
    wealth = 1.0
    weights = target_weights.copy()
    ledger = []

    for date, asset_returns in returns.iterrows():
        # 2) 先用上一期目标权重承受本期资产收益，避免未来函数。
        portfolio_return = (weights * asset_returns).sum()
        wealth *= 1.0 + portfolio_return

        # 3) 周期末把漂移权重恢复到目标权重，并记录单边换手。
        pretrade_value = weights * (1.0 + asset_returns)
        pretrade_weights = pretrade_value / pretrade_value.sum()
        turnover = 0.5 * (pretrade_weights - target_weights).abs().sum()
        wealth *= 1.0 - cost_bps / 10000.0 * turnover
        weights = target_weights.copy()

        # 4) 保存净收益、财富、权重和换手，供 MDD 与成本敏感性计算。
        ledger.append((date, wealth, portfolio_return, turnover))

    return ledger
~~~

### 1.8 失败模式与模型边界

- **把 ETF 代理当成资产本体：** GLD 不是现货金，SPY 不是无摩擦总回报指数；必须在结果表标注代理和费用。
- **把历史算术平均当作未来预期：** 样本均值受起止点、估计误差、制度变化和幸存者偏差影响。
- **忽略再平衡交易：** 固定权重不是自动可实现；频率越高，换手和成本越可能吞噬分散化收益。
- **用单一 MDD 评价全部风险：** MDD 不反映回撤发生概率、持续时间、尾部频率和流动性。
- **把黄金的条件避险性写成无条件规律：** 需要按危机定义、窗口和基准做条件相关/尾部分析。
- **把组合较低回撤误写为“策略 alpha”：** 固定权重只是风险暴露组合，除非有严谨基准、样本外和成本后的增量证据，不能叫 alpha。

### 1.9 本章结论与后续接口

买入并持有与战略资产配置是报告后续所有模型的共同基准：它给出最少参数、低换手、可解释的风险收益路径。SPY/GLD 示例显示固定权重可能降低特定样本中的最大回撤，但结果高度依赖代理、窗口、再平衡和成本。下一并列章节将研究**主观基本面/价值模型**，重点讨论如何把估值叙事变成可记录、可检验、但不伪装成机械信号的决策规则。

## 模型章节 02：主观基本面 / 价值交易

### 2.1 模型定位：从“便宜”到“可证伪的估值判断”

主观基本面交易（discretionary fundamental trading）先提出企业或宏观资产的经济判断，再决定买入价格、持有期限、仓位和退出条件。价值交易（value investing）是其中最容易被机械化的一支：核心命题不是“低市盈率必涨”，而是市场价格 \(P\) 与由现金流、资产、盈利能力或宏观稀缺性推导的内在价值 \(V\) 之间可能存在可利用的偏离。

主观判断与计量价值因子必须并列而不能混写：

| 维度 | 主观基本面/价值判断 | 计量价值代理 |
|---|---|---|
| 研究对象 | 企业竞争优势、资本配置、会计质量、管理层、行业结构、宏观情景 | B/M、E/P、FCF/P、EV/EBITDA 等可计算字段 |
| 核心输出 | 内在价值区间、置信度、催化剂、失效条件、仓位 | 横截面排序、分组收益、HML 多空收益 |
| 信息更新 | 财报、调研、政策与事件触发 | 固定频率重算、点时数据更新 |
| 可复现程度 | 决策日志可复核，但判断本身可能不可完全机械化 | 规则可复现，但数据定义与交易成本仍需冻结 |
| 主要风险 | 价值陷阱、叙事偏差、确认偏误、估值锚定 | 因子拥挤、结构变化、行业暴露、短腿融资和换手 |

本章不把“优秀公司”或“低估资产”的投资故事写成确定收益率。主观模型的可审查单位应是：**假设 → 证据 → 估值区间 → 安全边际 → 仓位 → 催化剂/退出 → 复盘结果**。只有当这些字段在时间上冻结，研究者才能判断一个判断是事后解释还是事前决策。

### 2.2 内在价值与安全边际的数学表达

#### 现金流折现（DCF）

对有可预测现金流的股票，最小化的股权现金流折现形式是：

\[
V_0=\sum_{t=1}^{T}\frac{FCFE_t}{(1+k_e)^t}
\;+\;\frac{TV_T}{(1+k_e)^T},
\qquad
TV_T=\frac{FCFE_{T+1}}{k_e-g}.
\]

其中 \(FCFE_t\) 是第 \(t\) 期股权自由现金流，\(k_e\) 是股权资本成本，\(g\) 是稳定期增长率，且终值公式要求 \(k_e>g\)。若采用企业自由现金流，则折现率换成 WACC，并在终值后扣除净债务得到股权价值。

**变量、直觉与实现映射：** DCF 把“未来能给股东多少钱”转换成今天的价格；远期现金流的折现权重较小，但终值通常占估值很大比例，因此 \(k_e\)、\(g\)、利润率和再投资率的微小变动会造成巨大估值区间。实现上应保存每次估值的输入快照、发布日期和假设，而不是只保存一个最终目标价。

#### 相对估值与收益率表达

常见相对估值指标可写为：

\[
EY_i=\frac{E_i}{P_i},\qquad
FCFY_i=\frac{FCF_i}{P_i},\qquad
BM_i=\frac{B_i}{M_i},\qquad
EVEBITDA_i=\frac{EV_i}{EBITDA_i}.
\]

其中 \(EY\) 是盈利收益率（earnings yield），\(FCFY\) 是自由现金流收益率，\(BM\) 是账面市值比（book-to-market），\(EVEBITDA\) 是企业价值倍数。收益率越高或倍数越低通常意味着“更便宜”，但只有在盈利、现金流和资产账面值具有可持续性时才有经济意义。

为了减少不同单位和行业分布差异，可以在同一形成日做横截面标准化：

\[
z_{i,k,t}=\frac{x_{i,k,t}-\operatorname{median}_t(x_{k,t})}
{1.4826\operatorname{MAD}_t(x_{k,t})+\epsilon},
\qquad
S_{i,t}=\sum_{k\in\mathcal K}\lambda_k z_{i,k,t}.
\]

这里使用 median/MAD（median absolute deviation）而非均值/标准差，是为了减弱极端估值的影响；\(S_{i,t}\) 是价值、质量或盈利稳定性指标的组合分数，\(\lambda_k\) 是预先登记的权重。行业内标准化、规模中性和 winsorization 必须在形成期内完成，不能看到未来收益后再挑选阈值。

#### 安全边际与仓位

主观价值判断通常不是使用单点估值，而是使用价值区间 \([V_i^L,V_i^U]\)。一个可审查的安全边际（margin of safety, MOS）定义是：

\[
MOS_i=1-\frac{P_i}{V_i^L}.
\]

只有当 \(MOS_i\) 超过预先登记的门槛、会计质量检查通过、催化剂存在且失效条件尚未触发时，才进入候选池。仓位可用风险预算而非“越便宜越重仓”：

\[
w_i=\operatorname{clip}\!\left(
\frac{MOS_i\,q_i}{\hat\sigma_i^2},
-w_{\max},w_{\max}\right),
\]

其中 \(q_i\in[0,1]\) 是对现金流质量、会计可靠性和催化剂确定性的置信度，\(\hat\sigma_i^2\) 是滚动风险估计。该式是研究模板而不是标准答案；它显式说明低估值如果伴随高不确定性，仓位仍可能被压低。

### 2.3 股票基本面模型的输入、流程与统计特征

#### 输入字段与点时约束

股票价值模型至少需要以下字段，并区分“财报发布日期”和“财报所属期”：

| 字段 | 作用 | 常见陷阱 |
|---|---|---|
| 市值、企业价值 | 分母与资本结构 | 使用未来修订市值或忽略优先股/少数股东 |
| 净利润、EBIT、EBITDA | 盈利能力与估值倍数 | 一次性项目、周期峰值和负盈利 |
| CFO、Capex、FCF | 现金流质量 | 把营运资本释放当作可持续现金流 |
| 总资产、净资产、商誉 | B/M 与资产重估 | 无形资产和回购导致账面值失真 |
| ROIC、ROE、毛利率 | 质量过滤 | 杠杆可机械抬高 ROE |
| 负债、利息覆盖率 | 生存风险 | 低估值可能只是破产概率上升 |
| 财报发布日期 | Point-in-time 可用性 | 用年末数据回填到财报公开前的回测日期 |

一个标准流程是：在形成日冻结当时可获得的基本面字段；做行业内 winsorization 与标准化；剔除负盈利、极端杠杆和流动性不足标的；构造价值/质量分数；按分位数形成多空或长-only 组合；在下一交易窗口执行；将 delisting return、公司行动、停牌和交易成本写入账本。

#### 价值模型的统计特征

价值暴露的常见统计特征不是“低估值每月稳定上涨”，而是：

1. **收益分布偏态与尾部集中：** 赢家可能来自少数价值重估，输家可能因破产或盈利崩塌形成大损失。
2. **长周期均值回复：** 估值偏离可能持续多年，等待成本和职业风险高于单次交易成本。
3. **价值陷阱（value trap）：** 低倍数由行业衰退、会计质量恶化、过高杠杆或技术替代解释，而不是价格错误。
4. **行业和风格暴露：** B/M 与 E/P 组合可能集中于金融、能源、周期和小盘股；“价值收益”与行业 beta 难以完全分离。
5. **与动量的负相关风险：** 价值反转常发生在价格持续下跌后，而动量策略会继续减仓；二者组合可改善路径，但不保证所有时期都对冲。
6. **样本不稳定：** 账面价值对软件、平台和研发密集企业的经济资本解释力下降，单一 B/M 不是跨时代不变的内在价值测量。

### 2.4 黄金的基本面/宏观价值判断

黄金没有企业现金流，不能直接套用股票 DCF。主观黄金模型通常把金价视为实际利率、美元、通胀预期、央行需求、风险厌恶和供给库存的共同结果。一个可用于研究而非因果宣称的状态模型是：

\[
r_{gold,t+1}
=\alpha
+\beta_1\Delta(-y^{real}_t)
+\beta_2\Delta USD_t
+\beta_3\Delta\pi^e_t
+\beta_4\Delta Risk_t
+\varepsilon_{t+1}.
\]

\(y^{real}\) 是实际利率，\(USD\) 是美元指数，\(\pi^e\) 是通胀预期，\(Risk\) 是预先定义的风险厌恶代理。使用 \(\Delta(-y^{real})\) 表示实际利率下降通常会降低持有无息黄金的机会成本；但这只是经济假设，必须用滚动样本外检验、稳定性检查和替代指标验证。

为了把宏观叙事转成仓位规则，可以构造标准化状态分数：

\[
F_t=\theta_1 z(-y^{real}_t)+\theta_2 z(-USD_t)
+\theta_3 z(\pi^e_t)+\theta_4 z(Risk_t),
\qquad
w^{gold}_t=\operatorname{clip}(w_0+\eta F_t,0,w_{\max}).
\]

这里的 \(w_0\) 是战略黄金权重，\(\eta\) 是状态倾斜幅度。实际研究必须记录宏观数据发布日期、修订版本、滞后、交易时点和 FX 口径；否则“知道当时的实际利率”可能包含未来修订信息。

### 2.7 价值与其他模型的组合方式

价值模型常与以下模型组合，而不是孤立地提高“便宜程度”：

1. **价值 + 质量：** 先用 B/M、E/P 或 FCF/P 找便宜资产，再用 ROIC、现金流稳定性、杠杆和盈利修正筛掉价值陷阱。组合分数可写为 \(S_i=\lambda_VS_i^V+\lambda_QS_i^Q\)。
2. **价值 + 动量：** 价值提供较慢的均值回复，动量提供价格确认；可在形成期做动量 veto，或让两类信号分别占风险预算。
3. **价值 + 黄金宏观覆盖：** 股票价值组合在估值修复等待期可能回撤很久，黄金状态分数可以作为低频防御仓位；这不是保证对冲，应报告条件相关和危机窗口。
4. **价值 + 风险目标：** 用单名波动、行业暴露、流动性和组合 MDD 约束仓位，避免“最便宜的股票”集中占据组合。

组合时必须保持信号和风险的边界：提高价值分数不等于提高仓位；只有在估值、质量、流动性和风险预算同时通过时才执行。

### 2.8 主观基本面—计量价值的实现伪代码

~~~python
def fundamental_value_pipeline(asof_date, point_in_time_fundamentals, prices):
    # 1) 只读取在 asof_date 之前已经公开的财报和市场数据。
    fields = point_in_time_fundamentals(asof_date)

    # 2) 计算估值、盈利质量、杠杆和流动性字段，并做行业内稳健标准化。
    value_score = robust_zscore(fields["fcf_yield"]) + robust_zscore(fields["book_to_market"])
    quality_score = robust_zscore(fields["roic"]) - robust_zscore(fields["leverage"])
    tradable = (fields["market_cap"] > MIN_CAP) & (fields["price"] > 0)

    # 3) 把主观判断登记为结构化字段，而不是在回测后手工挑选赢家。
    thesis = load_pre_registered_thesis(asof_date)
    eligible = tradable & thesis["accounting_ok"] & thesis["catalyst_present"]
    score = 0.5 * value_score + 0.5 * quality_score

    # 4) 先做行业/规模中性排序，再应用安全边际、波动率和单名上限。
    candidates = rank_within_industry(score[eligible])
    weights = risk_budget(candidates, prices, max_single=0.02, max_sector=0.20)

    # 5) 输出形成日持仓与证据账本；执行从下一交易窗口开始，避免未来函数。
    return {"weights": weights, "thesis": thesis, "evidence_date": asof_date}
~~~

### 2.9 失败模式、统计陷阱与风险边界

- **把低倍数等同于低估：** 盈利下修、债务到期、监管冲击和技术替代都可能使“便宜”成为合理价格。
- **财报未来函数：** 使用财报所属期而非发布日期会把未来信息提前放入形成期。
- **行业不可比：** 银行、软件、矿业和消费公司的资产负债表与现金流定义不同，跨行业直接比较 P/B 或 FCF yield 会制造伪信号。
- **终值主导 DCF：** \(k_e\) 和 \(g\) 的小变化可能改变估值数倍；应报告情景区间和反向估值，而不是单一目标价。
- **HML 不是可直接交易净收益：** 因子通常隐含多空、再平衡、借券和融资，真实策略会有成本、容量和税费。
- **价值因子长期失效：** 2010–2026 的本地 HML 代理为负 CAGR，不应因长样本正均值就隐藏近期衰减。
- **主观复盘偏差：** 只记录成功案例会产生 survivorship 与 hindsight bias；必须保留失败交易、撤销理由和当时可见信息。
- **把黄金宏观回归当作因果：** 实际利率、美元、通胀和风险厌恶高度相关，回归系数需要稳健标准误、替代指标和样本外验证。

### 2.10 本章结论与后续接口

主观基本面/价值模型的可复现核心不是一个神奇估值倍数，而是把现金流假设、会计质量、安全边际、催化剂、退出条件和仓位风险写成事前可核验的决策链。HML 的官方长样本代理显示价值暴露具有正的长期平均收益，但经历过约 58% 的最大回撤和长时间衰减；这正是为什么价值策略需要质量过滤、动量确认、行业约束和组合层风险管理。

下一并列章节将进入**趋势跟随与时间序列动量**：重点比较股票指数、黄金和跨资产趋势信号的数学形式、波动率目标、换手与危机期回撤。

## 模型章节 03：趋势跟随与时间序列动量

### 3.1 模型定位：不预测目标价，只判断方向是否延续

趋势跟随（trend following）与时间序列动量（time-series momentum, TSMOM）都利用同一资产过去价格变化与未来方向之间可能存在的持续性。它们与价值模型的逻辑相反：价值模型问“价格偏离内在价值多少”，趋势模型问“已经发生的价格方向是否仍在延续”。趋势交易不要求知道股票指数或黄金的合理价值，只要求信号、风险目标、交易时点和退出规则可机械执行。

二者常被混用，但可作如下区分：

| 类型 | 信号核心 | 典型仓位 | 研究问题 |
|---|---|---|---|
| 移动平均趋势 | 当前/前期价格与移动均线的相对位置 | 多头/现金或多空 | 价格是否位于平滑趋势之上 |
| 绝对动量 | 过去 \(L\) 期累计收益的正负 | 正收益做多、负收益空仓/做空 | 单资产自身是否具有方向 |
| 时间序列动量 | 多个回看期收益方向，配合波动率缩放 | 多空且风险标准化 | 不同资产的自身方向能否组合 |
| 突破系统 | 价格突破过去 \(L\) 期高/低点 | 突破入场、反向突破退出 | 新趋势是否已突破历史区间 |
| 多尺度趋势 | 短、中、长回看信号集成 | 连续仓位 | 减少单一参数依赖和换手跳跃 |

趋势跟随不是“上涨就买”的口号。可交易模型至少要回答：信号何时可见、下一期何时成交、未持仓资金收益是多少、是否允许做空、如何估计波动、仓位上限、交易成本和连续合约展期如何处理。

### 3.2 信号的数学表达

#### 过去收益符号

设资产价格为 \(P_t\)，\(L\) 是回看长度，最简单的时间序列动量信号是：

\[
m_{t,L}=\frac{P_t}{P_{t-L}}-1,
\qquad
s_{t,L}=\operatorname{sign}(m_{t,L}).
\]

**变量、直觉与实现映射：** \(m_{t,L}\) 是过去 \(L\) 期累计简单收益；\(s=+1\) 表示做多，\(s=-1\) 表示做空。若研究对象不允许做空，则把负信号映射为现金：\(s_{t,L}^{LC}=\max(s_{t,L},0)\)。实现时必须把 \(s_t\) 至少滞后一根 bar 后乘以 \(r_{t+1}\)，否则会把本期收盘信号用于本期收益。

#### 单移动平均与双移动平均

长度为 \(L\) 的简单移动平均（simple moving average, SMA）为：

\[
SMA_{t,L}=\frac1L\sum_{j=0}^{L-1}P_{t-j},
\qquad
s_t^{SMA}=\mathbb I(P_t>SMA_{t,L}).
\]

**变量、直觉与实现映射：** \(\mathbb I(\cdot)\) 是指示函数；本章的长-only 规则在价格高于均线时持有资产，否则持有零收益现金。回测中先在月末 \(t\) 计算信号，再让该信号作用于 \(t+1\) 月收益。

双移动平均规则将短期均线 \(SMA_{t,L_s}\) 与长期均线 \(SMA_{t,L_l}\) 比较：

\[
s_t^{dual}=\operatorname{sign}
\left(SMA_{t,L_s}-SMA_{t,L_l}\right),
\qquad L_s<L_l.
\]

**变量、直觉与实现映射：** 短均线上穿长均线表示近期价格相对长期水平转强。双均线减少价格对单条均线的瞬时穿越，但会增加两个窗口参数和信号延迟。

#### 多尺度连续信号

单一 10 月或 12 月窗口容易产生参数偶然性。多尺度模型可将多个回看期合成连续信号：

\[
\tilde s_t=\sum_{L\in\mathcal L}a_L
\frac{m_{t,L}}{\hat\sigma_{t,L}},
\qquad
s_t=\tanh(\tilde s_t),
\qquad \sum_La_L=1.
\]

**变量、直觉与实现映射：** \(a_L\) 是事前固定的窗口权重，\(\hat\sigma_{t,L}\) 标准化不同窗口的收益尺度，\(\tanh\) 把仓位限制在 \([-1,1]\)。连续信号比二元切换更平滑，但其参数、估计窗口和非线性映射必须登记，不能通过测试集反复调节。

### 3.3 仓位、波动率目标和交易成本

对目标年化波动 \(\sigma^*\)、预测波动 \(\hat\sigma_t\) 和最大杠杆 \(w_{\max}\)，风险标准化仓位为：

\[
w_t=\operatorname{clip}\!\left(
s_t\frac{\sigma^*}{\hat\sigma_t},
-w_{\max},w_{\max}\right).
\]

**变量、直觉与实现映射：** 趋势方向由 \(s_t\) 决定，仓位大小由波动率预算决定；高波动期自动降杠杆。实现中 \(\hat\sigma_t\) 只能使用 \(t\) 及以前数据，且应设置波动率下限，避免低波动估计制造极端杠杆。

计入换手成本后的下一期收益为：

\[
r_{t+1}^{trend,net}
=w_t r_{t+1}
+(1-|w_t|)r_{f,t+1}
-c_t|w_t-w_{t-1}|.
\]

**变量、直觉与实现映射：** \(r_f\) 是现金收益，\(c_t\) 是每单位仓位变化的手续费、点差和冲击近似。本章本地示例为 long/cash，现金收益设为 0，每次单边仓位变化扣 10 bps；因此它没有反映真实 T-bill 收益、借券、期货保证金或展期。

对 \(n\) 个资产，可先分别产生风险标准化趋势收益，再按风险预算组合：

\[
r_{p,t+1}
=\sum_{i=1}^{n}b_i
\frac{s_{i,t}}{\hat\sigma_{i,t}}
r_{i,t+1},
\qquad
\sum_ib_i=1.
\]

**变量、直觉与实现映射：** \(b_i\) 是资产族风险预算，而不是名义资金权重。真实跨资产 CTA 会覆盖股票指数、国债、商品和外汇；本章只有 SPY/GLD 两个 ETF，因而只能验证信号与统计流程，不能代表多资产期货趋势组合。

### 3.4 统计特征：趋势策略为什么常出现“多数小亏、少数大赚”

趋势策略的统计分布通常不同于买入并持有：

1. **截断部分下行但牺牲反弹：** 长-only 趋势在跌破均线后进入现金，可能减少持续熊市损失，却会错过 V 型反弹的初段。
2. **锯齿损失（whipsaw）：** 横盘期价格反复穿越均线，连续小亏与成本累积成为主要失败模式。
3. **收益可能正偏：** 多空趋势在少数长趋势中产生大收益，而在无趋势期承受小额反复止损；但正偏不是所有参数和资产的保证。
4. **波动率条件化：** 未做波动率标准化时，高波动资产会主导组合；做标准化后又引入估计误差和去杠杆滞后。
5. **危机凸性具有条件：** 趋势需要时间识别方向，突然跳空或快速 V 型反转可能同时伤害多资产仓位；“危机 alpha”不能写成无条件保险。
6. **参数相关性高：** 10、12、18 个月均线高度相关，不能把每个窗口当作独立策略计算显著性。

除平均收益、CAGR、Sharpe 和 MDD 外，本章应额外报告：

| 指标 | 意义 |
|---|---|
| 在场比例（invested fraction） | 资金暴露于风险资产的时间比例 |
| 年化换手 | 趋势切换与成本敏感度 |
| 信号翻转次数 | whipsaw 的直接计数 |
| 上涨/下跌市场捕获率 | 趋势在不同市场方向中的参与程度 |
| 最长空仓与最长连续亏损 | 等待成本和执行纪律压力 |
| 危机窗口收益 | 只能在事前冻结的危机列表上报告 |
| 参数稳定性 | 多窗口、不同成本和延迟下结果是否一致 |

### 3.5 股票趋势：减少深熊暴露，但可能降低长期复合收益

股票指数具有长期正风险溢价，长-only 趋势的核心取舍是：牺牲一部分持续上涨期和反弹期收益，换取在缓慢熊市中退出的可能。对个股趋势还需处理退市、涨跌停、停牌和横截面分散；本章使用 SPY，是为了隔离指数方向信号，不能推广到单名股票。

股票趋势的主要风险包括：

- 长期牛市中现金仓位形成机会成本；
- 大跌后快速反弹导致“低位卖出、高位买回”；
- 月度规则无法避免月内跳空；
- 价格指数、总回报指数和 ETF 调整价可能产生不同均线交叉；
- 现金利率为零的假设在高利率阶段低估空仓收益，在低利率阶段影响较小。

### 3.6 黄金趋势：无现金流资产更适合方向模型，但不是更容易

黄金缺少可直接折现的现金流，趋势信号因此常被用作宏观判断的替代。然而黄金的价格路径受美元、实际利率、央行需求、地缘冲击、ETF 申赎和期货仓位共同影响，长期横盘与快速反转会产生严重 whipsaw。

ETF、现货和期货趋势必须分开：

| 载体 | 趋势信号输入 | 额外收益/成本 |
|---|---|---|
| GLD 等 ETF | 调整后 ETF 价格 | 基金费率、跟踪误差、交易点差 |
| 伦敦现货 | 现货定盘/报价 | 托管、资金和交易时段 |
| COMEX 期货 | 连续合约或单合约价格 | 展期、保证金、期限结构和合约切换 |

本章 GLD 结果显示，12 月均线没有显著改善该样本的黄金最大回撤：净 MDD 约 −41.81%，与 GLD 买入并持有的 −42.91% 接近。这一反例很重要：趋势规则对股票有效的回撤控制不能机械外推到黄金。

### 3.7 文献证据与可支持边界

| 来源 | 支持的内容 | 不能支持的推论 |
|---|---|---|
| Fama & Blume (1966) | 早期过滤规则、交易成本和市场效率检验 | 不代表现代多资产期货趋势净表现 |
| Brock, Lakonishok & LeBaron (1992) | 对移动平均与交易区间突破规则的统计检验 | 不消除数据窥探和样本依赖 |
| Faber (2007) | 10 月移动平均用于低频战术资产配置的公开规则 | 论文样本结果不能直接外推到当前 ETF 或成本 |
| Moskowitz, Ooi & Pedersen (2012) | 跨期货资产的时间序列动量研究框架 | 不等于 SPY/GLD 两资产长-only 规则 |
| Hurst, Ooi & Pedersen (2017) | 长历史趋势跟随证据与危机讨论 | 历史回溯不构成未来回报承诺 |

### 3.8 本地复现实验：SPY、GLD 与双资产趋势

本节使用 <code>quant_finance/data/classic_strategy_trend_snapshot.json</code>。月末信号只作用于下一月；当价格不高于均线时持有零收益现金；每单位仓位变化扣 10 bps。数据仍是 Yahoo Finance SPY/GLD adjusted-close 二手代理，不能替代正式指数、现货或期货数据。

### 3.9 实现伪代码：严格滞后、成本与组合

~~~python
def monthly_trend_backtest(prices, lookback=12, cost_bps=10):
    # 1) 只在完整月份上计算移动平均，当前未完成月份必须排除。
    monthly_returns = prices.pct_change()
    moving_average = prices.rolling(lookback, min_periods=lookback).mean()

    # 2) 月末 t 形成信号，shift(1) 后才作用于 t+1 收益。
    raw_signal = (prices > moving_average).astype(float)
    position = raw_signal.where(moving_average.notna()).shift(1)

    # 3) long/cash 收益；现金收益可替换为同月 T-bill。
    gross_return = position * monthly_returns

    # 4) 初始建仓和后续翻转都计入单边仓位变化成本。
    turnover = position.diff().abs().fillna(position)
    net_return = gross_return - cost_bps / 10000.0 * turnover

    # 5) 多资产先独立计算信号，再按预先登记的风险预算聚合。
    portfolio_return = risk_budgeted_sum(net_return)
    return compute_cagr_sharpe_drawdown_turnover(portfolio_return)
~~~

### 3.10 失败模式与风险边界

- **信号与收益同月相乘：** 未 shift 的回测含收盘价未来函数，会系统性夸大收益。
- **选择最好窗口：** 在 3–24 个月中挑最高 Sharpe 而不计试验次数，会产生数据窥探。
- **忽略现金收益：** 长期空仓比例约 20%–30% 时，现金利率对结果有实质影响。
- **连续合约错误：** 黄金期货趋势若使用未经审查的回填连续价格，会把展期跳跃当成交易信号。
- **把低 MDD 等同于高收益：** 本地 SPY/50-50 结果降低回撤但也降低 CAGR；目标函数必须事先确定。
- **突然反转和跳空：** 趋势信号是滞后的，无法保证在闪崩、政策跳跃或 V 型反弹中及时退出/重入。
- **波动率目标顺周期：** 危机初期波动上升迫使去杠杆，危机后波动下降又可能加仓过慢。
- **资产不足造成伪分散：** SPY 与 GLD 两个代理不能代表股票、债券、外汇和商品的多资产 CTA。
- **交易成本线性化：** 10 bps 只是示例；真实点差、冲击、借券、期货保证金和税费具有状态依赖。

### 3.11 本章结论与后续接口

趋势跟随的核心价值是把方向判断、退出和风险预算机械化，而不是提高所有资产的平均收益。本地结果显示，12 月 SMA 在 SPY 和 SPY/GLD 组合上以较低 CAGR 换取明显较低的最大回撤，但对 GLD 的回撤控制有限。这说明趋势应作为跨资产、风险标准化和多尺度模型评估，不能从股票指数经验直接外推黄金。

下一并列章节将研究**横截面动量与相对强弱模型**：比较赢家—输家排序、行业中性、持有期重叠、反转风险及其与价值模型的组合。

## 模型章节 04：横截面动量与相对强弱

### 4.1 模型定位：在同一时点买相对赢家、卖相对输家

横截面动量（cross-sectional momentum）不问单个资产自身是否处于长期上升趋势，而是在同一形成日把资产按过去收益排序：买入相对赢家，卖出或低配相对输家。相对强弱（relative strength）是它在 long-only 组合中的版本，常用于行业轮动、ETF 轮动和跨资产配置。

它与第 3 章时间序列动量的差别是：

| 维度 | 时间序列动量 | 横截面动量 |
|---|---|---|
| 比较对象 | 同一资产过去与现在 | 同一时点不同资产之间 |
| 信号 | \(R_{i,t}^{(L)}\) 的正负 | \(R_{i,t}^{(L)}\) 的横截面排名 |
| 负信号 | 现金或做空自身 | 低配/做空输家 |
| 主要风险 | 趋势反转、空仓机会成本 | 动量崩溃、拥挤、行业和 beta 暴露 |
| 典型实现 | CTA 趋势 | 股票赢家—输家、行业/ETF 轮动 |

横截面动量的经典结论是经验性的，不是市场必然规律。它必须同时处理形成期与持有期重叠、行业中性、风险暴露、借券和交易成本；否则“赢家收益”可能只是行业、规模、市场 beta 或流动性风险的重新命名。

### 4.2 排名、组合与风险调整的数学表达

#### 形成期收益与排名

对 \(N_t\) 个可交易资产，回看 \(L\) 个月、可选跳过最近 \(J\) 个月，形成期收益为：

\[
R_{i,t}^{(L,J)}
=\prod_{u=t-L-J+1}^{t-J}(1+r_{i,u})-1.
\]

**变量、直觉与实现映射：** \(J=0\) 使用最新收益，\(J=1\) 跳过最近一个月以减弱短期反转；\(L=12,J=1\) 是经典中期动量的常见近似。形成日 \(t\) 只能使用已结束的 \(t-J\) 数据，持有期从下一交易窗口开始。

令 \(rank_t(i)\) 是 \(R_{i,t}^{(L,J)}\) 的降序排名。Top-\(K\) long-only 权重为：

\[
w_{i,t}^{TopK}
=\frac{\mathbb I(rank_t(i)\le K)}
{\sum_{j=1}^{N_t}\mathbb I(rank_t(j)\le K)}.
\]

**变量、直觉与实现映射：** 每期只持有前 \(K\) 个资产并等权；若 \(K=1\)，集中度高、换手和单资产风险都高；增大 \(K\) 可提高分散化但稀释信号。

多空赢家—输家组合常写为：

\[
r_{p,t+1}^{LS}
=\frac1K\sum_{i\in Winner_t}r_{i,t+1}
-\frac1K\sum_{j\in Loser_t}r_{j,t+1}.
\]

**变量、直觉与实现映射：** 多空结构减少市场 beta，但引入借券、融资、保证金、短腿挤压和尾部损失。French MOM 因子就是这类公开定义的股票多空代理之一，但它的构造细节、规模分组和再平衡不能被简单等同于个人投资者的 Top-K long-only。

#### 约束与风险中性

为减少行业和市场暴露，可在形成日对初始分数做残差化：

\[
score_{i,t}^{res}
=score_{i,t}
-\hat\gamma_t^\top z_{i,t}^{risk},
\qquad
\hat\gamma_t
=\arg\min_\gamma
\sum_i(score_{i,t}-\gamma^\top z_{i,t}^{risk})^2.
\]

其中 \(z^{risk}\) 可包含行业哑变量、规模、beta、波动率和流动性；残差化只能减少已登记的线性暴露，不能消除非线性或未来状态变化。

对连续仓位，可按风险调整后的动量评分排序：

\[
Q_{i,t}=\frac{R_{i,t}^{(L,J)}}{\hat\sigma_{i,t}}
-\lambda_\beta\hat\beta_{i,t}
-\lambda_c\widehat{cost}_{i,t}.
\]

**变量、直觉与实现映射：** \(Q\) 把收益、波动、市场 beta 和交易成本放在同一排序框架，但 \(\lambda\) 必须在训练/验证区间预先登记；否则它只是回测后调参。

### 4.3 持有期重叠、换手与统计推断

经典动量常用 \(J=1\) 的跳过最近月和 \(K_h\) 月持有期。若每月形成一个新组合，任意时点同时存在 \(K_h\) 个 vintage 组合，组合收益是：

\[
r_{p,t}
=\frac1{K_h}\sum_{h=0}^{K_h-1}
r_{p,t}^{(formation=t-h)}.
\]

**变量、直觉与实现映射：** 重叠持有使收益序列具有序列相关，不能把每个月观察当成独立样本；显著性需要 HAC/Newey–West、block bootstrap 或按形成期聚类。

换手由目标权重与实际漂移权重差异决定：

\[
\operatorname{Turnover}_t
=\frac12\sum_i|w_{i,t}^{target}-w_{i,t}^{pre}|,
\qquad
r_{p,t}^{net}=r_{p,t}^{gross}-c_t\operatorname{Turnover}_t.
\]

**变量、直觉与实现映射：** \(c_t\) 应拆成佣金、点差、冲击、借券、融资和税费；动量策略的短形成窗口、Top-1 集中仓位和频繁重排会使成本与容量成为一阶问题。

### 4.4 统计特征与典型失败模式

横截面动量的统计风险可概括为：

1. **中期延续、短期反转：** 过去 3–12 个月的相对收益可能延续，但最近几周的极端赢家/输家可能因流动性和价格压力反转，因此形成期与跳过期必须明确。
2. **动量崩溃（momentum crash）：** 市场急剧反弹时，危机前做空/低配的输家突然大涨，赢家组合相对落后；Daniel 与 Moskowitz 对这种状态依赖有专门讨论。
3. **负偏或厚尾：** 多空动量在少数快速反转中出现大损失，均值和 Sharpe 不能单独描述风险。
4. **行业/规模聚集：** 横截面赢家可能集中于同一行业或小盘股，所谓 alpha 可能是未控制的暴露。
5. **持有期重叠与显著性膨胀：** 多个窗口、跳过期、Top-K 和行业约束构成一个实验族，需要记录选择次数。
6. **容量与冲击：** 赢家—输家交易常发生在价格已大幅变化后，点差和市场冲击可能随信号强度上升。
7. **短腿与融资风险：** 多空策略的账面收益可被借券费、召回、涨停和保证金挤压。

因此本章除平均收益、CAGR、Sharpe 和 MDD 外，还应报告：

| 指标 | 目的 |
|---|---|
| Top-K 集中度/有效持仓数 | 判断是否被少数资产支配 |
| 行业和 beta 暴露 | 区分动量信号与风险暴露 |
| 年化换手、成本占比 | 判断毛收益能否转为净收益 |
| 最差月、最差连续期 | 识别 momentum crash |
| 多空腿分别收益 | 检查收益来自赢家、输家还是两者 |
| 形成期/持有期敏感性 | 检查参数稳定性 |
| HAC t 值、block bootstrap CI | 处理序列相关和非正态 |

### 4.5 股票横截面动量

股票动量的典型研究对象是个股或行业组合。研究契约需要冻结：

- 股票池是全市场、仅存活股票还是指数成员；
- 形成期价格是否使用复权总回报；
- 财报/公司行动/退市回报是否点时可用；
- 是否跳过最近一个月；
- Top-K 或赢家—输家分位数；
- 是否行业中性、规模中性和 beta 中性；
- 交易时点、限价/市价、点差、冲击、借券和涨跌停处理。

对个股，多空动量通常比 ETF 轮动更依赖底层数据质量。若没有退市收益，输家腿会被幸存者偏差系统性抬高；若只使用当前指数成分，历史赢家已经被筛选进样本，也会夸大动量。

### 4.6 黄金与跨资产相对强弱

单一黄金资产不能构造横截面排名，因此本章用 SPY（股票）、GLD（黄金）、SLV（白银）和 TLT（长期国债）构造小型跨资产代理。它回答的问题是：“在同一月末，过去 12 个月相对最强的资产是否值得进入下一月组合？”而不是“黄金本身是否有动量”。

黄金相关资产的相对强弱还存在额外边界：

| 问题 | 影响 |
|---|---|
| GLD 与 SLV 受美元和实际利率共同驱动 | 排名信号可能只是金属 beta |
| TLT 受利率周期驱动 | top-1 可能在危机期集中到债券 |
| ETF 上市日期不同 | 交集样本缩短且存在代理选择 |
| 资产交易时段不同 | 月末收盘时间不一致可能造成排序错位 |
| 低频排名仍需换手 | top-1 每月切换，成本和税费不可忽略 |

### 4.9 与价值、趋势和风险模型的组合

横截面动量的主要组合方式包括：

1. **价值 + 动量：** 用价值找相对便宜资产，用动量避免过早接住持续下跌的价值陷阱；组合时应报告两个信号的相关性和各自贡献。
2. **时间序列 + 横截面动量：** 先判断资产自身趋势为正，再在可持有资产中按横截面排名，减少把最强但处于下跌趋势的资产买入。
3. **动量 + 波动率目标：** 对 Top-K 资产单独缩放波动，防止高波动黄金/白银或单一股票支配组合。
4. **动量 + 行业/资产上限：** 对行业、金属、利率和股票设置集中度约束，避免排名结果变成单一宏观下注。
5. **动量 + 风险平价：** 让信号决定方向，让风险模型决定资金；不要使用动量分数直接替代组合风险预算。

### 4.10 实现伪代码：排名、持有期与成本

~~~python
def cross_sectional_momentum(prices, lookback=12, skip=1, top_k=2, cost_bps=10):
    # 1) 计算形成期收益；skip=1 跳过最近一个月以减少短期反转污染。
    formation_return = prices.pct_change(lookback).shift(skip)

    # 2) 每个月只用已经完成的数据，选出横截面 Top-K。
    target_weights = rank_to_equal_weight(formation_return, top_k)

    # 3) 目标权重作用于下一个月收益，避免把本期收盘排名用于本期成交。
    realized_return = prices.pct_change() * target_weights
    gross = realized_return.sum(axis=1)

    # 4) 计算权重变化并扣除单边成本；空缺资产需要重新归一化。
    turnover = target_weights.diff().abs().sum(axis=1)
    turnover.iloc[0] = target_weights.iloc[0].abs().sum()
    net = gross - cost_bps / 10000.0 * turnover

    # 5) 输出分腿收益、集中度、行业/beta 暴露及回撤统计。
    return build_momentum_ledger(gross, net, target_weights, turnover)
~~~

### 4.11 失败模式与风险边界

- **把横截面排名当作时间序列趋势：** 相对最强资产可能仍然下跌，必须明确 long-only 还是允许做空。
- **没有跳过最近月：** 短期反转可能混入中期动量，导致规则定义与经典文献不一致。
- **忽略成分和退市：** 当前股票池或 ETF 清单会产生幸存者偏差。
- **Top-1 过度集中：** 本地 Top-1 MDD −43.55%，且年化换手约 6 倍，显示集中和成本风险。
- **忽略行业/beta：** 动量收益可能只是科技、金属或利率方向暴露。
- **把 French MOM 当成长线净收益：** 官方因子是多空组合，借券、融资、税费和执行未在本地摘要中实现。
- **低估动量崩溃：** 急剧反弹、政策转向或流动性恢复会使此前输家快速上涨。
- **重复测试参数：** 回看期、skip、Top-K、持有期、行业约束和风险缩放构成大型实验族，必须登记并修正推断。

### 4.12 本章结论与后续接口

横截面动量的有效单位不是“买强卖弱”四个字，而是形成期、跳过期、持有期、排名池、风险中性、换手成本和崩溃保护的完整契约。官方 MOM 因子显示长期正均值伴随严重回撤和样本期衰减；四资产代理进一步显示 Top-2 比 Top-1 更稳健，但简单等权组合仍可能拥有更好的 Sharpe 和最大回撤。

## 模型章节 05：均值回复、配对交易与统计套利

### 5.1 模型定位：交易“偏离会收敛”，而不是交易单边方向

均值回复（mean reversion）假设某个价格、收益、价差或残差偏离其稳定中心后，未来具有向中心回归的倾向。配对交易（pairs trading）把这种假设用于两个经济相关资产的相对价格；统计套利（statistical arbitrage）则把价差扩展到多资产、因子残差和大量小型相对价值头寸。

它们与动量模型的差异是：

| 维度 | 动量/趋势 | 均值回复/配对 |
|---|---|---|
| 核心假设 | 方向会持续 | 偏离会收敛 |
| 入场 | 顺着已有方向 | 逆着偏离方向 |
| 主要收益形态 | 少数长趋势贡献大收益 | 多数小幅收敛，少数结构断裂造成大亏损 |
| 主要风险 | whipsaw、突然反转 | 接飞刀、协整失效、无限等待 |
| 退出 | 趋势反转/均线穿越 | 价差回到中心、止损或最大持有期 |

均值回复最危险的误区是把“历史上回到过均值”写成“未来一定回归”。只要均值本身移动、经济关系断裂、资本结构变化或交易载体改变，价差就可能在新水平稳定，甚至持续发散。

### 5.2 单变量均值回复：AR(1) 与 Ornstein–Uhlenbeck

离散时间的一阶自回归模型为：

\[
x_t-\mu
=\phi(x_{t-1}-\mu)+\varepsilon_t,
\qquad
\varepsilon_t\sim(0,\sigma_\varepsilon^2).
\]

当 \(|\phi|<1\) 时，冲击的条件期望按 \(\phi^h\) 衰减；若 \(\phi\) 接近 1，回复很慢；若 \(\phi=1\)，过程含单位根，固定均值假设失效。

**变量、直觉与实现映射：** \(x_t\) 可是价差、估值残差或收益状态，\(\mu\) 是长期中心，\(\phi\) 是持续性。代码中用形成窗口拟合 \(\hat\phi\)，而不能用全样本拟合后回填历史信号。

AR(1) 的启发式半衰期是：

\[
h_{1/2}=-\frac{\ln 2}{\ln|\phi|}.
\]

**变量、直觉与实现映射：** 半衰期表示预期偏离衰减一半所需周期；它不是强制退出日期。当 \(\hat\phi\) 接近 1 时，半衰期对估计误差极敏感，应报告置信区间和滚动稳定性。

连续时间 Ornstein–Uhlenbeck（OU）过程写为：

\[
dx_t=\kappa(\mu-x_t)\,dt+\sigma\,dW_t,
\qquad \kappa>0.
\]

**变量、直觉与实现映射：** \(\kappa\) 是均值回复速度，\(\sigma\) 是扩散波动，\(W_t\) 是布朗运动；OU 是价差建模的理想化基线，不意味着资产价格本身可以无边界地围绕常数均值波动。

### 5.3 配对价差、对冲比率与协整

设两个价格序列为 \(P_{A,t}\) 与 \(P_{B,t}\)，对数价差可写为：

\[
x_t=\log P_{A,t}-\alpha-\beta\log P_{B,t}.
\]

\(\beta\) 是 hedge ratio（对冲比率），可由形成窗口 OLS、总最小二乘、Kalman filter 或经济价值比率估计。价格高度相关并不意味着 \(x_t\) 平稳：相关性描述共同波动，协整（cointegration）要求某个线性组合消除共同随机趋势。

Engle–Granger 两步法的核心是：

\[
\log P_{A,t}
=\alpha+\beta\log P_{B,t}+u_t,
\qquad
\Delta u_t
=\gamma u_{t-1}
+\sum_{j=1}^{p}\psi_j\Delta u_{t-j}
+\eta_t.
\]

**变量、直觉与实现映射：** 第一步估计长期关系，第二步检验残差 \(u_t\) 是否平稳；\(\gamma<0\) 表示误差修正。ADF 临界值在估计残差场景下不是普通 t 分布；正式研究需使用正确 Engle–Granger/Johansen 临界值和滞后选择。本章环境没有安装正式协整包，因此不伪造 p 值。

### 5.4 z-score 入场、退出与组合收益

在形成窗口 \(W\) 上估计价差中心和尺度：

\[
z_t=\frac{x_t-\hat\mu_{t,W}}{\hat\sigma_{t,W}}.
\]

经典规则是：

\[
q_t=
\begin{cases}
-1,&z_t\ge z_{entry},\\
+1,&z_t\le-z_{entry},\\
0,&\text{价差回到 }z_{exit}\text{ 或触发止损}.
\end{cases}
\]

**变量、直觉与实现映射：** \(q=+1\) 表示做多价差（多 A、空 \(\beta\) 单位 B），\(q=-1\) 表示做空价差。信号必须延迟到下一交易时点；若价差仍在开仓方向扩大，不应不断加码而不设风险上限。

把总名义暴露规范化后：

\[
w_{A,t}=\frac{q_t}{1+|\beta_t|},
\qquad
w_{B,t}=-\frac{q_t\beta_t}{1+|\beta_t|},
\]

\[
r_{p,t+1}^{net}
=w_{A,t}r_{A,t+1}
+w_{B,t}r_{B,t+1}
-c_t\left(
|\Delta w_{A,t}|+|\Delta w_{B,t}|
\right).
\]

**变量、直觉与实现映射：** 规范化使两条腿的绝对权重和约为 1，避免 \(\beta\) 大时隐含高杠杆；真实账户还需计入空头借券、融资、股息、期货保证金和不同交易时段。

### 5.5 统计特征：高胜率为何仍可能亏损

配对交易常出现“多数交易小赚、少数交易大亏”的分布：

1. **负偏与厚尾：** 价差正常收敛时利润有限，结构断裂时损失可持续扩大。
2. **收益序列自相关：** 同一交易跨越多日，不能把每日 P&L 当作独立样本。
3. **参数估计误差：** \(\beta\)、均值、波动和半衰期同时估计，误差会叠加到仓位。
4. **多重检验：** 从上千对股票中选择历史最平稳的配对，本身是大规模模型选择。
5. **容量与融资：** 表面市场中性不等于资本中性；短腿借券和极端波动会放大资金压力。
6. **共同因子残留：** 行业 beta、商品 beta、实际利率和美元风险可能仍存在。

因此至少报告：

| 指标 | 说明 |
|---|---|
| 交易次数、胜率 | 只描述频率，不能替代平均盈亏 |
| 平均/中位交易收益 | 检查分布是否被少数尾部主导 |
| 最好/最差交易 | 识别结构断裂损失 |
| 平均/中位持有期 | 评估资金占用和半衰期一致性 |
| 年化换手和成本占比 | 判断价差利润能否覆盖执行 |
| 滚动 \(\beta,\phi,h_{1/2}\) | 检查关系稳定性 |
| MDD 与回撤持续期 | 衡量“等待收敛”的账户风险 |
| ADF/Johansen 与结构断裂检验 | 区分平稳价差和伪回归 |

### 5.6 股票配对与多资产统计套利

股票配对通常从同一行业、商业模式或共同因子暴露中寻找候选：

1. 形成期按标准化价格距离、相关性或协整统计筛选；
2. 冻结候选对和 hedge ratio 估计方法；
3. 交易期只更新允许的滚动参数；
4. 对财报、并购、分拆、指数调整和借券变化设置事件停牌规则；
5. 保存未盈利和结构断裂的配对，而不是只报告存活赢家。

统计套利可扩展到因子残差：

\[
r_{i,t}
=\alpha_i+\boldsymbol\beta_i^\top\mathbf f_t+\varepsilon_{i,t},
\qquad
z_{i,t}
=\frac{\sum_{u=t-W+1}^{t}\varepsilon_{i,u}}
{\widehat{\sigma}_{\varepsilon_i,t}}.
\]

**变量、直觉与实现映射：** \(\mathbf f_t\) 是市场、行业、价值、动量等公共因子；交易对象是残差累积而非原始价格。组合需同时约束市场、行业、风格和单名暴露，否则“统计套利”可能只是隐含因子下注。

### 5.7 黄金、白银与金银价差

黄金和白银具有共同贵金属驱动，但经济用途、工业需求、库存、波动率和市场规模不同。GLD–SLV 高相关不等于它们的对数价格存在稳定协整关系；金银比也可能因产业结构、货币制度和危机需求发生永久变化。

本章的 GLD–SLV 例子使用滚动 252 日 log-price OLS 和残差 z-score，目的不是推荐金银配对，而是展示：

- 相关资产的价差仍可长期不回归；
- 估计半衰期接近一年时，日频 z-score 交易资金占用很长；
- 胜率超过 50% 仍可能因一个结构断裂交易而总体亏损；
- 黄金 ETF 与白银 ETF 还包含不同费率、流动性和跟踪误差。

| 最大回撤 | −28.46% | −30.72% |

### 5.10 与趋势、价值和波动模型的组合

1. **配对 + 趋势过滤：** 只有当价差长期趋势未发生结构突破时执行短期均值回复；趋势过滤降低交易频率但可能错过正常回归。
2. **配对 + 事件过滤：** 财报、并购、分拆、指数调整、央行政策和商品供应冲击前暂停新仓，避免把基本面断裂当作统计偏离。
3. **配对 + 波动率目标：** 按残差波动缩放，而不是仅用 z-score 决定仓位；设置单对、行业和总 gross 上限。
4. **残差统计套利 + 因子中性：** 先剔除市场、行业、价值和动量因子，再交易残差；需报告因子暴露漂移。
5. **均值回复 + 动量组合：** 两类策略在不同状态下可能互补，但同一资产上可能产生相互抵消的频繁交易，必须在组合层统一净仓位。

### 5.11 实现伪代码：滚动估计、滞后与失败保留

~~~python
def rolling_pair_trade(price_a, price_b, window=252, entry_z=2.0, cost_bps=5):
    # 1) 每日只用过去 window 天对数价格估计 alpha、beta 和残差尺度。
    rolling_beta, rolling_z = rolling_log_price_regression(price_a, price_b, window)

    # 2) z 超过阈值时反向交易价差，回到 0 才平仓；状态机防止每日重复开仓。
    raw_position = state_machine(rolling_z, entry=entry_z, exit=0.0)

    # 3) 信号和 hedge ratio 均延迟一天，避免当日收盘信息用于当日收益。
    position = raw_position.shift(1)
    beta = rolling_beta.shift(1)

    # 4) 规范化两腿名义暴露，并显式记录权重变化。
    weight_a = position / (1.0 + beta.abs())
    weight_b = -position * beta / (1.0 + beta.abs())
    turnover = weight_a.diff().abs() + weight_b.diff().abs()

    # 5) 扣除成本，保存每笔交易、持有期、尾部损失和滚动参数。
    gross = weight_a * price_a.pct_change() + weight_b * price_b.pct_change()
    net = gross - cost_bps / 10000.0 * turnover
    return build_pair_ledger(net, rolling_z, beta, position)
~~~

### 5.12 失败模式与风险边界

- **相关性冒充协整：** 高相关价格可以共同随机游走，价差不存在稳定均值。
- **全样本选对和估参：** 使用未来数据筛选最稳定配对，是典型数据窥探。
- **固定 hedge ratio：** 企业杠杆、商品用途和市场结构变化会使 \(\beta\) 漂移。
- **无限加仓：** z-score 越极端不一定越安全；结构断裂时反向加仓会放大尾部损失。
- **胜率幻觉：** 本地 58.62% 胜率仍对应负 CAGR 和 −30.72% MDD。
- **忽略借券和融资：** 多空价差的市场 beta 较低，但资本占用、保证金和 short squeeze 仍显著。
- **半衰期误用：** \(\hat\phi\) 接近 1 时半衰期极不稳定，不能把估计值当作硬退出时间。
- **缺少结构断裂测试：** 产业、政策、并购和指数成分变化可永久改变价差中心。
- **多重检验：** 数千资产对、窗口、阈值和止损组合会产生大量伪显著策略。

### 5.13 本章结论与后续接口

均值回复和统计套利的关键不是 z-score 本身，而是证明交易对象存在足够稳定的经济或统计关系，并为关系失效设置退出、仓位和组合边界。GLD–SLV 反例显示，高胜率、正中位交易和低表面波动仍可能被少数尾部损失击穿；因此协整、结构断裂、成本和最差交易必须与平均收益同时报告。

下一并列章节将研究**低波动、质量、规模与多因子股票模型**，把单一因子收益、组合暴露、因子拥挤和因子间组合放在同一章节内。

## 模型章节 06：低波动、质量、规模与多因子股票模型

### 6.1 模型定位：把“风格”变成可解释的风险暴露

因子模型（factor model）把资产收益分解为公共风险因子、个体残差和可估计的暴露。低波动、质量、规模和价值不是彼此独立的“神奇标签”，而是不同的排序、组合和风险约束方式。研究目标不是简单找出过去收益最高的因子，而是回答：

- 因子定义是否有经济解释；
- 排序字段是否在形成日可用；
- 组合收益来自风险补偿、行为偏差还是数据挖掘；
- 因子之间是否高度相关、互相抵消或在压力期同时失效；
- 长-only 产品与论文中的多空因子是否具有相同收益和回撤。

因子模型最适合股票横截面，但不能直接把股票 SMB/HML/RMW/CMA 套到黄金现货。黄金应继续使用实际利率、美元、通胀、风险厌恶和期限结构等宏观状态变量；跨资产组合可以用因子暴露做风险归因，但不能假设所有资产共享同一套会计因子。

### 6.2 因子组合与收益回归的数学表达

#### 排序因子

对形成日的特征 \(x_{i,t}\)（例如 B/M、盈利能力、投资强度或历史波动率）排序，将资产分为高组 \(H_t\) 与低组 \(L_t\)，因子收益为：

\[
F_t=\sum_{i\in H_t}w_{i,t}^{H}r_{i,t}
-\sum_{j\in L_t}w_{j,t}^{L}r_{j,t}.
\]

**变量、直觉与实现映射：** \(F_t\) 是高特征组合减低特征组合的多空收益；\(w^H,w^L\) 可等权或市值加权。形成规则、分位点、行业约束和再平衡频率决定了因子本身，不能只写“买高卖低”。

Fama–French 五因子常用市场、规模、价值、盈利能力和投资因子：

\[
R_{i,t}^{e}
=\alpha_i
+\beta_{M,i}MKT_t
+\beta_{S,i}SMB_t
+\beta_{H,i}HML_t
+\beta_{R,i}RMW_t
+\beta_{C,i}CMA_t
+\varepsilon_{i,t}.
\]

**变量、直觉与实现映射：** \(R_i^e=R_i-R_f\) 是超额收益，\(MKT\) 是市场超额收益，SMB 是小盘减大盘，HML 是高 B/M 减低 B/M，RMW 是高盈利减低盈利，CMA 是保守投资减激进投资。回归 alpha 只是模型未解释部分，不自动等于交易后 alpha。

#### 低波动与风险加权

最简单的低波动评分是过去窗口的实现波动：

\[
\hat\sigma_{i,t}
=\sqrt{K\cdot\operatorname{Var}
\left(r_{i,t-W+1:t}\right)},
\qquad
w_{i,t}^{invvol}
=\frac{\hat\sigma_{i,t}^{-1}}
{\sum_j\hat\sigma_{j,t}^{-1}}.
\]

**变量、直觉与实现映射：** 逆波动权重降低高波动资产的名义权重；它不是最小方差组合，因为忽略协方差。最小方差优化为：

\[
\min_{\mathbf w}\ \mathbf w^\top\hat\Sigma_t\mathbf w,
\qquad
\mathbf1^\top\mathbf w=1,\quad
\mathbf w\in\mathcal C.
\]

其中 \(\hat\Sigma_t\) 是滚动协方差，\(\mathcal C\) 可包含 long-only、单名、行业和换手约束。估计误差会使无约束最小方差权重极端集中，因此收缩协方差和权重上限是模型的一部分。

#### 质量与综合评分

质量因子可组合盈利能力、盈利稳定性、现金流、杠杆和应计项：

\[
Q_{i,t}
=\lambda_1z(ROIC_{i,t})
+\lambda_2z(FCF/Assets_{i,t})
-\lambda_3z(Leverage_{i,t})
-\lambda_4z(Accruals_{i,t}).
\]

多因子排序可写为：

\[
S_{i,t}
=\sum_{k=1}^{K}\lambda_k z_{i,k,t},
\qquad
\sum_k|\lambda_k|=1.
\]

**变量、直觉与实现映射：** \(z_{i,k,t}\) 需在形成日按行业/规模标准化；\(\lambda_k\) 应由研究协议预先冻结，不能在测试集上选择。综合分数还要记录每个子因子的边际贡献，否则“多因子”只是把不可解释的调参隐藏起来。

### 6.3 四类因子的经济直觉与统计特征

| 因子 | 典型特征 | 可能解释 | 主要风险 |
|---|---|---|---|
| 规模 SMB | 小盘相对大盘 | 流动性、融资和风险补偿 | 交易成本、容量、长期衰减 |
| 价值 HML | 高 B/M 或高盈利收益率 | 过度外推、风险补偿、资产重估 | 价值陷阱、行业集中、长时间失效 |
| 质量 RMW | 高盈利、稳定现金流、低杠杆 | 经营质量与生存概率 | 指标定义、会计修订、成长暴露 |
| 投资 CMA | 保守投资减激进投资 | 资本配置与预期增长 | 周期行业、会计口径和规模相关性 |
| 低波动 | 低历史波动或低 beta | 杠杆约束、彩票偏好、基准约束 | 利率、行业集中、拥挤和低波失效 |

因子收益的统计特征包括：

1. **非平稳的均值：** 长样本正均值可被几十年的负或零收益阶段抵消。
2. **因子相关性：** 价值、质量、低波和规模可能有共同的行业或盈利暴露。
3. **多空尾部：** 因子多空组合在市场急转、融资收缩和拥挤解除时同时亏损。
4. **收益不等于可交易净收益：** 论文因子通常忽略税费、借券、冲击和产品管理费。
5. **因子定义漂移：** B/M 在无形资产密集行业中解释力下降；ROE 受回购和杠杆影响；历史波动受窗口和价格频率影响。
6. **因子拥挤与容量：** 越多资金使用同一公开排序，越可能降低未来净收益和提高共振回撤。

### 6.4 股票实现的形成、约束与回归评估

一个可复查的股票因子管线应包括：

1. 在点时形成日读取最新可用价格、财报、公司行动和退市状态；
2. 对负盈利、异常账面值、极端杠杆和流动性不足做事前规则过滤；
3. 行业内 winsorization 与标准化，避免行业构成替代因子本身；
4. 按分位数组合，冻结市值/等权方式和再平衡；
5. 记录因子组合 gross/net 收益、换手、行业、规模、beta 和容量；
6. 用时序回归和横截面回归检验 alpha 与因子暴露，使用 HAC 或 block bootstrap；
7. 保留失败候选和参数选择次数，不把最优因子排序当作唯一结果。

低波动策略尤其要区分：

- **低波动排序：** 直接选择历史波动最小资产；
- **最小方差优化：** 使用协方差矩阵求最小组合方差；
- **低 beta：** 对市场 beta 排序，可能与低波动但不等价；
- **波动率目标：** 对整个策略加杠杆或减杠杆，不等于低波动股票因子。

### 6.5 黄金与跨资产的因子边界

黄金没有 SMB、HML 或 RMW 的企业会计字段，因此本报告不把黄金塞入股票五因子回归。黄金的跨资产因子可以使用：

\[
r_{gold,t+1}
=\alpha
+\beta_1\Delta(-y^{real}_t)
+\beta_2\Delta USD_t
+\beta_3\Delta\pi_t^e
+\beta_4\Delta Risk_t
+\varepsilon_{t+1}.
\]

这个宏观回归与股票质量/规模因子是不同模型，组合时应在风险归因表中单独列出。黄金可以作为低波动/质量股票组合的防御资产，但“低波动股票 + 黄金”仍可能共同暴露于美元、实际利率或流动性冲击。

### 6.8 多因子组合与风险归因

多因子组合可以使用三种方式：

1. **独立袖套（sleeve）：** 价值、质量、低波和规模各占预先登记的名义权重，易解释但忽略因子相关性。
2. **风险平价因子组合：** 对因子收益协方差做风险贡献平衡，避免高波因子主导组合。
3. **综合排序：** 将标准化因子分数合成一个股票分数，再做行业和风险约束；集中度低但因子贡献更难解释。

组合风险归因可写为：

\[
\operatorname{Var}(r_p)
=\mathbf w_F^\top\Sigma_F\mathbf w_F
+\mathbf w_\varepsilon^\top\Sigma_\varepsilon\mathbf w_\varepsilon
+2\mathbf w_F^\top\operatorname{Cov}(F,\varepsilon)\mathbf w_\varepsilon.
\]

**变量、直觉与实现映射：** \(\mathbf w_F\) 是因子暴露，\(\Sigma_F\) 是因子协方差，残差项是个股特异风险。组合优化不能只看因子平均收益；需要报告风险贡献、因子相关、最大回撤和成本敏感性。

### 6.9 实现伪代码：因子形成、约束和净收益

~~~python
def multifactor_portfolio(asof_date, point_in_time_data, prices):
    # 1) 读取形成日之前可见的价值、质量、规模、投资和波动字段。
    data = point_in_time_data(asof_date)

    # 2) 行业内 winsorize/standardize，减少行业构成和极端值的伪影响。
    value = robust_industry_zscore(data["book_to_market"])
    quality = robust_industry_zscore(data["roic"]) - robust_industry_zscore(data["leverage"])
    size = -robust_zscore(data["market_cap"])
    low_vol = -robust_zscore(data["realized_volatility"])

    # 3) 组合分数权重必须在研究协议中冻结，不能用测试结果调节。
    score = 0.30 * value + 0.30 * quality + 0.20 * size + 0.20 * low_vol

    # 4) 先做行业、beta、单名和流动性约束，再计算目标权重。
    target = constrained_rank_portfolio(score, data, max_sector=0.20, max_single=0.02)

    # 5) 以下一交易窗口成交，扣除换手成本并记录因子/行业风险贡献。
    realized = execute_next_period(target, prices)
    net = realized.gross_return - realized.turnover * realized.cost_model
    return factor_ledger(net, target, realized.exposures)
~~~

### 6.10 失败模式与风险边界

- **把论文多空因子当作 ETF 净收益：** 因子含空头、融资、再平衡和不可见交易成本。
- **财报未来函数：** 使用修订后或尚未发布数据会抬高质量、价值和盈利能力结果。
- **低波动集中行业：** 低波动组合可能集中于公用事业、金融或防御消费，危机类型改变时风险会跃迁。
- **质量与成长重叠：** 高 ROIC/高利润率常与成长暴露相关，不能把所有收益归为质量。
- **规模因子成本高：** 小盘股票点差、容量、停牌和退市风险可能吞噬 SMB。
- **因子拥挤：** 多因子 ETF 与主动产品共享筛选规则，拥挤解除会产生共振回撤。
- **协方差估计误差：** 风险平价或最小方差组合对协方差窗口、收缩强度和缺失数据敏感。
- **跨资产因子错配：** 不能把 HML/RMW/CMA 直接解释黄金的实际利率和美元风险。
- **多重检验和参数自由度：** 因子定义、分位数、行业中性、再平衡和权重选择都必须登记。

### 6.11 本章结论与后续接口

低波动、质量、规模和多因子模型的核心贡献是把股票横截面差异转为可解释的风险暴露和组合约束，而不是提供一张永远有效的收益排行榜。官方五因子结果显示，因子长期平均收益与严重回撤并存；ETF 代理显示低波动可能降低波动但牺牲 CAGR，质量和规模结果对窗口与行业暴露敏感。

## 模型章节 07：波动率目标、风险平价与动态风险管理

### 7.1 模型定位：先决定“承受多少风险”，再决定名义仓位

波动率目标（volatility targeting）和风险平价（risk parity）都把风险估计放在资产选择之前，但两者解决的问题不同：

| 模型 | 主要问题 | 输出 |
|---|---|---|
| 波动率目标 | 单个策略或组合应承受多少年化波动 | 总杠杆/去杠杆倍数 |
| 逆波动加权 | 如何让高波动资产少占名义权重 | 资产名义权重 |
| 风险平价 | 如何让各资产对组合风险贡献接近目标预算 | 资产权重，使 \(RC_i\approx b_i\sigma_p\) |
| 最小方差 | 在约束下最小化组合方差 | 依赖协方差矩阵的最优权重 |
| 动态去杠杆 | 回撤、波动或压力状态发生时如何降低风险 | 状态依赖的仓位上限 |

这些模型不是收益预测器。它们通常假设收益信号已经存在，只改变暴露尺度；若预测波动错误、相关性在危机期跃迁或现金收益被忽略，风险管理层可能降低收益而没有按目标降低回撤。

### 7.2 波动率预测与波动率目标

最简单的滚动波动率预测为：

\[
\hat\sigma_{t,W}
=\sqrt{K\cdot\frac1{W-1}
\sum_{j=1}^{W}(r_{t-j}-\bar r_{t,W})^2}.
\]

**变量、直觉与实现映射：** \(W\) 是观察窗口，\(K\) 是年化因子；只使用 \(t-1\) 及以前的收益。短窗口响应快但噪声大，长窗口稳定但在危机初期反应慢。

EWMA（指数加权移动平均）为：

\[
\hat\sigma_t^2
=(1-\lambda)r_{t-1}^2+\lambda\hat\sigma_{t-1}^2,
\qquad 0<\lambda<1.
\]

**变量、直觉与实现映射：** \(\lambda\) 越大，旧信息衰减越慢；EWMA 保证预测方差非负，但仍面临衰减参数和初值选择。GARCH(1,1) 在此基础上增加常数项与长期方差约束：

\[
\sigma_t^2=\omega+\alpha r_{t-1}^2+\beta\sigma_{t-1}^2,
\qquad
\omega>0,\ \alpha,\beta\ge0,\ \alpha+\beta<1.
\]

对目标年化波动 \(\sigma^*\)，总仓位倍数为：

\[
\ell_t
=\operatorname{clip}\!\left(
\frac{\sigma^*}{\hat\sigma_t},
0,\ell_{\max}\right),
\qquad
r_{p,t+1}^{VT}
=\ell_t r_{p,t+1}
+(1-\ell_t)r_{f,t+1}.
\]

**变量、直觉与实现映射：** \(\ell_t<1\) 表示去杠杆并持有现金，\(\ell_t>1\) 表示借入资金放大风险资产；杠杆上限、保证金、融资利率和交易成本必须写入协议。实际波动不会恰好等于 \(\sigma^*\)，因为预测误差、跳跃、相关性变化和滞后都会产生偏离。

### 7.3 风险平价与风险贡献

组合波动率为：

\[
\sigma_p(\mathbf w)
=\sqrt{\mathbf w^\top\Sigma\mathbf w}.
\]

资产 \(i\) 的边际风险贡献（MRC）与总风险贡献（RC）为：

\[
MRC_i=\frac{\partial\sigma_p}{\partial w_i}
=\frac{(\Sigma\mathbf w)_i}{\sigma_p},
\qquad
RC_i=w_i\,MRC_i.
\]

**变量、直觉与实现映射：** \(RC_i\) 衡量资产 \(i\) 对组合总波动的贡献，\(\sum_iRC_i=\sigma_p\)。风险平价指定预算 \(b_i\)：

\[
RC_i=b_i\sigma_p,\qquad
\sum_i b_i=1.
\]

两资产且相关性相近时，逆波动权重 \(w_i\propto1/\hat\sigma_i\) 接近风险平价；相关性不同时，必须用协方差矩阵求解，不能把逆波动加权误写成精确 ERC（equal risk contribution）。

一个带约束的风险平价目标可写为：

\[
\min_{\mathbf w}
\sum_i\left(
\frac{RC_i(\mathbf w)}{\sigma_p(\mathbf w)}-b_i
\right)^2
+\gamma\|\mathbf w-\mathbf w_{t-1}\|_1,
\]

\[
\mathbf1^\top\mathbf w=1,\quad
\mathbf w\in\mathcal C.
\]

**变量、直觉与实现映射：** 第一项逼近风险预算，第二项惩罚换手；\(\mathcal C\) 可包括 long-only、单名上限、杠杆和行业约束。协方差估计错误会通过非线性优化变成权重集中，因此收缩、平滑和压力测试是模型的一部分，而非事后修补。

### 7.4 动态风险管理的统计特征

动态风险模型的核心统计难点是：

1. **波动聚集：** 大波动往往成簇出现，固定杠杆会在危机期承担过高风险。
2. **预测滞后：** 使用过去收益估计未来波动，突然跳跃时无法提前去杠杆。
3. **负相关与相关性跃迁：** 股票和黄金在正常时期可能分散，但危机时相关性、美元和流动性会同时变化。
4. **波动率拖累：** 频繁缩放可能在高波动后低位减仓、低波动后高位加仓，损失复合收益。
5. **杠杆与融资：** 目标波动低不代表资本安全；杠杆、保证金、融资利率和流动性决定尾部损失。
6. **估计误差放大：** 风险平价/最小方差对协方差矩阵高度敏感，收缩方法改变的不是排版而是组合行为。
7. **目标与实现偏离：** 目标 10% 只是一项约束，实际收益波动可能因为滞后、跳跃和上限长期高于或低于目标。

因此应额外报告：

| 指标 | 目的 |
|---|---|
| 实际年化波动与目标差距 | 检查风险目标是否实现 |
| 平均杠杆/现金权重 | 识别资金使用与机会成本 |
| 杠杆上限触发比例 | 识别模型是否经常受约束 |
| 去杠杆事件与恢复期 | 检查危机路径 |
| 年化换手和成本占比 | 动态权重的可实现性 |
| 风险贡献和相关性 | 判断分散化是否真实 |
| 压力场景损失 | 估计跳跃、相关性上升和融资收紧风险 |

### 7.5 股票、黄金与跨资产风险管理

股票单资产波动目标容易解释，但多资产组合必须同时估计协方差。黄金可能降低正常期组合波动，也可能在美元冲击、实际利率跃升或 ETF 流动性压力下与股票同时下跌。风险平价不能依赖历史相关性永远稳定。

本章采用 SPY/GLD 两资产作为机制示例：

- 固定 50/50 作为名义基准；
- 逆波动权重作为近似风险平价；
- 以 12 个月滚动组合波动估计 10% 目标；
- 杠杆上限 1.5；
- 空闲资金收益设为零；
- 每次总换手扣 10 bps。

该协议没有加入债券、现金、外汇或期货保证金，因此不能代表机构风险平价组合。

### 7.7 本地结果：固定权重、风险平价与波动目标

本节使用 <code>quant_finance/data/classic_strategy_risk_management_snapshot.json</code>。所有策略均为月度，使用滞后 12 个月风险估计，排除未完成月份，现金收益设为零。

| 策略 | 净 CAGR | 实际年化波动 | Sharpe（RF=0） | 最大回撤 | 年化换手 |
|---|---:|---:|---:|---:|---:|
| 固定 50/50 | 11.33% | 11.98% | 0.96 | −25.62% | 0.20 |
| 逆波动风险平价 | 11.52% | 11.76% | 0.99 | −28.49% | 0.36 |
| 固定 50/50 + 10% 波动目标 | 9.26% | 11.69% | 0.82 | −26.47% | 0.78 |
| 风险平价 + 10% 波动目标 | 9.84% | 11.58% | 0.87 | −28.94% | 0.85 |

**结果解释。** 逆波动风险平价略提高 CAGR 和 Sharpe，但最大回撤反而高于固定 50/50；10% 波动目标没有把实际波动压到 10%，反而因滞后和零现金收益降低了 CAGR。该结果不证明风险管理无效，而是证明其效果依赖目标、预测、现金收益、融资和资产集合，不能只看曲线平滑程度。

**目标偏离。** 固定波动目标策略平均杠杆约 0.94，约 6.2% 权重留在零收益现金；风险平价波动目标平均杠杆约 0.96，约 3.9% 现金。由于局部样本波动和目标估计不同，实际波动仍处在约 11.6%–11.7%。

### 7.8 与其他策略的组合

1. **趋势 + 波动目标：** 趋势决定方向，波动模型决定名义杠杆；需防止两个模块同时在危机初期去杠杆。
2. **价值/质量 + 风险平价：** 因子决定股票选择，风险平价限制股票、黄金和债券的风险贡献。
3. **均值回复 + 动态限仓：** 对价差设置残差波动、最大持有期和结构断裂止损。
4. **主观宏观观点 + Black–Litterman：** 观点改变预期收益，但风险协方差和杠杆上限仍需独立估计。
5. **风险预算 + 压力测试：** 先设定正常期预算，再对相关性升高、波动跳跃、现金利率下降和融资收紧做压力情景。

### 7.9 实现伪代码：滞后风险估计与风险贡献

~~~python
def risk_managed_portfolio(returns, target_vol=0.10, lookback=12, max_leverage=1.5):
    # 1) 用截至上月的收益估计波动和协方差，禁止当前月信息泄漏。
    forecast_cov = lagged_rolling_covariance(returns, lookback)

    # 2) 先求风险平价或约束最小方差的资产权重。
    base_weights = solve_risk_budget(forecast_cov, budgets=[0.5, 0.5])

    # 3) 计算组合预测波动，再应用目标波动和杠杆上限。
    forecast_vol = portfolio_volatility(base_weights, forecast_cov)
    scale = min(max_leverage, target_vol / max(forecast_vol, 1e-8))
    asset_weights = scale * base_weights
    cash_weight = 1.0 - asset_weights.sum()

    # 4) 对上一期持仓漂移与本期目标权重计算换手，并扣除成本。
    turnover = rebalance_turnover(asset_weights, cash_weight, returns)
    net_return = (asset_weights * returns.current).sum() - turnover * cost_model

    # 5) 记录实际波动、风险贡献、现金、杠杆、压力损失和 MDD。
    return append_risk_ledger(net_return, asset_weights, cash_weight, forecast_vol)
~~~

### 7.10 失败模式与风险边界

- **把目标波动当作保证：** 跳跃、相关性跃迁和估计滞后使实际波动偏离目标。
- **风险平价等于逆波动：** 相关性不相等时，逆波动不保证风险贡献相等。
- **忽略现金和融资利率：** 去杠杆期间的现金收益直接影响 CAGR；杠杆期间融资利率会侵蚀收益。
- **忽略再平衡漂移：** 固定权重也有交易成本，动态权重的换手可能显著更高。
- **风险模型过度平滑：** 长窗口在危机初期反应慢，短窗口则噪声和换手高。
- **杠杆上限未压力测试：** 上限触发时，目标波动模型可能失去原先风险控制能力。
- **协方差未来函数：** 使用包含当前或未来收益的矩阵会高估去杠杆及时性。
- **把更低波动叫 alpha：** 风险缩放改变的是暴露路径，不自动产生新的预测信息。

### 7.11 本章结论与后续接口

波动率目标与风险平价是风险预算模型，不是收益保证模型。SPY/GLD 示例显示，逆波动风险平价略改善 Sharpe，但可能扩大最大回撤；10% 波动目标因滞后、零现金收益和杠杆限制未达到目标，且 CAGR 下降。正式研究必须报告目标偏离、现金/融资、换手、风险贡献和压力损失，而不是只展示更平滑的净值曲线。

下一并列章节将研究**Carry、期限结构与宏观跨资产模型**，重点讨论期货展期收益、利差、美元/实际利率和黄金等资产的主观宏观组合。

## 模型章节 08：Carry、期限结构与宏观跨资产模型

### 8.1 模型定位：收益来自持有结构，而不只是价格方向

Carry（持有收益）描述在价格不变或风险状态不变时，仅仅因为持有某项资产、合约或利差而获得的预期收益。期限结构（term structure）则描述同一标的不同到期合约之间的价格关系。两者经常被合并讨论，但概念并不相同：

| 市场 | Carry 的典型来源 | 主要风险 |
|---|---|---|
| 商品/黄金期货 | 近月与远月价差、便利收益、库存稀缺、抵押品利息 | 展期跳价、基差扩大、保证金和流动性 |
| 外汇 | 远期点数、两国短期利率差 | 汇率崩溃、融资货币拥挤、资本管制 |
| 债券 | 票息、融资利率、收益率曲线 roll-down | 利率跳升、曲线形状变化、久期损失 |
| 股票 | 股息率、回购收益、估值与融资差 | 盈利下修、股息削减、股价跳跃 |
| 黄金现货/ETF | 没有固定票息；持有收益取决于实际利率、美元、租借/便利收益和 ETF 费用 | 实际利率上升、美元走强、危机期流动性折价 |

Carry 因此是**收益来源的会计分解**，不是无风险套利。Koijen 等人的跨资产研究把 carry 作为跨市场可比较的预测变量；商品研究则强调库存和便利收益会改变期货风险溢价。文献结论支持“carry 是可研究的风险暴露”，不支持把历史平均 carry 当作固定票息或未来保证收益。[1][2]

### 8.2 期货收益、展期收益与远期点数的数学表达

对连续持有的期货合约，单期总收益可以近似分解为：

\[
r^{\mathrm{fut}}_{t+1}
\approx r^{\mathrm{spot}}_{t+1}
      +r^{\mathrm{roll}}_{t+1}
      +r^{\mathrm{collateral}}_{t+1}
      -r^{\mathrm{fee}}_{t+1}.
\]

**变量与证据边界：** \(r^{\mathrm{spot}}\) 是现货价格变化，\(r^{\mathrm{roll}}\) 是换月时从近月合约切换到远月合约产生的收益，\(r^{\mathrm{collateral}}\) 是保证金/抵押品利息，\(r^{\mathrm{fee}}\) 是管理与交易成本。该式是收益归因近似，不是连续合约供应商的精确结算恒等式；本地数据没有保存逐合约换月表，因此只能估计 proxy。

若在时点 \(t\) 从近月合约 \(F_{t}^{(1)}\) 换到下一合约 \(F_{t}^{(2)}\)，在价格单位一致时，常用的对数展期近似为：

\[
r^{\mathrm{roll}}_t
\approx \ln\!\left(\frac{F_t^{(1)}}{F_t^{(2)}}\right).
\]

**直觉：** 当远月价格低于近月（backwardation，现货升水）时，上式为正；当远月价格高于近月（contango，期货升水）时，上式为负。实际收益还取决于换月比例、时间间隔、价格跳变和交易成本。没有近月/次近月的同步观测时，不能把连续前月价格收益直接称为 roll yield。

外汇远期的 carry 常用远期点数或利差表示。覆盖利率平价（covered interest parity, CIP）的基准关系为：

\[
\frac{F_t}{S_t}
\approx \frac{1+r_{d,t}\Delta}{1+r_{f,t}\Delta},
\qquad
c^{\mathrm{FX}}_t
=\ln\!\left(\frac{F_t}{S_t}\right),
\]

其中 \(S_t\) 是即期汇率，\(F_t\) 是同期限远期汇率，\(r_d,r_f\) 分别是计价货币和基准货币短期利率，\(\Delta\) 为年化期限。CIP 是定价基线；跨货币 basis、融资约束和风险溢价使可交易 carry 不等于简单利差。[3]

债券 carry 与 roll-down 可作局部近似：

\[
c^{\mathrm{bond}}_t
\approx y_t-r^{\mathrm{fund}}_t
       -D_t\,\Delta y_t^{\mathrm{roll}},
\]

其中 \(y_t\) 是票息/到期收益率，\(r^{\mathrm{fund}}_t\) 是融资成本，\(D_t\) 是修正久期，\(\Delta y_t^{\mathrm{roll}}\) 表示沿收益率曲线滚动到更短期限的收益率变化。该式只适合小幅平移和局部曲线；大幅利率跳跃时凸性和曲率项不能忽略。

### 8.3 黄金与宏观跨资产的 carry 解释

黄金不是有固定票息的债券。对黄金 ETF 或现货多头，实际持有收益可拆为：

\[
r^{\mathrm{gold}}_t
\approx r^{\mathrm{USD\ price}}_t
      -r^{\mathrm{real\ rate\ drag}}_t
      -r^{\mathrm{ETF\ fee}}_t
      +r^{\mathrm{convenience/lease}}_t.
\]

**变量与统计含义：** \(r^{\mathrm{real\ rate\ drag}}\) 不是会计上直接扣除的一笔费用，而是实际利率变化对无息资产估值的机会成本代理；便利收益/租借收益在公开 ETF 价格中无法单独识别。Baur–Lucey 将黄金的 hedge 与 safe haven 区分为正常期和极端下跌期条件，不应把黄金的防御属性误写成稳定 carry。[4]

宏观 carry 组合通常同时观察：

1. **实际利率：** FRED 的 TIPS 实际收益率序列可作为黄金机会成本和债券曲线状态变量；必须记录发布时间和修订边界。
2. **美元：** 美元指数或贸易加权美元影响以美元计价黄金和非美元资产的共同风险暴露。
3. **通胀与增长：** 通胀上行、增长下行和流动性收紧可能使商品 carry、债券 roll-down 与股票股息 carry 同时失效。
4. **期限结构：** contango/backwardation 是商品库存、便利收益和融资条件的混合信号，不宜只按价格斜率解释。

### 8.4 计量模型：横截面 carry 排名与宏观过滤

设 \(c_{i,t}\) 为资产 \(i\) 的 carry 估计，常见横截面排名规则为：

\[
\operatorname{rank}_{i,t}=\operatorname{rank}\left(
\frac{c_{i,t}-\operatorname{median}_j(c_{j,t})}
{\operatorname{MAD}_j(c_{j,t})+\varepsilon}
\right),
\]

选取最高的 \(K\) 个资产做多，或同时做多高 carry、做空低 carry。MAD（median absolute deviation，中位数绝对偏差）比样本标准差更不易受极端价差影响。

信号必须滞后：

\[
w_{i,t+1}
=\mathcal{W}\!\left(c_{i,t-L+1:t}\right),
\qquad
r_{p,t+1}=\sum_i w_{i,t+1}r_{i,t+1}-\kappa\,\mathrm{Turnover}_{t+1},
\]

其中 \(L\) 是 carry 平滑窗口，\(\mathcal W\) 是排序、风险缩放和约束函数，\(\kappa\) 是单位换手成本。若使用远期报价或库存数据，必须以当时已发布的信息构造 \(c_{i,t}\)，不能使用事后修订。

宏观过滤器可以把 carry 暴露与状态变量结合：

\[
w_{i,t+1}=w^{\mathrm{carry}}_{i,t+1}
\cdot g(z_t),
\qquad
g(z_t)=\operatorname{clip}\left(
1-\beta\,\mathbf{1}\{z_t\in\mathcal S_{\mathrm{stress}}\},
g_{\min},1\right),
\]

其中 \(z_t\) 可包含实际利率变化、美元趋势、隐含波动率、期限结构斜率和流动性指标；\(\mathcal S_{\mathrm{stress}}\) 是压力状态集合。该过滤器是风险治理层，不应在回测中把未来危机标签直接当作信号。

### 8.5 本地证据：四资产 carry/basis proxy 回测

| 组合/规则 | 净年化算术平均 | 净 CAGR | 年化波动 | Sharpe（RF=0） | 最大回撤 | 年化换手 |
|---|---:|---:|---:|---:|---:|---:|
| 四资产等权 ETF 基准 | 5.43% | 4.90% | 11.32% | 0.48 | −27.96% | 0.06 |
| Top-2 相对 carry proxy | 1.58% | −0.21% | 18.25% | 0.09 | −63.06% | 5.66 |
| Top-2 正 carry proxy（否则现金） | 5.89% | 4.63% | 16.98% | 0.35 | −43.44% | 8.22 |

**结果解释。** 在这个代理协议中，简单相对排名没有改善组合收益，且回撤和换手显著上升；正 carry 过滤降低了部分负暴露，但仍未超过等权基准的风险调整结果。该失败结果有重要信息：连续合约构造误差、ETF 跟踪差、零现金收益和高频排名都会把理论 carry 溢价转化为交易成本与模型风险。它不能证明 carry 无效，也不能支持对真实期货策略的结论。

### 8.6 与趋势、价值和风险预算的组合方式

| 组合方式 | 机制 | 主要收益/风险交换 |
|---|---|---|
| Carry + 趋势 | carry 提供持有收益，趋势在期限结构反转时减仓 | 可能降低 contango 崩溃，但信号冲突时换手增加 |
| Carry + 价值 | 用长期估值约束极端高/低 carry | 降低拥挤风险，牺牲短期响应速度 |
| Carry + 风险平价 | 先按 carry 选资产，再按协方差分配风险 | 限制油/外汇高波动资产主导组合 |
| 黄金 carry proxy + 实际利率过滤 | 实际利率快速上升时降低无息黄金名义权重 | 可能错过实际利率与黄金同涨的流动性阶段 |
| 多空 carry | 做多高 carry、做空低 carry | 对融资、借券、保证金和尾部相关性最敏感 |

组合层仍应使用：

\[
\max_{\mathbf w}\quad
\mathbf w^\top\hat{\boldsymbol\mu}
-\frac{\lambda}{2}\mathbf w^\top\hat\Sigma\mathbf w
-\eta\lVert\mathbf w-\mathbf w_{t-1}\rVert_1,
\]

并增加单资产、单市场、单期限结构和杠杆上限。carry 的估计收益 \(\hat{\boldsymbol\mu}\) 往往比协方差估计更不稳定，不能让优化器把一个噪声均值放大成极端仓位。

### 8.7 主观宏观模型与可形式化边界

主观宏观交易常从“实际利率下降、美元走弱、库存紧张、增长回升”等叙事出发。可审计的记录应至少包括：

1. 观点方向和时间尺度（例如 1–3 个月或 1–3 年）；
2. 支撑变量与发布日期（利率、通胀、库存、曲线斜率、美元）；
3. 预期 carry、预期价格变化和尾部情景的拆分；
4. 初始仓位、最大损失、止盈/止损、流动性和保证金上限；
5. 观点失效条件和复盘日期。

若缺少点时数据和逐笔交易账本，只能报告“主观判断框架”，不能给出与机械策略同口径的长期平均收益。把宏观叙事转成 \(g(z_t)\) 过滤器后，仍需独立样本外验证，避免事后挑选危机状态。

### 8.8 实现伪代码：carry proxy、状态过滤与风险约束

~~~python
def carry_portfolio(front_futures, etf_prices, macro_state, lookback=3, top_k=2):
    # 1) 对齐连续近月期货与 ETF 的点时月末价格；排除未完成月份。
    months = common_completed_months(front_futures, etf_prices)

    # 2) 计算 futures-minus-ETF basis/roll proxy；不能把它标成纯 roll yield。
    proxy = monthly_return(front_futures, months) - monthly_return(etf_prices, months)

    # 3) 在 t 月末仅使用过去 lookback 个月的 proxy 排名，禁止未来函数。
    score = trailing_mean(proxy, lookback).shift(1)
    selected = top_k_assets(score, k=top_k, positive_only=True)

    # 4) 将宏观压力状态转成名义权重上限，而不是直接使用未来危机标签。
    weights = equal_weight(selected)
    weights = apply_state_filter(weights, macro_state.shift(1))
    weights = risk_budget_and_leverage_cap(weights, covariance_lagged=True)

    # 5) 用 ETF 或真实期货总收益执行；计算换手、融资、保证金和展期成本。
    gross = execute_next_month(weights, etf_prices)
    net = gross - turnover(weights) * cost_model - financing_cost(weights)
    return ledger(net, proxy, weights, macro_state)
~~~

### 8.9 统计特征、容量与失败边界

- **Carry 与价格方向不同：** 正 carry 可以和现货下跌同时发生；收益分解必须分别报告现货、展期、抵押品和费用。
- **Contango 不是永远负收益：** 期货升水可能补偿库存、便利收益或灾难风险；简单反向做空 contango 会暴露跳涨风险。
- **连续合约偏差：** 不同供应商的换月日、价格拼接和复权方法会改变 roll proxy，必须保存合约级数据或至少记录供应商规则。
- **黄金没有固定 carry：** 不能用债券票息公式直接套用黄金；实际利率和美元关系是状态依赖的统计关系。
- **高换手与容量：** carry 排名对微小价差敏感，换月、保证金和 bid–ask 成本可能超过名义溢价。
- **融资与保证金：** 多空 carry 需要借券和融资；压力期保证金上调会迫使拥挤仓位同时平仓。
- **利差崩溃：** 外汇 carry 的收益常集中在平稳期，极端风险可能呈负偏度和跳跃损失。
- **宏观过滤过拟合：** 实际利率、美元、VIX、库存和曲线变量的选择应预先登记，并使用 purging/embargo 或 walk-forward。
- **统计显著性不足：** 本节 proxy 的 iid t 值不是 HAC 显著性；局部正均值不能证明风险溢价普遍存在。

### 8.10 本章结论与后续接口

Carry/期限结构模型把“持有资产的结构性收益”和“价格方向收益”分开，是股票股息、债券 roll-down、外汇远期点数、商品展期和黄金宏观机会成本之间的共同语言。SPY/GLD 等股票—黄金组合不能直接替代期货 carry；本节四资产 proxy 实验明确显示，未经合约级展期、抵押品利息和融资建模的 carry 排名可能出现高换手、低 CAGR 和极端回撤。

下一并列章节将研究**主观宏观与事件驱动模型**，把宏观叙事、事件窗口、仓位上限和不可回测的证据边界单独展开。

## 模型章节 09：主观宏观与事件驱动模型

### 9.1 模型定位：把叙事、信息到达和仓位治理分开

主观宏观（discretionary macro）以经济周期、货币政策、通胀、增长、美元、实际利率和地缘风险形成交易观点；事件驱动（event-driven）则把财报、并购、监管、FOMC、CPI 或突发事件的**信息到达时点**作为交易触发器。两者都可能使用股票和黄金，但与机械趋势/因子模型的证据结构不同：

| 维度 | 主观宏观 | 事件驱动 |
|---|---|---|
| 信号 | 对经济状态的解释和情景概率 | 事件实际值与预期值的意外差 |
| 持有期 | 周、月到数年 | 分钟、日到数周 |
| 数学对象 | 状态、观点概率、仓位上限 | abnormal return、CAR、事件后漂移 |
| 收益证据 | 通常依赖完整交易账本 | 可用事件研究估计平均异常收益 |
| 主要风险 | 叙事漂移、仓位过大、相关性跃迁 | 泄漏、抢跑、跳空、执行和事件取消 |

主观模型可以结构化，却不能因为写出了一个评分函数就自动变成可复现的计量策略。若观点、概率、修正时间和交易价格没有逐点存档，应把结果标为“不可回测的决策框架”，不与机械策略的 CAGR 排行混合。

### 9.2 事件研究的统计学表达

事件研究（event study）先定义事件时点 \(\tau\)、估计窗口和事件窗口。对股票 \(i\) 的市场模型为：

\[
r_{i,t}=\alpha_i+\beta_i r_{m,t}+\varepsilon_{i,t},
\qquad t\in\mathcal E_i,
\]

事件日的异常收益（abnormal return, AR）为：

\[
AR_{i,\tau+h}
=r_{i,\tau+h}
-\left(\hat\alpha_i+\hat\beta_i r_{m,\tau+h}\right),
\qquad h\in[\!-​H_1,H_2].
\]

**变量与实现映射：** \(\mathcal E_i\) 是事件前的估计窗口，\([-H_1,H_2]\) 是事件窗口；\(\hat\alpha_i,\hat\beta_i\) 只能使用事件前信息估计。单事件累计异常收益为：

\[
CAR_i(\tau;H_1,H_2)
=\sum_{h=-H_1}^{H_2}AR_{i,\tau+h}.
\]

对 \(N\) 个同类事件，平均异常收益与累计平均异常收益为：

\[
AAR_h=\frac1N\sum_{i=1}^{N}AR_{i,\tau_i+h},
\qquad
CAAR=\sum_{h=-H_1}^{H_2}AAR_h.
\]

事件研究关注的是**窗口内平均异常收益**，不是长期 CAGR；如果事件窗口为 \([-1,+1]\) 日，不能把 3 日 CAR 年化后当成可持续收益。

### 9.3 宏观意外与跨资产响应

宏观事件交易的核心变量是意外（surprise），而不是公告绝对水平：

\[
s_t=\frac{A_t-E_t}{\hat\sigma_{E,t}},
\]

其中 \(A_t\) 是实际公布值，\(E_t\) 是公告前调查或市场隐含预期，\(\hat\sigma_{E,t}\) 是预期分布的尺度。对未来 \(h\) 个交易日的股票或黄金收益，可估计：

\[
r_{a,t:t+h}
=\alpha_h+\beta_h s_t
+\gamma_h^\top X_t+u_{t,h},
\]

其中 \(a\in\{\mathrm{SPY},\mathrm{GLD}\}\)，\(X_t\) 包含美元、实际利率、波动率和流动性控制变量。跨资产系数 \(\beta_h\) 不必同号：偏鹰派的利率意外通常压低长久期股票和黄金，但增长/通胀意外可能同时推高商品和周期股票。

事件相互靠近时，误差项重叠，普通 t 值会低估不确定性。应使用事件聚类、HAC、wild bootstrap 或按公告日 block bootstrap；多种窗口、资产和 surprise 定义还需要 White Reality Check 或 Deflated Sharpe/多重检验控制。[1][2]

### 9.4 主观宏观的状态—观点—仓位框架

一个可审计的主观宏观观点可以写成情景集合 \(\mathcal S=\{s_1,\ldots,s_K\}\)：

\[
\pi_k=P(s_k\mid\mathcal I_t),
\qquad
\mu_{a,k}=E[r_{a,t:t+H}\mid s_k],
\qquad
\bar\mu_a=\sum_{k=1}^{K}\pi_k\mu_{a,k}.
\]

**直觉：** 交易者先记录信息集 \(\mathcal I_t\)、情景概率 \(\pi_k\) 和每个资产在情景下的收益，而不是直接写“看多黄金”。仓位再由风险预算限制：

\[
w_{a,t}
=\operatorname{clip}\left(
\frac{q_t\,\bar\mu_a}{\hat\sigma_{a,t}^2},
-w_{a,\max},w_{a,\max}\right),
\qquad
\sum_a|w_{a,t}|\le L_{\max}.
\]

\(q_t\) 是观点置信度，\(\hat\sigma\) 是滞后风险估计；公式只是把主观判断映射到透明的仓位预算，并不证明 \(\bar\mu_a\) 可被准确估计。每次观点更新要记录 \(\Delta\pi_k\)、仓位变动、失效条件和事后结果。

### 9.5 股票、黄金与事件类型

#### FOMC、通胀和实际利率事件

FOMC 利率决策和 CPI/PCE 公布的关键是 surprise 与政策路径，而不是“降息必然利好股票”。Bernanke–Kuttner 的事件研究估计，意外的 25bp 联邦基金目标利率下降与广义股票价格约 1% 的正向反应相关；这是事件窗口统计，不是长期年化收益。[3] 黄金还同时受美元、实际利率和避险需求影响，单一利率方向无法解释全部事件日变化。

#### 财报、盈利预期与公司行动

股票事件驱动可以将实际 EPS、收入、指引和分析师预期构成 surprise；必须区分公告前泄漏、盘前/盘后公告、跳空成交和后续漂移。并购套利还要加入交易完成概率、失败损失、时间价值和监管条件，不能只看宣布日价差。

#### 地缘风险与黄金

地缘事件往往造成黄金、美元和波动率同时跳变。黄金的 safe-haven 定义需要条件化于股票市场极端下跌，而不是简单计算全样本相关系数。[4] 主观交易应记录事件分类、初始暴露、止损和流动性状态；否则事后很容易把任何上涨都解释成“避险”。

### 9.6 收益率、回撤与证据分层

事件策略的核心统计量是 AAR、CAAR、窗口胜率、跳空损失和持有期 P&L；主观宏观若没有完整交易账本，则没有可核验的长期平均收益或最大回撤。本报告因此把可比数字分为三层：

| 证据层 | 可报告数字 | 本节状态 |
|---|---|---|
| 文献事件窗口 | Bernanke–Kuttner：意外 25bp 降息与广义股票约 +1% 事件响应；单位为事件窗口，不年化 | 有来源，可复核论文设定 |
| 本地机械基准 | SPY CAGR 10.79%、MDD −50.78%；GLD CAGR 10.22%、MDD −42.91%；50/50 CAGR 11.23%、MDD −25.60% | 来自基准快照，不是事件策略结果 |
| 主观宏观/事件组合 | 长期 CAGR、Sharpe、MDD、交易级成本 | ⚠️ 未找到完整点时观点、公告预期和成交账本，不能伪造 |

本地基准仅用于校准量纲，取自 <code>quant_finance/data/classic_strategy_baseline_snapshot.json</code>；不能把基准收益误写成事件模型 alpha。任何事件策略若要报告 CAGR/MDD，必须保存事件清单、预期值版本、信号生成时间、下一可成交价格、持仓、成本和未成交订单。

### 9.7 主观与计量的组合方式

| 组合 | 结构 | 风险控制 |
|---|---|---|
| 主观宏观观点 + Black–Litterman | 将情景观点转为收益分布，再与市场均衡收益融合 | 观点置信度、单资产上限、协方差收缩 |
| 事件信号 + 趋势过滤 | 事件只在长期趋势方向一致时执行 | 防止逆势跳空，代价是错过快速反转 |
| FOMC/CPI 事件 + 黄金/股票对冲 | 以实际利率和美元状态决定 SPY/GLD 相对仓位 | 控制美元集中暴露与隔夜跳空 |
| 事件策略 + 风险平价 | 事件头寸作为卫星仓位，核心组合承担基础风险预算 | 单事件风险预算、最大持有期和日内止损 |
| 主观观点 + 机械退出 | 入场可主观，退出和限仓规则机械化 | 观点失效条件必须在入场前写明 |

### 9.8 实现伪代码：事件窗口与主观观点账本

~~~python
def event_macro_trade(event, prices, expectations, risk_model):
    # 1) 冻结事件的实际值、预期值、发布时间和可交易时间戳。
    surprise = standardize(event.actual - expectations.asof(event.release_time))

    # 2) 估计窗口只用公告前数据，计算 beta、AR、CAR 和事件簇标签。
    model = fit_market_model(prices.before(event.release_time))
    abnormal = realized_return(prices, event.window) - model.expected_return(event.window)
    record_event_statistics(event.id, surprise, abnormal)

    # 3) 主观层记录情景概率、观点置信度、失效条件和最大持仓期。
    scenarios = analyst_scenario_ledger(event, surprise)
    raw_view = scenario_weighted_view(scenarios)

    # 4) 风险层把观点映射到 SPY/GLD 权重，加入波动、相关性和杠杆约束。
    weights = risk_model.size(raw_view, prices.lagged_returns)
    weights = clip_by_event_limit(weights, max_loss=event.max_loss)

    # 5) 下一根可成交价格执行，记录滑点、跳空、撤单、持有期和退出原因。
    fill = execute_next_tradable_bar(weights, prices, event.execution_window)
    return settle_and_review(fill, event.invalidating_conditions)
~~~

### 9.9 失败模式与风险边界

- **把叙事当作统计显著性：** “通胀上升利好黄金”是条件命题，必须明确实际利率、美元和风险状态。
- **事件泄漏：** 使用事后修订的预期、新闻摘要时间或收盘价会产生未来函数。
- **公告时间与价格不可成交：** 盘前、盘后和夜盘事件不能用同一收盘价假设；跳空时止损不等于成交价。
- **事件重叠：** CPI、FOMC、财报和地缘事件窗口重叠，不能把同一异常收益重复归因。
- **小样本与选择偏差：** 只挑成功事件会产生幸存者偏差；应登记全部候选和取消事件。
- **主观仓位漂移：** 置信度上升而风险预算未调整会造成隐含杠杆；每次观点变动都要记录权重和理由。
- **并购/事件完成风险：** 交易失败、监管延迟和融资条件会产生非对称损失。
- **黄金避险误读：** 极端风险时美元流动性和保证金需求可能压制黄金，safe haven 不是无条件保护。
- **无法形成长期统计：** 没有点时账本时，报告应保留“未核验”而不是给出看似精确的 CAGR、Sharpe 或 MDD。

### 9.10 本章结论与后续接口

主观宏观与事件驱动模型的可复核核心不是预测故事，而是信息集、意外定义、事件窗口、情景概率、仓位上限和成交账本。事件研究能够估计短窗口平均异常收益；它不能直接推出长期 CAGR。SPY/GLD 基准数据显示股票、黄金及其组合的长期回撤量级，但在缺少点时事件预期与交易账本时，本节不把这些数字冒充事件策略表现。

下一并列章节将研究**组合构建、策略集成与综合比较**，统一比较前述模型的收益、回撤、换手、容量和证据等级。

## 模型章节 10：组合构建、策略集成与综合比较

### 10.1 模型定位：组合不是把排行榜简单相加

前九章的模型解决的是不同层次的问题：价值/质量与 carry 提供收益解释，趋势与动量提供方向信号，均值回复提供相对价值，波动率目标与风险平价控制暴露，主观宏观与事件模型提供状态判断。组合构建的任务是把这些信号放在同一个资本、风险、换手和证据约束下。

| 组合层方法 | 输入 | 输出 | 典型风险 |
|---|---|---|---|
| 固定权重/等权 | 预先给定的资产或策略权重 | 稳定、透明的名义配置 | 权重不等于风险，危机时集中度可能升高 |
| 均值—方差 | 预期收益 \(\hat{\boldsymbol\mu}\)、协方差 \(\hat\Sigma\) | 最大化风险调整收益的权重 | 预期收益估计误差和极端权重 |
| 最小方差 | 协方差 \(\hat\Sigma\) | 在约束下最小化波动 | 历史相关性不稳定、集中到低波资产 |
| 风险平价 | 风险预算 (b_i)、协方差 | 各资产风险贡献接近预算 | 协方差估计和杠杆/融资风险 |
| Black–Litterman | 市场均衡收益、主观观点和置信度 | 收缩后的后验预期收益 | 观点矩阵、置信度和先验敏感 |
| 策略集成 | 多个策略净收益序列 | 等权、风险加权或状态切换的策略组合 | 信号相关性跃迁、重复暴露和叠加成本 |

### 10.2 均值—方差、最小方差与约束

Markowitz 的均值—方差组合可写成：

\[
\max_{\mathbf w}
\quad \mathbf w^\top\hat{\boldsymbol\mu}
-\frac{\lambda}{2}\mathbf w^\top\hat\Sigma\mathbf w
-\eta\lVert\mathbf w-\mathbf w_{t-1}\rVert_1,
\]

\[
\mathbf1^\top\mathbf w=1,
\qquad
\mathbf w\in\mathcal C.
\]

其中 \(\hat{\boldsymbol\mu}\) 是预期收益，\(\hat\Sigma\) 是协方差，\(\lambda\) 是风险厌恶，\(\eta\) 是换手惩罚，\(\mathcal C\) 可包含 long-only、单资产上限、杠杆和行业中性约束。最小方差特例令目标收益项为零：

\[
\min_{\mathbf w\in\mathcal C}
\quad \mathbf w^\top\hat\Sigma\mathbf w
+\eta\lVert\mathbf w-\mathbf w_{t-1}\rVert_1.
\]

**实现含义：** 组合优化器不应直接使用全样本平均收益；应将估计窗口、收缩协方差、点时信号和交易成本写入配置。若 \(\hat{\boldsymbol\mu}\) 的标准误与均值同量级，最小方差或等权通常比未约束均值—方差更稳健。[1][2]

### 10.3 风险平价、风险预算与策略级分配

资产组合波动率和风险贡献为：

\[
\sigma_p=\sqrt{\mathbf w^\top\Sigma\mathbf w},
\qquad
RC_i=w_i\frac{(\Sigma\mathbf w)_i}{\sigma_p}.
\]

风险预算 (b_i) 要求：

\[
RC_i=b_i\sigma_p,
\qquad \sum_i b_i=1.
\]

若把“趋势、价值、carry、均值回复、宏观事件”作为策略资产，同样可以定义策略级风险贡献 (RC_s)。但策略收益的相关性不是资产相关性的简单替代：两个不同名称的策略可能同时持有股票 beta、美元或短波动暴露。组合前需做收益相关、因子暴露和压力场景的三重检查。

### 10.4 Black–Litterman：把主观观点限制在可解释的范围

市场均衡收益的逆向优化先验为：

\[
\boldsymbol\Pi=\delta\Sigma\mathbf w_{\mathrm{mkt}},
\]

其中 \(\delta\) 是风险厌恶系数，\(\mathbf w_{\mathrm{mkt}}\) 是市场组合权重。给定观点：

\[
P\mathbf r=\mathbf q+\boldsymbol\varepsilon,
\qquad
\boldsymbol\varepsilon\sim N(0,\Omega),
\]

后验预期收益为：

\[
E[\mathbf r\mid\mathbf q]
=\left[(\tau\Sigma)^{-1}+P^\top\Omega^{-1}P\right]^{-1}
\left[(\tau\Sigma)^{-1}\boldsymbol\Pi+P^\top\Omega^{-1}\mathbf q\right].
\]

**变量与风险边界：** \(P\) 将观点映射到资产，\(\mathbf q\) 是观点收益，\(\Omega\) 是观点不确定性，\(\tau\) 控制先验不确定性。较大的 \(\Omega\) 会收缩观点影响；若把主观宏观观点设成零方差，优化器会产生不现实的极端仓位。Black–Litterman 是观点治理工具，不是预测准确性的证明。[3]

### 10.5 策略集成：等权、风险权重与状态切换

设 \(R_{s,t}\) 是策略 \(s\) 的净收益，固定等权集成为：

\[
R^{\mathrm{ens}}_{t}=\sum_{s=1}^{S}\alpha_sR_{s,t},
\qquad
\alpha_s=\frac1S.
\]

风险加权集成使用策略协方差：

\[
\min_{\boldsymbol\alpha}
\quad \boldsymbol\alpha^\top\hat\Sigma_R\boldsymbol\alpha,
\qquad
\mathbf1^\top\boldsymbol\alpha=1,
\quad 0\le\alpha_s\le\alpha_{\max}.
\]

状态切换集成可写为：

\[
\alpha_{s,t}=\frac{\exp(\theta_s^\top z_t)}
{\sum_j\exp(\theta_j^\top z_t)},
\]

其中 \(z_t\) 是滞后风险、趋势、实际利率、美元和流动性状态。状态切换增加参数自由度，必须使用冻结的训练/验证/测试切分和失败账本；在本报告中只将它作为扩展框架，不把未执行的状态模型当作结果。

### 10.7 综合比较矩阵与选择建议

| 目标 | 首选模型 | 可搭配模型 | 必须监控 |
|---|---|---|---|
| 长期资本增长 | 买入并持有、价值/质量 | 黄金配置、风险预算 | 估值、集中度、MDD、再平衡成本 |
| 危机防御 | 趋势、波动目标 | 黄金、风险平价 | 信号滞后、现金收益、跳跃风险 |
| 捕捉风险溢价 | 动量、carry、价值 | 多因子、策略等权 | 换手、拥挤、崩溃偏度、容量 |
| 低换手执行 | 固定权重、慢速价值 | 低频趋势、Black–Litterman | 点差、税费、权重漂移 |
| 主观信息整合 | 宏观观点 + BL | 事件窗口 + 机械退出 | 观点置信度、信息时间戳、限仓 |
| 研究与教学 | 策略等权集成 | walk-forward、失败账本 | 多重检验、样本外、可复现性 |

不同章节的收益数字不能直接排成一张跨窗口排行榜：SPY/GLD 基准、French 因子、ETF 代理、carry proxy 和事件窗口分别使用不同资产、频率、样本和成本。综合比较首先要问“是否同协议”，其次才是 CAGR 或 Sharpe 大小。

### 10.8 组合层统计与治理

组合报告至少应保留：

1. 净收益、算术平均、CAGR、波动、Sharpe、Sortino、Calmar、最大回撤及持续期；
2. 策略/资产相关矩阵、滚动 beta、因子暴露、风险贡献和压力损失；
3. 年化换手、成本分解、融资/保证金、现金收益和容量假设；
4. 训练/验证/测试切分、参数候选数量、选择规则、PBO/DSR 或 Reality Check；
5. 每次权重变更的原因、数据版本、信号时间戳、订单和实际成交偏差。

组合优化的统计误差可以用 block bootstrap 或 HAC 置信区间表达；若策略收益有明显自相关或波动聚集，独立同分布标准误会过度乐观。对多策略筛选，必须把候选数量和失败策略一并记录。

### 10.9 实现伪代码：统一组合管线

~~~python
def integrated_portfolio(strategy_returns, asset_returns, config):
    # 1) 读取点时信号与净收益序列，检查所有策略的共同样本和缺失月份。
    aligned = align_common_sample(strategy_returns, asset_returns, config.sample)

    # 2) 先在策略层计算相关性、因子暴露、波动和风险贡献。
    risk = estimate_lagged_risk(aligned, lookback=config.lookback)
    exposure = factor_and_asset_exposures(aligned, risk)

    # 3) 用固定等权、风险预算或约束优化生成策略层目标权重。
    weights = choose_allocator(config.allocator, risk.covariance, exposure, config.constraints)

    # 4) 将主观观点仅作为有置信度和上限的 overlay，不覆盖核心风险约束。
    weights = apply_black_litterman_or_event_overlay(weights, config.views, risk)

    # 5) 扣除策略层换手、资产层执行成本、融资、现金收益和容量惩罚。
    net = execute_and_cost(weights, aligned, cost_model=config.cost_model)

    # 6) 输出 CAGR、MDD、Sharpe、风险贡献、压力情景和选择前后的失败账本。
    return build_governance_ledger(net, weights, risk, exposure)
~~~

### 10.10 失败模式与组合边界

- **重复暴露：** 趋势、动量、carry 和主观宏观可能在不同名称下同时做多美元、股票 beta 或短波动。
- **相关性跃迁：** 历史分散化在危机期可能失效；风险平价和最小方差应配合压力相关矩阵。
- **优化器极端权重：** 小的预期收益差异会被均值—方差优化放大；应使用收缩、上限和换手惩罚。
- **双重成本：** constituent 已扣交易成本后，策略 overlay 还会产生策略层换手；不能默认零成本叠加。
- **异步信号：** 事件、日频趋势和月频风险预算若在不同时间戳更新，组合可能隐含未来函数。
- **回测选择偏差：** 只展示最好的组合忽略了候选失败策略；应保留参数敏感性和选择前分布。
- **现金与融资口径：** 去杠杆的现金收益、杠杆的融资利率和期货抵押品收益直接改变 CAGR。
- **容量与执行：** 小盘价值、短期均值回复和事件策略的理论收益可能无法承受真实冲击。
- **不可比数字误读：** 不同样本期、代理资产和频率的 Sharpe/MDD 不能直接排序。

### 10.11 本章结论与后续接口

组合构建的核心不是找到单一“最好模型”，而是在统一协议下控制重复风险、估计误差、换手和尾部损失。SPY/GLD 同样本实验显示，四策略等权集成的 CAGR 为 10.03%、Sharpe 为 0.96、最大回撤为 −20.44%，相较 50/50 买入并持有降低了回撤但牺牲少量增长；趋势+波动目标防御集成进一步降低回撤，但收益下降。由于集成层尚未建模额外 overlay 成本，该结果只能作为机制证据。

## 风险治理与可复现清单

### 回测前

- 固定资产代理、复权字段、连续合约换月规则、现金/融资和交易日历；
- 保存原始下载日期、URL、SHA-256、字段定义和许可边界；
- 预先登记信号窗口、持有期、候选参数、成本模型和样本外切分；
- 对公告、财报和宏观数据使用点时发布时间，而不是事后修订值。

### 回测中

- 信号在 (t) 形成、交易在下一可成交时点执行；
- 同时记录 gross、net、换手、融资、展期、现金收益和未成交订单；
- 对收益、波动、Sharpe、MDD、回撤持续期、偏度、峰度、VaR/ES 和因子暴露做统一统计；
- 使用 HAC、block bootstrap 或事件聚类处理时间依赖，并登记多重检验数量；
- 保留失败策略、参数敏感性和成本倍数，而不是只保留最佳曲线。

### 上线前

- 对异常行情、跳空、停牌、涨跌停、保证金上调、流动性消失和相关性跃迁做压力测试；
- 设定单资产、单策略、单事件、杠杆、最大换手和日损失上限；
- 监控实盘与回测的滑点、信号延迟、数据修订、风险贡献和回撤恢复期；
- 对主观观点保存版本化情景概率、置信度、失效条件和复盘结论；
- 定期执行独立复核，确认模型没有把数据泄漏、参数选择或偶然相关性误认为 alpha。

## 最终结论

经典交易模型没有单一的“平均收益率答案”。买入并持有提供最低复杂度基准；价值、动量、趋势、均值回复和 carry 提供不同的风险溢价假设；波动率目标与风险平价改变暴露路径；主观宏观与事件模型把信息解释转为情景、事件窗口和仓位治理。股票、黄金和跨资产组合的可用结论，必须同时满足：数学表达清楚、点时数据可追溯、成本口径透明、收益和回撤同协议计算、失败边界明确。

统一 SPY/GLD 实验显示，四策略等权集成在特定样本中实现约 10.03% CAGR、0.96 Sharpe 和 −20.44% 最大回撤，但集成层尚未额外计入策略权重换手；这说明分散化可能改善路径，却不构成未来收益承诺。报告最终建议把模型当作可监控的风险预算组件，而不是不可质疑的预测器。
