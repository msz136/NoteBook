# ARIS 学术模板契约

`aris_academic_v1.css` 是 `quant_finance/` 的规范样式源。渲染器将其完整内联到 HTML，禁止正常工作流中直接修改生成的 HTML。

模板依据仓库 `AGENTS.md` 的 ARIS academic v1 文字规范重建。原指引列出的两份 `interview_materials/vla/` 参考文件当前不存在，因此这里保证可机器检查的版式属性，但不声称与缺失文件逐像素一致。

最低要求：暖纸色、学术衬线字体、1280px 双栏、260px sticky TOC、蓝色双线 H1、深蓝表头、atom-one-light 兼容代码配色、`.formula` 容器、打印样式和 900px 响应式断点。
