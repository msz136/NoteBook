问题（Question）

目标是查看上海交通大学数学科学学院与机械与动力工程学院的公开师资页面，筛选与大语言模型（Large Language Model, LLM）、视觉语言模型（Vision-Language Model, VLM）、神经网络（Neural Network, NN）、具身智能（Embodied AI）、机器人脑（Robot Brain）、视觉-语言-动作模型（Vision-Language-Action Model, VLA）和世界模型（World Model）相关的导师，并进一步核查研究方向与公开招生信息。

背景与动机（Background & Motivation）

这类导师筛选容易出现两种误判：一是看到“机器人研究所”就把所有老师都归为 VLA/具身智能；二是看到“优化、微分方程、科学计算”就直接归为 world model。实际判断应以教师个人页明示研究方向为主，把机器人硬件/控制、AI for manufacturing、深度学习理论、VLA/多模态大模型、自动驾驶端到端系统分层处理。

本次证据来自用户已打开的 Chrome 页面与官网链接：数学学院当前页面是“计算数学 Computational Mathematics”研究方向页；机械动力学院当前页面进入“教师名录”，其页面通过官方接口按研究所列出教师。Windows Computer Use 曾用于确认 Chrome 窗口存在，但截图步骤因无法可靠判定当前浏览器 URL 而被安全策略停止；后续网页核查采用 Chrome 只读页面读取和官网请求。

证据范围与筛选准则

实际查看范围

  • 数学科学学院：以官方“计算数学 Computational Mathematics”研究方向页列出的 33 位教师为主，并打开个人主页或教师详情页核查研究兴趣与导师状态。
  • 机械与动力工程学院：从官方教师名录中优先查看“机器人研究所”“元知机器人研究院”“前沿交叉研究中心”“智能汽车研究所”“机电控制与物流装备研究所”“智能制造与信息工程研究所”“重大装备设计与控制工程研究所”等相关类目。
  • 明确跳过或只作边界记录：工程热物理、热能、制冷、燃料电池、核能、碳中和、纯基础制造/材料/光热方向，除非教师页出现大模型、具身、VLA、机器人学习或 NN 证据。

分级公式

令 \(p\) 表示教师个人页，\(K_s\) 表示强相关关键词集合（如 VLA、具身智能、大模型、机器人智能体、强化/模仿学习），\(K_w\) 表示弱相关关键词集合（如优化、微分方程、科学机器学习、数字孪生）。本报告采用如下人工校验后的相关性评分：

\[ R(p)=3\sum_{k\in K_s}\mathbf{1}[k\in p]+\sum_{k\in K_w}\mathbf{1}[k\in p]+\mathbf{1}[\text{公开招生信息}] \]

变量解释：\(R(p)\) 不是自动排名，而是用于提醒人工复核的筛选分数；\(\mathbf{1}[\cdot]\) 是指示函数。实现映射：先从官方页面抽取研究方向、招生、个人主页、指导学生等字段，再按关键词召回，最后人工剔除“智能制造但非具身/非学习”的误命中。

未发现数学科学学院计算数学页面中有人明确把“VLA、具身智能、机器人闭环世界模型”列为直接研究方向；数学学院候选更适合作为 LLM/NN 理论、优化、ODE/PDE、科学机器学习支撑。机械动力学院则有多名教师个人页明确出现“具身智能”“VLA”“大模型”“机器人智能体”等关键词。

基础概念与术语

  • 具身智能（Embodied AI）：模型不只处理静态文本/图像，而是在环境中感知、决策、执行并接收反馈。
  • 视觉-语言-动作模型（VLA）：把视觉观测 \(o_t\)、语言任务 \(c\) 和动作 \(a_t\) 统一建模，典型目标是学习 \(p_\theta(a_{t:t+H}\mid o_{\le t}, c)\)。
  • 世界模型（World Model）：学习环境动力学或未来观测分布，例如 \(p_\theta(o_{t+1:t+H}\mid o_{\le t}, a_{t:t+H-1}, c)\)，可用于预测、规划和仿真。
  • 弱相关数学方向：ODE/PDE、动力系统、高维优化、科学机器学习可以支撑 world model 或 VLA 的理论/训练，但若教师页未出现机器人、VLA、世界模型或多模态闭环，本报告不把它们列为直接导师方向。

弱相关与排除边界

弱相关但可作为理论支撑

  • 数学学院的优化、ODE/PDE、科学机器学习导师可支撑 world model 的训练稳定性、动力学建模和高维优化问题，但公开页面没有显示直接做 VLA/机器人闭环。
  • 机械学院的智能制造、超精密制造、工业 AI、大语言模型运维方向可支撑具身系统的工程落地，但多数不是端到端 VLA 或机器人基础模型。

本次明确降权或排除的方向

  • 热能、工程热物理、制冷、燃料电池、核能、碳中和等研究所：除个别智能汽车/智能网联教师外，未作为重点查看。
  • 纯机器人硬件/传统控制：若个人页仅写工业机器人、机构设计、伺服控制、医疗机器人，而没有学习、VLA、大模型、具身智能、强化/模仿学习等证据，仅作为泛机器人背景，不进入强相关短名单。
  • 数学学院基础数学、代数、数论、几何、组合等方向：与用户指定方向距离较远，未展开逐页筛选。

    for person in math_people + me_people:
        page = fetch_official_profile(person.url)
        fields = extract_fields(page, ["研究方向", "研究兴趣", "招生", "硕士", "博士", "个人主页"])

        # 3. Recall with keywords, then manually demote false positives.
        score = relevance_score(fields)
        if score > 0:
            candidates.append((person, fields, score))

    # 4. Classify evidence: direct VLA/embodied, robotics+AI, math theory, or exclude.
    return human_verified_tiers(candidates)

风险与后续建议

  • 网页招生信息会快速变化，尤其是“2026/2027 名额”这类内容；正式联系前应再次打开个人页确认。
  • “大模型应用”不一定意味着训练 VLA 基座模型，可能只是工业诊断、知识图谱或数字孪生中的 LLM 工具链；邮件中应询问数据、模型、动作空间和评测闭环。
  • 数学学院候选大多需要用理论问题切入，如泛化、优化、PDE/ODE、神经网络数值代数，而不是直接询问机器人项目。
  • 机械学院导师方向工程属性强，建议准备一页项目说明：已有 VLA/world model 训练经验、仿真平台、实机控制或多模态数据处理经历。
