背景与动机（Background & Motivation）

机器人世界模型（Robot World Model）的核心命题是：能否将大规模视频预训练的生成能力转化为机器人策略？传统方法将"感知→规划→控制"分离为独立模块；而世界模型路线试图用一个统一的生成模型同时完成未来状态预测（world model）、动作生成（policy）和价值估计（value function）。

本项目线的核心设计哲学是：将机器人策略学习重新表述为条件视频生成问题。具体而言，将动作（action）、本体感知（proprioception）、价值函数回报（value function return）统一编码为视频潜在空间中的"帧"，与视觉观测帧共享同一个扩散模型的去噪过程。这使得一个预训练好的视频生成模型��以通过后训练直接输出机器人动作。

核心架构设计：统一潜在序列表示

设计思想：Action-as-Latent-Frame

Cosmos Policy 的核心创新在于将机器人策略学习统一到视频扩散模型的框架中。其关键洞察是：动作、本体感知、价值回报都可以被编码为与图像潜在帧同构的张量，从而复用视频生成模型的去噪能力来同时预测未来视觉状态和机器人动作。

具体而言，一个训练样本的潜在序列 \( x_0 \in \mathbb{R}^{B \times C' \times T' \times H' \times W'} \) 由以下"帧"组成：

帧类型内容角色
Blank frame全零占位Tokenizer 对齐
Current proprio本体感知向量 → 重复填充至 \(C' \times H' \times W'\)条件输入
Current wrist image腕部相机图像（×4 复制）条件输入
Current left/right image第三人称左/右相机图像（×4 复制）条件输入
Action chunk动作序列 → 展平重复填充至潜在帧体积预测目标
Future proprio未来本体感知预测目标（world model）
Future wrist/left/right image未来视觉观测预测目标（world model）
Value returnMonte-Carlo 回报标量 → 广播至潜在帧预测目标（value function）
代码证据：cosmos_policy/datasets/robocasa_dataset.py:878-975 — __getitem__ 方法按上述顺序构建 image_list，每种模态占据固定的 current_sequence_idx 位置，并通过 *_latent_idx 字段传递给模型。

Latent Injection 机制

非视觉模态（action、proprio、value）通过 latent injection 注入到 VAE 编码后的潜在空间中。核心函数 replace_latent_with_action_chunk 的算法如下：

  1. 将 action chunk \( a \in \mathbb{R}^{B \times \text{chunk\_size} \times \text{action\_dim}} \) 展平为 \( \mathbb{R}^{B \times (\text{chunk\_size} \cdot \text{action\_dim})} \)
  2. 重复填充至目标潜在帧体积 \( C' \times H' \times W' \)（如 \(16 \times 28 \times 28 = 12544\) 元素）
  3. 替换 \( x_0[:, :, \text{action\_idx}, :, :] \) 处的潜在帧
# cosmos_policy/models/policy_text2world_model.py:64-109
def replace_latent_with_action_chunk(x0, action_chunk, action_indices):
    batch_indices = torch.arange(x0.shape[0], device=x0.device)
    action_image_latent = x0[batch_indices, :, action_indices, :, :]
    result = torch.zeros_like(action_image_latent)
    batch_size, latent_channels, latent_h, latent_w = action_image_latent.shape
    flat_action = action_chunk.reshape(batch_size, -1)
    num_action_elements = flat_action.shape[1]
    latent_elements = latent_channels * latent_h * latent_w
    # 重复填充直到覆盖整个潜在帧体积
    num_repeats = (latent_elements + num_action_elements - 1) // num_action_elements
    repeated_action = flat_action.repeat(1, num_repeats)[:, :latent_elements]
    flat_result = result.reshape(batch_size, -1)
    flat_result[:, :] = repeated_action
    new_x0 = x0
    new_x0[batch_indices, :, action_indices, :, :] = flat_result.reshape(
        batch_size, latent_channels, latent_h, latent_w)
    return new_x0

这种设计的优势在于：动作信息直接存在于扩散模型的去噪目标 \( x_0 \) 中，模型学习的是"从噪声中恢复包含动作信息的潜在帧"，而非通过额外的 head 预测动作。这使得预训练的视频生成能力可以直接迁移到动作预测任务。

关键架构选择：

  • RoPE 3D：对时间、高度、宽度三个维度分别施加旋转位置编码，支持外推（extrapolation ratio: t=1.0, h=3.0, w=3.0）
  • AdaLN-LoRA：使用 Adaptive Layer Normalization 注入时间步信息，并通过 LoRA（rank=32）实现参数高效微调
  • Cross-attention projection：将 T5 文本嵌入（100352 维）投影到 1024 维后与视觉 token 做交叉注意力
  • SAC (Selective Activation Checkpointing)：每 1 个 block 做一次激活检查点，平衡显存与计算

训练算法：Rectified Flow + Hybrid Sigma + Multi-Objective Loss

扩散过程：EDM 框架下的 Rectified Flow

模型采用 EDM（Elucidating the Design Space of Diffusion-Based Generative Models, Karras et al. 2022）框架，前向过程定义为：

\[ x_t = x_0 + \sigma \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I) \]

其中 \(\sigma\) 是噪声水平。模型学习去噪函数 \( D_\theta(x_t; \sigma) \) 来预测 \( x_0 \)。EDM 的 preconditioning 将网络输出 \( F_\theta \) 转换为 \( x_0 \) 预测：

\[ D_\theta(x_t; \sigma) = c_{\text{skip}}(\sigma) \cdot x_t + c_{\text{out}}(\sigma) \cdot F_\theta(c_{\text{in}}(\sigma) \cdot x_t; c_{\text{noise}}(\sigma)) \]

# EDM preconditioning 输出
x0_pred = c_skip * xt_B_C_T_H_W + c_out * net_output

Hybrid Sigma Distribution：混合噪声水平采样

训练时的噪声水平 \(\sigma\) 采样是影响扩散模型质量的关键因素。本项目实现了 HybridEDMSDE，采用混合分布策略：

\[ \sigma \sim \begin{cases} \exp(\mathcal{N}(p_{\text{mean}}, p_{\text{std}}^2)) & \text{with probability } 0.7 \\ \text{Uniform}(\sigma_{\text{lower}}, \sigma_{\text{upper}}) & \text{with probability } 0.3 \end{cases} \]

其中 \( p_{\text{mean}} = 0.0, p_{\text{std}} = 1.0, \sigma_{\text{lower}} = 1.0, \sigma_{\text{upper}} = 85.0 \)。

代码证据：cosmos_predict2_src/cosmos_policy/modules/hybrid_edm_sde.py:48-92 — HybridEDMSDE.sample_t() 实现了 70/30 混合采样。 
# hybrid_edm_sde.py:65-89
def sample_t(self, batch_size):
    if self.hybrid_sigma_distribution:
        samples = torch.zeros(batch_size, device="cuda")
        distribution_choice = torch.rand(batch_size, device="cuda") < 0.7
        num_lognormal = distribution_choice.sum().item()
        num_uniform = batch_size - num_lognormal
        # 70% 从 log-normal 采样
        if num_lognormal > 0:
            cdf_vals = np.random.uniform(size=(num_lognormal))
            log_sigmas = torch.tensor(
                [self.gaussian_dist.inv_cdf(v) for v in cdf_vals], device="cuda")
            samples[distribution_choice] = torch.exp(log_sigmas)
        # 30% 从 uniform[1.0, 85.0] 采样
        if num_uniform > 0:
            samples[~distribution_choice] = torch.empty(
                num_uniform, device="cuda").uniform_(self.uniform_lower, self.uniform_upper)
        return samples

设计动机：标准 log-normal 分布倾向于在中等噪声水平集中采样，导致模型在高噪声（全局结构生成）和低噪声（细节精修）区域训练不足。混合分布通过 30% 的均匀采样强制模型在更宽的噪声范围内学习，特别是对视频条件生成中的"从条件帧预测未来帧"场景至关重要。

此外，Video2World 模型还支持额外的 high sigma 策略叠加（5% 概率从 [80, 2000] 均匀采样），进一步增强模型对极高噪声的鲁棒性：

# policy_video2world_model.py:783-786 (UNIFORM80_2000 策略)
mask = torch.rand(sigma_B_1.shape, device=sigma_B_1.device) < self.config.high_sigma_ratio  # 0.05
new_sigma = torch.rand(sigma_B_1.shape, device=sigma_B_1.device) * 1920 + 80
sigma_B_1 = torch.where(mask, new_sigma, sigma_B_1)

Multi-Objective Loss：三重预测目标的统一训练

Cosmos Policy 的训练损失是一个多目标函数，通过 mask 机制 在同一个 batch 内同时训练三种预测能力：

\[ \mathcal{L} = \mathcal{L}_{\text{policy}} + \mathcal{L}_{\text{world model}} + \mathcal{L}_{\text{value function}} \]

每个样本根据其来源（demonstration vs. rollout）和随机采样（p_world_model = 0.5）被分配到不同的预测目标：

样本类型预测目标Loss 作用帧
Demonstration（成功演示）Policy（动作预测）仅 action latent frame
Rollout + world_model_maskWorld Model（未来状态预测）future proprio + future wrist + future images
Rollout + value_function_maskValue Function（回报预测）仅 value latent frame
代码证据：cosmos_policy/models/policy_text2world_model.py:443-546 — compute_loss_with_epsilon_and_sigma() 中的 mask 构建逻辑。 
# policy_text2world_model.py:443-546 (Loss mask 构建核心)
# 初始化全 1 mask
final_mask_B_T = torch.ones((B, T), dtype=torch.long, device=device)

if self.config.mask_loss_for_action_future_state_prediction:
    mask_B_T = torch.zeros((B, T), dtype=torch.long, device=device)
    # Demo 样本：仅对 action frame 计算 loss
    demo_idx = (rollout_data_mask == 0)
    mask_B_T[demo_batch_indices, action_indices[demo_batch_indices]] = 1
    # World model 样本：仅对 future state frames 计算 loss
    world_idx = (rollout_data_mask == 1) & (world_model_sample_mask == 1)
    mask_B_T[world_batch_indices, future_image_indices[world_batch_indices]] = 1
    mask_B_T[world_batch_indices, future_wrist_image_indices[world_batch_indices]] = 1
    mask_B_T[world_batch_indices, future_proprio_indices[world_batch_indices]] = 1
    # Value function 样本：仅对 value frame 计算 loss
    value_idx = (rollout_data_mask == 1) & (value_function_sample_mask == 1)
    mask_B_T[value_batch_indices, value_indices[value_batch_indices]] = 1
    final_mask_B_T = final_mask_B_T * mask_B_T

# Action loss 加权（multiplier = 16）
final_mask_B_T[batch_indices, action_indices] *= int(self.config.action_loss_multiplier)

Action Loss Multiplier = 16：当前训练配置将动作预测的 loss 权重放大 16 倍。这反映了一个关键的工程判断——在统一的潜在空间中，动作信号的信息密度远低于图像帧（7D action vs. 12544 维潜在帧），需要显式加权才能让模型充分关注动作预测质量。

EDM Loss 权重

最终的 per-sample loss 为：

\[ \mathcal{L}_{\text{EDM}} = w(\sigma) \cdot \| x_0 - D_\theta(x_t; \sigma) \|^2 \cdot M \]

其中 \( w(\sigma) \) 是 EDM 的 per-sigma loss weight，\( M \) 是上述 multi-objective mask（含 action multiplier）。

Video Conditioning：Frame Replace 策略

模型使用 Frame Replace 条件策略：将条件帧（当前观测）直接替换到噪声输入中，而非通过 concatenation 或 cross-attention 注入。

关键设计：

  • 条件帧使用极低噪声 \(\sigma_{\text{cond}} = 0.0001\)，近似干净信号
  • 通过 condition_video_input_mask_B_C_T_H_W 控制哪些帧是条件、哪些是预测目标
  • 去噪后，条件帧位置的预测被强制替换回 ground truth（denoise_replace_gt_frames=True），确保 loss 不在条件帧上计算
# policy_video2world_model.py:426-438 (Frame Replace 实现)
# 将条件帧注入噪声输入

_, _, _, c_noise_cond = self.scaling(sigma=sigma_cond)
c_noise = c_noise_cond * condition_mask_mean + c_noise * (1 - condition_mask_mean)

数据采样策略：Demo/Rollout 混合训练

训练数据由两部分组成，通过概率采样混合：

  • Demonstration data（success_only/）：成功的人类遥操作演示，用于训练 policy（动作预测）
  • Rollout data（all_episodes/）：包含成功和失败的 rollout，用于训练 world model 和 value function

采样概率链：

\[ P(\text{demo}) = 0.5, \quad P(\text{rollout}) = 0.5 \] \[ P(\text{world model} | \text{rollout}) = 0.5, \quad P(\text{value function} | \text{rollout}) = 0.5 \]

Value function 使用 Monte-Carlo 回报作为监督信号：

\[ G_t = \sum_{k=0}^{T-t-1} \gamma^k r_{t+k+1}, \quad \gamma = 0.99 \]

其中终端奖励 \( r_T = 1 \)（成功）或 \( r_T = 0 \)（失败）。

代码证据：cosmos_policy/datasets/robocasa_dataset.py:815-824 — __getitem__ 中的 p_world_model 随机分配逻辑。

DreamDojo：预训练与后训练的两阶段设计

Latent Action Model（LAM）：从视频中发现动作

DreamDojo 的第一步不是直接训练世界模型，而是先训练一个 Latent Action Model——从无标注的人类视频中自监督地提取"潜在动作"表征。这解决了大规模人类视频缺乏动作标注的问题。

LAM 的训练数据是纯视频（MP4），代码会递归搜索指定目录下的所有视频文件。训练完成后，LAM 被集成到世界模型中，为预训练阶段提供 proxy action 信号。

代码证据：01_pretraining_and_posttraining/reference_docs/LAM.md — "The code will recursively search the folder and add any detected MP4 videos to the training set."；LAM 权重路径通过 text2world_model_rectified_flow.py 中的 ckpt_path 注入到主模型。

预训练的关键设计选择：

  • zero_init_action_embedder = True：预训练时动作嵌入器初始化为零，意味着模型先学习纯视频预测能力，动作信号在后训练阶段才激活
  • state_t = 4（即 \(1 + 12 \div 4\)）：每个样本包含 4 个时间步的潜在状态，对应 12 帧视频经过 temporal compression ratio=4 后的表示
  • num_frames = 13：每个训练样本包含 13 帧视频（1 条件帧 + 12 预测帧）

后训练：统一动作空间的多机器人适配

后训练阶段将预训练好的世界模型适配到具体机器人的动作空间。关键设计是 384 维统一动作投影层：

# POSTTRAIN.md 中的维度分配
[0, 29)    → Fourier GR-1
[29, 58)   → Retargeted GR-1 (Manus gloves)
[58, 101)  → Unitree G1
[101, 147) → Bimanual YAM
[147, 169) → AgiBot
[169, 220) → Reserved
[220, 352) → MANO actions (手部)
[352, 384) → Latent actions (LAM 输出)

设计思想：通过预留统一的 384 维空间，不同机器人的动作可以共享同一个模型权重，只需在后训练时激活对应的维度区间。这使得预训练的视觉理解能力可以跨机器人平台迁移。后训练时 zero_init_action_embedder = False，动作嵌入器开始学习。

代码证据：configs/2b_480_640_gr1.yaml vs configs/2b_480_640_pretrain.yaml — 对比可见后训练将 zero_init_action_embedder 从 true 改为 false，并指定具体机器人数据集。

蒸馏算法：从教师到实时学生

设计动机

扩散模型的推理需要多步去噪（通常 20-50 步），无法满足机器人实时控制的需求（10 FPS）。DreamDojo 的蒸馏管线将多步教师模型压缩为单步/少步因果学生模型。

三阶段蒸馏流程

Stage 1: Teacher Generation

从教师模型在多个噪声级别生成去噪目标，作为学生训练的监督信号：

# launch_teacher_gen.sh 关键参数
torchrun -m cosmos_predict2._src.predict2.action.inference.inference_gr00t_warmup \
  --experiment=groot_ac_reason_embeddings_rectified_flow_2b_480_640_gr1 \
  --ckpt_path checkpoints/model/ \
  --guidance 0 \
  --chunk_size 12 \
  --query_steps 0,9,18,27,34  # 在 5 个噪声级别采样教师输出

query_steps = [0, 9, 18, 27, 34] 对应 35 步去噪调度中的 5 个均匀间隔点，为学生提供从高噪声到低噪声的完整去噪轨迹。

Stage 2: Warmup（知识蒸馏）

训练因果学生网络对齐教师的去噪输出。学生使用因果架构（causal），只能看到当前和过去的帧，不能看到未来帧——这是实时推理的必要条件。

Stage 3: Self-Forcing（DMD 蒸馏）

Self-Forcing 是蒸馏管线的核心创新。它解决了 autoregressive 生成中的 exposure bias 问题：warmup 阶段学生只见过教师生成的干净帧作为历史输入，但推理时必须使用自己生成的（可能有误差的）帧。

Self-Forcing 的训练方式：

  1. 让学生用自己的 autoregressive rollout 生成历史帧
  2. 教师模型对学生的输出计算 score（梯度方向）
  3. 通过 DMD（Distribution Matching Distillation）损失让学生的输出分布匹配教师的输出分布

torchrun -m scripts.train \
  --config=cosmos_predict2/_src/predict2/interactive/configs/config_distill.py \
  -- experiment=cosmos_predict2p5_2B_action_gr00t_gr1_self_forcing_no_s3
代码证据：02_distillation_and_inference/reference_docs/DISTILL.md — "Finetune the student model with its own autoregressive rollouts to improve long-horizon stability, using the teacher model to provide the score during DMD distillation."

推理：10 FPS 实时交互

蒸馏后的学生模型支持两种推理模式：

  • 离线推理：从预录动作序列生成视频，用于评估
  • 实时遥操作：以 10 FPS 接收实时动作输入，自回归生成视频帧，支持超过 1 分钟的稳定交互

VGG-T-Omega Action Regression：3D 几何先验注入

设计思想

Cosmos Policy 的一个潜在弱点是：它在 2D 潜在空间中预测动作，缺乏显式的 3D 几何理解。VGG-T-Omega Action Regression 分支试图通过引入预训练的 3D 视觉几何先验来弥补这一不足。

架构设计

# scripts/train_vggt_action_regression.py 文档字符串
"""
Architecture (mirrors DA3 action regression):
  - VGGT-Omega Aggregator backbone (frozen) — alternating frame/inter-frame attention
  - CameraHead trunk (4-layer self-attention) — pretrained from pose estimation
  - Per-wrist action heads — new, regresses action chunks from camera tokens

Pretrained weight reuse:
  - aggregator: full pretrained weights (frozen)
  - trunk_left / trunk_right: initialized from CameraHead.trunk
  - token_norm / trunk_norm: initialized from CameraHead norms

View layout with num_history=2, num_context_views=1:
  image shape: (B, 6, 3, H, W)
  views:       [left_t0, left_t1, right_t0, right_t1, base_t0, base_t1]
  left  → camera_tokens[:, 0:2] → trunk_left → head_left → action[0:8]
  right → camera_tokens[:, 2:4] → trunk_right → head_right → action[8:16]
"""

核心设计选择：

  • 冻结 backbone：VGGT-Omega 的 aggregator（交替 frame/inter-frame attention）完全冻结，保留其 3D 几何理解能力
  • 复用 pose estimation 权重：CameraHead trunk 从 pose estimation 任务初始化，将"估计相机位姿"的能力迁移到"估计末端执行器动作"
  • 双腕独立 head：左右腕分别有独立的 action head，各预测 8 维动作 chunk
  • 历史帧输入：使用 num_history=2 帧提供时间上下文，使模型能感知运动方向
代码证据：04_remote_progress_20260521/evidence/code/vggt-omega/scripts/train_vggt_action_regression.py:1-80 — 完整的架构文档字符串和导入结构。

与 Cosmos Policy 的关系：这条线是 Cosmos Policy 的补充而非替代。Cosmos Policy 在 2D 潜在空间中做端到端的 policy/world model/value 联合训练；VGG-T-Omega 则提供一个基于 3D 几何的 action regression baseline，用于评估 3D 先验对策略质量的贡献。

关键设计 Trade-off

1. Latent Injection vs. Separate Head

将动作编码为潜在帧（而非通过独立 MLP head 预测）的优势是复用了扩散模型的全部生成能力，但代价是动作信号被"稀释"在高维潜在空间中（7×32=224 维 action 填充到 12544 维潜在帧），需要 action_loss_multiplier=16 来补偿。

2. Multi-Objective 统一训练 vs. 分阶段训练

Cosmos Policy 选择在同一个 batch 内混合 policy/world model/value function 三种目标。优势是共享表征、减少训练成本；风险是不同目标之间可能存在梯度冲突。当前通过 mask 机制确保每个样本只对一种目标计算 loss，避免了显式的多任务梯度冲突。

3. Hybrid Sigma Distribution 的必要性

标准 log-normal 采样在 \(\sigma \in [0.01, 10]\) 区间集中，但视频条件生成需要模型在极高噪声（\(\sigma > 80\)，对应"从条件帧想象全新未来"）和极低噪声（\(\sigma < 0.01\)，对应"精修细节"）都有良好表现。混合分布 + 额外的 high sigma 策略确保了这一点。

4. Frame Replace vs. Cross-Attention Conditioning

Frame Replace 直接将条件帧"放入"噪声输入中，比 cross-attention 更强地约束了生成结果与条件帧的一致性。这对机器人场景至关重要——生成的未来帧必须与当前观测在物理上连续。
